We need to create three database tables to store refund data: refund_requests, refund_policies, and refund_appeals. These tables will be the source of truth for all refund operations.

Create a Laravel migration for refund_requests table with these fields:
- id (UUID primary key)
- ticket_id (UUID, foreign key to tickets.id, indexed)
- order_id (UUID, foreign key to orders.id)
- user_id (UUID, foreign key to users.id, indexed)
- event_id (UUID, foreign key to events.id, indexed)
- original_amount (decimal 10,2)
- refund_amount (decimal 10,2)
- refund_percentage (decimal 5,2)
- reason (string: event_cancelled, personal_circumstances, duplicate_purchase, other)
- explanation (text, nullable)
- refund_method (string: original_payment_method, store_credit, alternative_payment_method)
- status (string: pending, approved, rejected, processing, completed, failed)
- rejection_reason (text, nullable)
- approved_by (UUID, nullable, foreign key to users.id)
- approved_at (timestamp, nullable)
- processing_started_at (timestamp, nullable)
- completed_at (timestamp, nullable)
- payment_gateway_refund_id (string, nullable)
- payment_gateway_response (json, nullable)
- appeal_count (integer, default 0)
- last_appeal_at (timestamp, nullable)
- created_at and updated_at (timestamps)
- Add composite indexes on (user_id, status), (event_id, status), and (ticket_id)

Create a migration for refund_policies table with:
- id (UUID primary key)
- event_id (UUID, unique, foreign key to events.id)
- organizer_id (UUID, foreign key to organizers.id)
- refund_window_days (integer, default 14)
- refund_percentage_before_event (decimal 5,2)
- refund_percentage_after_event_start (decimal 5,2)
- allow_refunds_after_event_start (boolean, default false)
- processing_time_business_days (integer, default 3)
- allowed_refund_methods (json array)
- requires_approval (boolean, default false)
- auto_approve_threshold (decimal 10,2, nullable)
- max_refunds_per_user (integer, nullable)
- refund_reasons (json array)
- cancellation_policy (text, nullable)
- is_active (boolean, default true)
- created_at and updated_at (timestamps)

Create a migration for refund_appeals table with:
- id (UUID primary key)
- refund_request_id (UUID, foreign key to refund_requests.id, indexed)
- user_id (UUID, foreign key to users.id, indexed)
- appeal_reason (text)
- status (string: pending, approved, rejected, default pending)
- reviewed_by (UUID, nullable, foreign key to users.id)
- review_notes (text, nullable)
- reviewed_at (timestamp, nullable)
- created_at and updated_at (timestamps)

Run php artisan migrate to apply all migrations to your database.
