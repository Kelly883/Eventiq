We need five reusable React components for the QR code ticketing system:

1. QRScanner — A full-screen camera component that uses jsQR to decode QR codes in real-time. Takes a callback prop that fires when a QR code is successfully decoded. Shows a loading state while initializing the camera ('Initializing camera...'). Handles camera permission denied with a message and link to settings. Shows a scanning overlay with corner guides. Debounces rapid scans to prevent duplicate detections. Exposes methods to start/stop scanning and to manually set the scanned data (for testing or manual entry fallback).

2. TicketCard — Displays ticket details in a card overlay. Shows attendee name, ticket tier, event title, and check-in status. Takes a ticket object and status string ('valid', 'checked_in', 'void', 'expired', 'fraud_flagged'). Renders different content based on status. Used on VenueCheckInPage to show details after scanning.

3. StatusBadge — Color-coded status indicator. Takes a status string and renders: green for 'valid', amber for 'checked_in', red for 'void'/'expired'/'fraud_flagged'. Shows the status text and optional timestamp (e.g., 'Already checked in at 14:32'). Reusable across multiple pages.

4. OfflineIndicator — Shows sync status in the top-right corner. Takes a boolean isOnline prop and optional lastSyncAt timestamp. Shows 'Online' in green or 'Offline - limited functionality' in red. Displays last sync time. Includes a manual sync button that triggers a callback.

5. SearchBar — Sticky search input for manual ticket lookup. Takes a placeholder, onSearch callback, and optional isLoading state. Allows searching by ticket ID or attendee email. Shows a loading spinner while searching. Clears the input after a successful search. Used at the top of VenueCheckInPage as a fallback for unreadable QR codes.

All components should be mobile-optimized with large touch targets for venue staff wearing gloves. Use clear, readable fonts and high contrast colors.
