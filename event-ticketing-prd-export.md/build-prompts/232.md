We need state management to handle the QR scanning workflow, ticket verification, and offline caching without making the VenueCheckInPage component handle all the logic itself.

Create three state managers:

1. QR Scanner State — Tracks the camera stream, detected QR codes, and scanning status. Should expose: isInitializing (boolean), cameraPermissionDenied (boolean), lastScannedQrCode (string), scanningError (string or null). Methods: initializeCamera(), stopCamera(), handleQrDetection(qrData). This state should debounce rapid re-scans to prevent duplicate API calls.

2. Ticket Verification State — Tracks the currently scanned ticket's details and verification status. Should expose: currentTicket (object with ticketId, attendeeName, tier, eventTitle, status, isValid), verificationLoading (boolean), verificationError (string or null), lastVerifiedAt (timestamp). Methods: verifyQrCode(qrCodeData, venueId), clearCurrentTicket(). This calls POST /api/tickets/verify-qr and handles the response.

3. Check-In State — Tracks the check-in workflow and offline caching. Should expose: checkInLoading (boolean), checkInError (string or null), isOffline (boolean), cachedCheckIns (array), syncStatus ('synced' | 'syncing' | 'pending'), realTimeMetrics (object with totalCapacity, totalCheckedIn, remainingCapacity). Methods: checkInTicket(ticketId, qrCodeData, venueId), voidTicket(ticketId, reason), syncCheckIns(eventId, lastSyncAt), cacheCheckIn(ticketData). When offline, cache check-ins to localStorage. When online, sync by calling GET /api/venue/check-in/sync and POST /api/tickets/:ticketId/check-in for cached items.

4. Offline Cache Manager — Persists check-in data to localStorage and retrieves it on page load. Should expose: getCachedCheckIns(eventId), saveCachedCheckIn(eventId, ticketData), clearCachedCheckIns(eventId), getLastSyncAt(eventId). This enables the venue staff to continue working without internet.

Keep all business logic (API calls, verification, caching) out of the VenueCheckInPage component — it should only call methods and react to state changes.
