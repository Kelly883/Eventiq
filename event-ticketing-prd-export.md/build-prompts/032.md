We need a couple of things set up before building the ticketing feature:

1. HTTP Client — Make sure axios or fetch is configured on the frontend to handle API requests with authentication headers. The client should automatically include the Bearer token in the Authorization header for all requests to /api/organizer/events/. Set up a base URL pointing to your Laravel backend.

2. Date and Time Utilities — Install date-fns or dayjs for handling dates. We'll need this for:
   - Parsing and formatting sales_start_date, sales_end_date, and early_bird_end_date
   - Calculating whether early bird pricing is active (comparing current time to early_bird_end_date)
   - Validating that sales_end_date is after sales_start_date
   - Displaying human-readable dates in the UI (e.g., 'Ends in 2 days')

3. Currency Formatting — Set up a utility function that formats prices (price and early_bird_price fields) consistently across the UI. Store prices as decimals in the database but display them with proper currency symbols and two decimal places.

These utilities will be used throughout the ticketing components and hooks.
