We need three SDKs set up before building the analytics feature:

1. Mixpanel for event tracking — Install mixpanel-js on the frontend. Initialize it in your main app file (src/main.tsx or src/App.tsx) with your Mixpanel project token. This tracks ticket sales events, page views, and user interactions. We'll log events like 'ticket_purchased' with metadata (tier, price, timestamp). On the backend, you'll need the Mixpanel PHP SDK or HTTP client to query event data for analytics.

2. Recharts for charting — Install recharts. This is a React charting library built on D3 that we'll use for the sales velocity line chart, revenue breakdown bar chart, and pricing window pie chart. It handles responsive sizing and interactive tooltips out of the box.

3. Date utilities — Install date-fns. We'll use this for date range calculations, formatting timestamps for display, and grouping sales data by hour/day/week for the sales velocity chart.

On the backend, set up Laravel's database connection to ensure it can query the analytics tables efficiently. Add any necessary database indexes (we'll define those in database_setup).

Also install react-window on the frontend for the DetailedAnalyticsPage transaction table — this virtualizes large lists so they render fast even with thousands of rows.
