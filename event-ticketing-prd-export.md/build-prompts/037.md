We need three libraries set up before we build the event discovery feature:

1. React Router — Install react-router-dom. We'll use it to create routes for EventBrowsePage (/events), EventDetailPage (/events/:eventId), and CategoryBrowsePage (/events/category/:categoryId). Make sure the router is initialized in your main app file.

2. TanStack Query (React Query) — Install @tanstack/react-query. This handles all data fetching, caching, and synchronization with the Laravel backend. Set up a QueryClient with sensible defaults (staleTime, cacheTime, retry logic). Wrap your app with QueryClientProvider so all components can use useQuery and useMutation hooks.

3. Zustand — Install zustand. We'll use it for lightweight client-side state management (filter selections, search queries, sort preferences). Create a store for event filters that persists across page navigation.

On the Laravel side, make sure your API is configured to accept CORS requests from your frontend domain (update config/cors.php if needed). Test that you can make a simple GET request from the frontend to the backend without CORS errors.
