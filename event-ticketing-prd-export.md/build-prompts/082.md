We need to define the data models for the authentication system on both frontend and backend.

On the backend (Laravel), we already created the models in the previous step, but let's make sure they're complete:

1. User model (app/Models/User.php) — Should have fields: id, email, passwordHash, name, role, emailVerified, createdAt, updatedAt, lastLoginAt. Add relationships: hasMany('Session'), hasMany('PasswordResetToken'). Hide passwordHash from API responses by adding it to the $hidden array. Add a method isPasswordCorrect($password) that uses Hash::check() for constant-time comparison. Add a method invalidateAllSessions() that sets revokedAt on all active sessions.

2. Session model (app/Models/Session.php) — Fields: id, userId, token, expiresAt, createdAt, revokedAt. Add relationship: belongsTo('User'). Add a method isActive() that checks revokedAt is null and expiresAt is in the future.

3. PasswordResetToken model (app/Models/PasswordResetToken.php) — Fields: id, userId, token, expiresAt, usedAt, createdAt. Add relationship: belongsTo('User'). Add a method isValid() that checks usedAt is null and expiresAt is in the future.

On the frontend (React), create TypeScript interfaces in src/features/auth/types/:

1. User interface — { id: string, email: string, name: string, role: 'organizer' | 'attendee' }
2. AuthResponse interface — { token: string, user: User }
3. LoginRequest interface — { email: string, password: string }
4. RegisterRequest interface — { email: string, password: string, name: string }
5. ResetPasswordRequest interface — { token: string, newPassword: string }

All models should be immutable and have proper TypeScript types.
