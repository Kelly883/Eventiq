# Step 133 of 345: Set up routes for accessibility and localization pages

We need to add three routes to the app's router for the accessibility and localization pages:

1. /settings/accessibility — AccessibilitySettingsPage
2. /settings/language — LanguagePreferencePage
3. /settings/device-localization — DeviceLocalizationSyncPage

All three routes should be protected by authentication middleware — if the user isn't logged in, redirect to /login with a toast message 'Sign in to customize your preferences'.

Add links to these pages in the app's settings menu or navigation drawer. The settings menu should have three items: 'Accessibility', 'Language & Region', and 'Device Sync'. Clicking each navigates to the corresponding page.

Make sure the back button from each page returns to the settings menu (or wherever the user came from).

For deep linking: if someone tries to access /settings/accessibility while logged out, they should be redirected to /login, and after signing in, they should be sent back to /settings/accessibility.
