We need three Laravel Eloquent models and corresponding TypeScript types for the check-in system:

1. Ticket model (app/Models/Ticket.php) — Represents a single ticket. Fields: id, event_id, ticket_id, attendee_name, attendee_email, tier, status, checked_in_at, checked_in_by. Add relationships: belongsTo Event, belongsTo User (for checked_in_by), hasMany FraudEvent. Add a scope method scopeByEvent($query, $eventId) to filter by event. Add a method isCheckedIn() that returns true if status='checked_in'. Add a method canCheckIn() that checks if status='valid' and no fraud flags exist.

2. FraudEvent model (app/Models/FraudEvent.php) — Tracks suspicious activity. Fields: id, ticket_id, event_id, fraud_type, detected_at, first_check_in_at, first_check_in_by, second_check_in_at, second_check_in_by, risk_level, notes. Add relationships: belongsTo Ticket, belongsTo Event. Add a method isDuplicate() that returns true if fraud_type='duplicate_checkin'.

3. AuditLog model (app/Models/AuditLog.php) — Logs all actions. Fields: id, event_id, user_id, action, ticket_id, details (JSON), created_at. Add relationships: belongsTo Event, belongsTo User. Add a scope scopeByEvent($query, $eventId) and scopeByAction($query, $action).

On the frontend, create TypeScript types in src/features/check-in/types/index.ts:
- Ticket type with all fields from the Ticket model
- FraudEvent type with all fields
- AuditLog type with all fields
- CheckInResult type for API responses: { ticketId, status, message, previousCheckInAt?, riskLevel? }
- SearchResult type for search responses: { results: Ticket[], total, query }
- StatsResponse type: { totalCapacity, totalCheckedIn, totalRemaining, totalVoid, checkInRate, lastUpdateAt }

Make all types immutable and add helper functions like formatCheckInTime() and getRiskLevelColor().
