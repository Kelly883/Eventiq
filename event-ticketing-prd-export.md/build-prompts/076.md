2. auditLogs table (if not already present) — Tracks all admin actions. Fields: id (UUID), userId (foreign key to users.id — the admin performing the action), action (string: 'user_suspended', 'user_unsuspended', 'event_approved', 'event_flagged', 'event_cancelled', 'payout_approved', 'payout_rejected', 'payment_refunded', etc.), targetType (string: 'user', 'event', 'order', 'payout'), targetId (UUID), description (text), metadata (JSON for additional context), createdAt (timestamp). Create indexes for performance:

- users: (role, status, createdAt) for user management queries
