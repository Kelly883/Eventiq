Now connect authentication to the app's routing so unauthenticated users can't access protected pages and authenticated users can't access auth pages.

Set up route guards using React Router. Create a ProtectedRoute component that checks if the user is authenticated (using the useAuth hook). If not authenticated and not still loading, redirect to /login. If authenticated, render the requested page. If still loading, show a loading spinner.

Create a PublicRoute component for auth pages (LoginPage, RegisterPage, ForgotPasswordPage, ResetPasswordPage). If the user is already authenticated, redirect them to /dashboard. If not authenticated, render the page.

Define your routes: /login, /register, /forgot-password, /reset-password as PublicRoutes. All other pages (like /dashboard) as ProtectedRoutes.

Add a route guard at the app level: if a user tries to access a protected route while loading, show a loading spinner. If they try while not authenticated, redirect to /login.

Handle deep linking: if an unauthenticated user tries to access /dashboard directly, redirect to /login. After they log in, optionally redirect them back to the page they were trying to access (using a 'from' location in the router state).

Add a logout action in the app header or user menu: when clicked, call the logout method from AuthContext, which clears the token and user, then redirect to /login.

Make sure the ResetPasswordPage can be accessed without authentication (it's token-gated, not auth-gated) — add it as a PublicRoute but don't redirect authenticated users away from it.
