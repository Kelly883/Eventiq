We need to define the TicketTier data model on both backend and frontend.

Backend (Laravel):
Create app/Features/Ticketing/Models/TicketTier.php as an Eloquent model. Define all 12 fields from the schema as properties. Add relationships:
- belongsTo Event (the parent event)
- Add accessor methods:
  - isEarlyBirdActive() — returns true if current time is before early_bird_end_date and early_bird_price is set
  - getEffectivePrice() — returns early_bird_price if early bird is active, otherwise price
  - isAvailable() — returns true if current time is between sales_start_date and sales_end_date (or if dates are null)
  - getRemainingQuantity() — returns quantity minus sold count (we'll calculate this from orders later)

Add a scope method: scopeForEvent($query, $eventId) to filter tiers by event.

Frontend (React + TypeScript):
Create src/features/ticketing/types/index.ts with a TicketTier interface matching the schema:
```typescript
interface TicketTier {

  quantity: number;
  sales_start_date: string | null;

  early_bird_end_date: string | null;
```

Add helper functions in the same file:
- isEarlyBirdActive(tier: TicketTier): boolean
- getEffectivePrice(tier: TicketTier): number
- isAvailable(tier: TicketTier): boolean
- formatPrice(price: number): string

These helpers mirror the backend logic so the frontend can calculate prices and availability without waiting for the server.
