We need several reusable React components that will be shared across EventCreatePage and EventEditPage, as well as used in OrganizerEventListPage.

1. EventForm component (src/features/events/components/EventForm.tsx) — This is the main form used by both create and edit pages. It should:
- Accept props: isEditMode (boolean), initialData (Event | null), onSubmit (function)
- Use react-hook-form for form state management
- Render sections in cards: Details (title, description with TipTap editor), Venue (name, address), Tickets (dynamic ticket tier list), Media (banner upload)
- Include real-time validation on blur for each field
- Show a sticky footer with 'Save as Draft' and 'Publish Event' buttons (or 'Save Changes' in edit mode)
- Disable the form and show a spinner on the clicked button while saving
- Display inline validation errors below each field

2. TicketTierForm component (src/features/events/components/TicketTierForm.tsx) — A sub-form for managing individual ticket tiers:
- Render fields: name, price, quantity, sales_start_date, sales_end_date
- Accept props: tier (TicketTier | null), onSave (function), onRemove (function)
- Include 'Add Tier', 'Save Tier', and 'Remove Tier' buttons
- Validate that name and quantity are not empty

3. BannerUpload component (src/features/events/components/BannerUpload.tsx) — Handles banner image uploads:
- Show a preview of the current banner (if editing)
- Provide a file input or drag-and-drop zone for selecting a new image
- Validate file type (image only) and size (max 5MB) on the client before uploading
- Show upload progress while the file is being sent to POST /api/organizer/events/:eventId/upload-banner
- Display the new banner URL after successful upload
- Show error messages if validation fails

4. EventCard component (src/features/events/components/EventCard.tsx) — Displays a single event in the list:
- Show event title, date range, venue name, and ticket sales progress (e.g., '45/100 tickets sold')
- Display a status badge (Draft, Published, Archived)
- Include action buttons: 'Edit' (navigates to /organizer/events/:eventId/edit) and 'Delete' (triggers confirmation modal)
- Accept props: event (Event), onDelete (function)

5. DeleteConfirmationModal component (src/features/events/components/DeleteConfirmationModal.tsx) — A reusable modal for confirming event deletion:
- Show a warning message: 'Are you sure you want to delete this event? This action cannot be undone.'
- Include 'Cancel' and 'Delete' buttons
- Accept props: isOpen (boolean), eventTitle (string), onConfirm (function), onCancel (function)
- Show a loading state on the 'Delete' button while the request is in progress

6. RichTextEditor component (src/features/events/components/RichTextEditor.tsx) — Wraps TipTap for the event description:
- Provide basic formatting options: bold, italic, underline, bullet list, numbered list, link
- Accept props: value (string), onChange (function)
- Show a character count (e.g., '250/5000 characters')

All components should use TypeScript for type safety and accept the Event and TicketTier types from src/features/events/types/index.ts.
