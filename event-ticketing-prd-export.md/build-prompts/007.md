We're building a ticket inventory management system for event organizers. This feature lets organizers track and adjust ticket stock across different tiers and pricing windows.

On the frontend (React + Vite), create a feature folder at src/features/ticketInventory/ with these subfolders:
- pages/ (for TicketInventoryDashboardPage and AdjustInventoryModal)
- components/ (reusable UI pieces like InventorySummaryCard, InventoryTable, PricingWindowRow, LowStockAlert, InventoryExportButton)
- hooks/ (custom hooks like useInventoryData, useAdjustInventory, useInventoryExport)
- types/ (TypeScript interfaces for inventory, adjustments, audit logs)
- api/ (API client functions for all five endpoints)
- utils/ (helpers like formatUtilizationPercentage, calculateLowStock)

On the backend (Laravel), create these folders under app/:
- Http/Controllers/Organizer/InventoryController.ts (handles all five endpoints)
- Models/TicketInventory.php and InventoryAdjustment.php (Eloquent models)
- Policies/TicketInventoryPolicy.php (authorization rules)
- Requests/ (form requests for validation)
- Resources/ (API resource classes for responses)

Also create database/migrations/ for the two new tables: ticket_inventory and inventory_adjustments.
