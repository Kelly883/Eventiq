We need two key libraries set up for the event calendar feature:

1. React Big Calendar (react-big-calendar) — This is the main calendar UI library. Install it via npm. It provides month, week, and day view components out of the box, which we'll use for EventCalendarPage. Configure it with date-fns as the date library (not Moment.js, since we're using date-fns everywhere). Set up the localizer: import { dateFnsLocalizer } from 'react-big-calendar' and configure it with date-fns locale.

2. Date-fns (date-fns) — Already likely in the project, but make sure it's installed. We'll use it for all date parsing, formatting, and manipulation. Functions we'll need: parse, format, startOfMonth, endOfMonth, startOfWeek, endOfWeek, isSameDay, isWithinInterval, and getISOWeek.

On the backend (Laravel), install carbon for date handling if not already present (it usually is). We'll use Carbon to parse ISO8601 dates from query params and validate date ranges.

Create a shared constants file at src/features/events-calendar/utils/dateConstants.ts that exports: DATE_FORMAT (ISO8601), DISPLAY_FORMAT (readable format), CALENDAR_VIEWS (month, week, day), and AVAILABILITY_COLORS (green for available, amber for low stock, red for sold out).
