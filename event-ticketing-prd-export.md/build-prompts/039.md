We need to set up the payment provider SDKs so we can securely handle payments.

On the frontend (React), install the Stripe and PayPal SDKs:
- Install @stripe/react-stripe-js and @stripe/js for Stripe integration
- Install @paypal/paypal-js for PayPal integration
- Store your Stripe publishable key in a .env file as VITE_STRIPE_PUBLISHABLE_KEY (never expose the secret key to the client)
- Store your PayPal client ID as VITE_PAYPAL_CLIENT_ID

On the backend (Laravel), install the payment provider packages:
- Install stripe/stripe-php via Composer for Stripe server-side operations
- Add STRIPE_SECRET_KEY and STRIPE_WEBHOOK_SECRET to your .env file (these stay server-side only)
- Add PAYPAL_MODE, PAYPAL_CLIENT_ID, and PAYPAL_SECRET to .env if using PayPal

Create a config file at config/payment.php that reads these environment variables and exports them as a structured config object. This keeps payment credentials centralized and easy to manage.

Initialize the Stripe client in a Laravel service provider so it's available throughout the application. Do the same for PayPal if using it.

Test that both SDKs initialize without errors when the app starts.
