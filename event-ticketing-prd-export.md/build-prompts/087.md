We need a Laravel model and TypeScript types for pricing windows.

Create the PricingWindow model at app/Features/Pricing/Models/PricingWindow.php. It should:
- Extend Illuminate\Database\Eloquent\Model
- Use SoftDeletes trait for soft delete support
- Define fillable fields: window_name, start_date_time, end_date_time, price, quantity_limit, priority
- Define relationships: belongsTo Event, belongsTo TicketTier (ticket_category_id)
- Add a computed attribute isActive that checks if current time is between start_date_time and end_date_time
- Add a method getAvailableQuantity() that returns quantity_limit - quantity_sold (or null if unlimited)
- Cast dates to Carbon instances, price to decimal
- Use timestamps (created_at, updated_at)

On the frontend, create TypeScript types at src/features/pricing/types/pricing.ts:
- PricingWindow interface with all fields from the schema
- PricingWindowFormData for the form (subset of fields for creation/update)
- PricingPreviewData for the preview modal

Create Zod validation schemas:
- pricingWindowSchema for form validation (windowName required, min 1 char; startDateTime < endDateTime; price > 0; quantityLimit > 0 if provided)
- These schemas should match the backend validation rules
