We need five API endpoints for the organizer profile system. Here's what each one does:

1. GET /api/organizers/:organizerId — Public endpoint to fetch an organizer's profile. Takes organizerId as a URL parameter. Query the organizers table by id. Check the isPublic flag — if false and the requester is not the organizer, return 404 (don't reveal private profiles exist). Call the getPublicProfile() method to filter sensitive fields based on emailPublic and phonePublic toggles. Return the public profile. Rate limit 20/min per IP to prevent scraping. No auth required.

2. GET /api/organizers/:organizerId/events — Public endpoint to fetch an organizer's events. Takes organizerId as URL param and query params: status (upcoming|past), limit (default 20, max 100), offset (default 0). Query the organizers table, check isPublic flag (return 404 if private). Query the events table filtered by organizer_id. Filter by status based on event date (upcoming = date > now, past = date <= now). Order by date descending. Paginate with limit/offset. Return {events: [{id, title, date, description, thumbnailUrl, ticketsAvailable, ticketsSold}], total, limit, offset}. Rate limit 20/min per IP. No auth required.

3. GET /api/organizers/me — Authenticated endpoint to fetch the current user's organizer profile. Verify the bearer token using Laravel Sanctum. Extract userId from the token. Query organizers by userId. Check the user has the 'Organizer' role via the OrganizerPolicy. Call getPrivateProfile() to return all fields including private ones. Return the full profile with updatedAt. Return 401 if not authenticated, 403 if not an organizer, 404 if no profile exists yet.

4. PATCH /api/organizers/me/update — Authenticated endpoint to update the organizer's profile. Verify bearer token. Extract userId. Query organizers by userId. Validate the request body using UpdateOrganizerRequest (displayName required, bio max 500 chars, URLs valid format, hex colors valid). Store old values for the audit log. Update the organizers record. Create an auditLog entry with action='profile_updated', oldValue and newValue objects. Return the updated profile. Rate limit 5/min per user. Return 400 for validation errors, 401 if not authenticated, 403 if not an organizer, 404 if no profile, 429 if rate limited.

5. POST /api/organizers/me/upload-avatar — Authenticated endpoint to upload an organizer's avatar. Verify bearer token. Extract userId. Query organizers by userId. Validate the file: check MIME type (image/jpeg, image/png, image/webp), check file size (max 5MB). Use Laravel Storage to upload to S3 at path avatars/{userId}/{timestamp}.{ext}. Use sharp to resize the image to 400x400 pixels. Generate a download URL from storage. Update organizers.avatarUrl with the new URL. Delete the old avatar from storage if it exists. Create an auditLog entry with action='avatar_uploaded'. Return {avatarUrl}. Rate limit 10/min per user. Return 400 for validation errors, 401 if not authenticated, 403 if not an organizer, 404 if no profile, 413 if file too large, 500 if upload fails.

All endpoints should use Laravel Eloquent for queries, apply the OrganizerPolicy for authorization, and handle errors gracefully.
