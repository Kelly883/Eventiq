Now connect the payment pages to the rest of the app. Add routes for both pages: /settings/payment-methods (PaymentMethodsPage) and /organizer/settings/payments (OrganizerPaymentSettingsPage).

On the existing user settings page, add a 'Payment Methods' link or tab that navigates to /settings/payment-methods. On the existing organizer settings page, add a 'Payments' link or tab that navigates to /organizer/settings/payments.

Wire up these connections:
- When the user successfully adds a payment method, show a toast confirmation with a 'View Payment Methods' action that scrolls to the newly added card
- When the user successfully removes a payment method, show a toast confirmation
- When the organizer successfully connects their Stripe account, show a toast confirmation and refresh the page to show the connected status
- The Stripe Connect onboarding flow redirects to GET /api/organizer/settings/stripe-connect-return, which should redirect back to /organizer/settings/payments after updating the status
- Back button from either page goes back to the parent settings page
- Deep links to /settings/payment-methods or /organizer/settings/payments should work when the user is logged in (redirect to login first if not authenticated)
