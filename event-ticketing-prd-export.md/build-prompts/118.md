We need to set up React Router routes for the three event discovery pages so users can navigate between them.

Create these routes in your React Router configuration:

1. /events — EventBrowsePage (the main event marketplace with search, filters, and event grid)
2. /events/:eventId — EventDetailPage (detailed view of a single event with full information, ticket tiers, and pricing)
3. /events/category/:categoryId — CategoryBrowsePage (filtered event listing for a specific category)

Make sure the routes are set up in the correct order in your router config — the more specific routes (/events/:eventId) should come BEFORE the less specific ones (/events) to avoid route conflicts.

Also add a breadcrumb navigation component that shows the current location:
- On /events: just 'Events'
- On /events/:eventId: 'Events > Event Title' (fetch the title from the event data)
- On /events/category/:categoryId: 'Events > Category Name' (fetch the category name from the category data)

The breadcrumb should be clickable so users can navigate back to the parent page.

Add a 'Browse Events' link or button on your home page or main navigation that routes to /events. If the app has a bottom navigation bar or header menu, make sure there's a way to get to the event discovery feature from anywhere in the app.
