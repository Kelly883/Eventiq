Unit tests:
- API Keys store: fetching keys populates the array, creating a key sets newlyCreatedKey, clearing removes it, revoking removes from array
- Webhooks store: fetching webhooks populates the array, creating adds to array, deleting removes from array
- API Logs store: fetching logs populates the array, loading more appends (doesn't replace)
- Error handling: errors are captured and exposed in the store

Component tests:
- DeveloperPortalPage: shows 'Access Denied' for non-organizers, redirects to login for unauthenticated users
- ApiKeysTab: displays keys in a table, 'Create New Key' button opens modal, form validation works, submitting creates a key
- WebhooksTab: displays webhooks in a table, 'Register Webhook' button opens modal, form validation works, submitting creates a webhook, 'Send Test' button sends payload
- ApiLogsTab: displays logs in reverse chronological order
- DocumentationTab: displays static content and links

Integration tests (full user flows):
- Create an API key → see the full key in a modal → copy it → close → key appears in the table
- Revoke an API key → key disappears from the table
- Create a webhook → webhook appears in the table
- Send a test payload to a webhook → success or error notification
- Delete a webhook → webhook disappears from the table
- Navigate to /developer while not logged in → login modal
- Navigate to /developer as a non-organizer → 'Access Denied'

API endpoint tests:
- GET /api/developer/api-keys: returns only the user's keys, rejects without auth
- POST /api/developer/api-keys: creates a key, returns the raw key once, rejects without auth
- DELETE /api/developer/api-keys/:keyId: revokes a key, rejects if user doesn't own it
- GET /api/developer/webhooks: returns only the user's webhooks, rejects without auth
- POST /api/developer/webhooks: creates a webhook, validates URL, rejects without auth
- DELETE /api/developer/webhooks/:webhookId: deletes a webhook, rejects if user doesn't own it
- GET /api/developer/api-logs: returns the user's API call logs, rejects without auth
- GET /v1/events: requires a valid API key with 'events:read' scope
