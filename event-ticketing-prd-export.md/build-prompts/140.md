We need to build the PATCH /api/organizer/events/:eventId endpoint that updates an event and its ticket tiers in a single transaction.

Create app/Features/Ticketing/Controllers/EventTicketingController.php with an update() method that:

1. Validates the request using app/Features/Ticketing/Requests/UpdateTicketTiersRequest.php. The request should validate:
   - eventId is a valid event that exists
   - ticketTiers is an array of tier objects
   - Each tier has: name (required, string), price (required, decimal > 0), quantity (required, int > 0), sales_start_date (optional, datetime), sales_end_date (optional, datetime, must be after sales_start_date if both present), benefits_description (optional, string), tier_image_url (optional, URL), early_bird_price (optional, decimal > 0, must be less than price), early_bird_end_date (optional, datetime, must be before sales_end_date if both present), max_per_customer (optional, int > 0)

2. Checks authorization — the authenticated user must be the event organizer (use Laravel Policy)

3. Wraps everything in a database transaction to ensure consistency:
   - For each tier in the request:
     - If it has an id, update the existing tier
     - If it has no id, create a new tier
   - Delete any existing tiers that aren't in the request (soft delete or hard delete based on your preference)
   - Return the updated event with all its tiers

4. Returns 200 with message 'Event and ticket tiers updated successfully' and the updated tiers

5. Error handling:
   - 400 if validation fails (return validation errors)
   - 401 if not authenticated
   - 403 if the user isn't the event organizer
   - 404 if the event doesn't exist
   - 500 if the transaction fails

Create app/Features/Ticketing/Services/TicketTierService.php to handle the business logic of syncing tiers (create/update/delete). This keeps the controller clean and makes the logic testable.

Create app/Features/Ticketing/Resources/TicketTierResource.php to format the response — include all fields from the schema plus calculated fields like isEarlyBirdActive and effectivePrice.
