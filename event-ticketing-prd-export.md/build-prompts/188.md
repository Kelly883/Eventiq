We need four reusable React components that the payment pages will share:

1. PaymentMethodCard — Displays a single saved payment method. Shows the card brand (Visa, Mastercard, etc.), last four digits, expiration date, and a badge if it's the default. Include two action buttons: 'Set as Default' (only if not already default) and 'Remove'. Tapping 'Set as Default' calls a callback with the payment method ID. Tapping 'Remove' shows a confirmation dialog before calling a delete callback. The card should have a subtle background and clear typography. This gets used in the PaymentMethodsPage list.

2. StripeElementsForm — A form component that wraps Stripe Elements for securely collecting card details. It should render the CardElement from @stripe/react-stripe-js with proper styling to match the app theme. Include fields for cardholder name. Add a submit button labeled 'Add Card'. On submit, call stripe.createPaymentMethod() to tokenize the card (never send raw card data to the server). If successful, call an onSuccess callback with the payment method ID. If it fails, show the Stripe error message. Show a loading spinner while processing. This component is used in the 'Add New Card' modal.

3. ConnectStatusDisplay — Shows the organizer's Stripe Connect status. If not connected, display explanatory text about the Stripe partnership and a prominent 'Connect with Stripe' button. If connected, show the masked Stripe account ID (e.g., 'acct_1234...'), the status badge ('Enabled', 'Pending', etc.), and a link to the Stripe Express Dashboard. Include a 'Disconnect' button that shows a confirmation dialog. The 'Connect with Stripe' button navigates to /api/organizer/settings/stripe-connect. This component is used on the OrganizerPaymentSettingsPage.

4. PaymentMethodSkeleton — A loading placeholder that mimics the PaymentMethodCard layout. Shows shimmer animations for the card brand, last four digits, expiration, and action buttons. This is used while payment methods are loading.

All components should handle loading and error states gracefully. Use TypeScript for type safety. Import the PaymentMethod and OrganizerPaymentSettings types from src/features/payment/types/.
