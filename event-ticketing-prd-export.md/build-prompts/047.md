We need to integrate with payment gateways (Stripe and PayPal) so we can actually process refunds through them. This is critical because the refund_requests table stores paymentGatewayRefundId and paymentGatewayResponse — we need to be able to call out to these services.

On the backend (Laravel):
1. Install the Stripe PHP SDK: composer require stripe/stripe-php
2. Install the PayPal SDK: composer require paypal/checkout-sdk-php
3. Add STRIPE_SECRET_KEY, STRIPE_PUBLIC_KEY, PAYPAL_CLIENT_ID, and PAYPAL_CLIENT_SECRET to your .env file
4. Create a config file at config/payment-gateways.php that loads these keys and exposes helper functions
5. Create a PaymentGatewayService.php in app/Services/ that abstracts both Stripe and PayPal. This service should have methods like: processRefund($refundRequestId, $paymentMethod) which calls the appropriate gateway based on how the original payment was made, and parseGatewayResponse() to extract the refund ID and store it in paymentGatewayResponse

On the frontend (React):
1. Install @stripe/react-stripe-js and @stripe/stripe-js: npm install @stripe/react-stripe-js @stripe/stripe-js
2. Add VITE_STRIPE_PUBLIC_KEY to your .env file (this is the public key, safe to expose)
3. Create a StripeProvider component that wraps the app and initializes Stripe

The frontend doesn't directly process refunds — that happens on the backend — but we need Stripe loaded for potential future features like displaying payment method details.
