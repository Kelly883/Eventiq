We need several reusable components that the auth pages (LoginPage, RegisterPage, ForgotPasswordPage, ResetPasswordPage) will share.

1. FormField component — A wrapper for text inputs with consistent styling. Props: label (string), type ('text' | 'email' | 'password'), value (string), onChange (callback), onBlur (callback), error (string | null), placeholder (string), disabled (boolean). Renders a label, input field, and error message below the field in red text if error exists. The input border should be red when there's an error.

2. PasswordVisibilityToggle component — An icon button that appears inside the password field (positioned absolutely on the right). Clicking it toggles between showing the password as plain text and hiding it as dots. Use an eye icon for 'show' and eye-slash icon for 'hide'. Should be a small, subtle button that doesn't distract from the form.

3. PasswordStrengthMeter component — Shows password strength as a colored bar and text label. Props: password (string). Calculates strength based on: weak (< 8 chars or only lowercase), medium (8+ chars with lowercase + uppercase OR lowercase + numbers), strong (8+ chars with lowercase + uppercase + numbers). Renders a bar that fills from left to right with color: red for weak, amber for medium, green for strong. Below the bar, show the text label 'Weak', 'Medium', or 'Strong' in the corresponding color.

4. SubmitButton component — A button for form submission. Props: loading (boolean), disabled (boolean), children (text). When loading is true, show a spinner icon and disable the button. The button text changes based on context (passed as children). Use a consistent style across all auth pages.

5. AuthCard component — A centered card container for auth forms. Props: children (React nodes), title (string). Renders a card with max-width 448px (md breakpoint), centered on the page with a subtle gradient background. The title appears at the top of the card. This ensures visual consistency across LoginPage, RegisterPage, ForgotPasswordPage, and ResetPasswordPage.

All components should be in src/features/auth/components/ and exported from an index.ts file for easy importing.
