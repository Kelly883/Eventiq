We need seven reusable components that will be shared across AccessibilitySettingsPage, LanguagePreferencePage, and DeviceLocalizationSyncPage:

1. SettingCard — A container component for a single preference setting. Takes a label, description, and children (the control). Shows the label prominently, description below in smaller text, and the control on the right (desktop) or below (mobile). Used for every setting on both pages.

2. AccessibilityPreview — Shows a live preview of how text looks with current accessibility settings applied. Takes the current fontSize, lineHeight, letterSpacing, wordSpacing, highContrast, and colorBlindnessMode. Renders sample text that updates in real-time as settings change. Shows a paragraph of Lorem ipsum, a heading, and a list to demonstrate different text styles. Apply CSS filters for color blindness simulation (protanopia, deuteranopia, tritanopia). Apply high contrast colors if enabled. Apply motion reduction (prefers-reduced-motion) if enabled.

3. LocaleFormatPreview — Shows how dates, times, and numbers will be formatted with current locale settings. Takes dateFormat, timeFormat, numberFormat, currency, and language. Displays examples: today's date formatted, current time formatted, a sample number (1234.56), and a sample price (USD 99.99). Updates in real-time as settings change.

4. LanguageSelector — A grid of language options with flag icons and language names. Takes the list of supported languages, current language, and an onChange callback. Shows each language as a card with flag icon, native language name, and English name. Current language is highlighted with a checkmark. Clicking a language calls onChange. On mobile, becomes a vertical list instead of a grid. Keyboard navigation with arrow keys.

5. SyncStatusBadge — A small badge showing sync status for a device. Takes status ('synced', 'pending', 'error') and optional message. Shows green checkmark for synced, amber clock for pending, red X for error. Hovering shows a tooltip with the message or estimated sync time.

6. DeviceCard — Shows information about a single registered device. Takes device data (name, type, language, accessibility settings summary, lastSyncTime, syncStatus). Displays device icon (phone/tablet/desktop), device name (editable), current language, accessibility settings summary (e.g., 'Font: 16px, High Contrast: Off'), last sync time, and sync status badge. Shows action buttons: Edit, Remove. On mobile, actions are in a collapsible menu.

7. ColorBlindnessSimulator — A utility component that applies color blindness filters to its children. Takes a mode ('none', 'protanopia', 'deuteranopia', 'tritanopia') and renders children with appropriate CSS filters applied. Used by AccessibilityPreview to show how colors look to users with color blindness.

All components should be fully keyboard accessible (ARIA labels, semantic HTML, focus management) and support the current accessibility settings (high contrast, reduced motion, screen reader optimization).
