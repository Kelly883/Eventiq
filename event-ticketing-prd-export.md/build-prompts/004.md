We're building an event creation and management system for organizers. For this step, I need you to set up the folder structure for both the frontend and backend.

On the frontend (React + Vite), create a features/events/ directory with these subfolders:
- pages/ (for OrganizerEventListPage, EventCreatePage, EventEditPage)
- components/ (for reusable UI pieces like EventForm, TicketTierForm, BannerUpload, EventCard)
- hooks/ (for custom React hooks like useEventList, useCreateEvent, useEditEvent)
- types/ (for TypeScript interfaces matching the Event and TicketTier schemas)
- services/ (for API client functions that call the backend endpoints)

On the backend (Laravel), create these directories under app/:
- Http/Controllers/Organizer/ (for EventController handling all event operations)
- Models/ (Event and TicketTier Eloquent models)
- Policies/ (EventPolicy for authorization)
- Resources/ (EventResource and TicketTierResource for API responses)
- Requests/ (StoreEventRequest, UpdateEventRequest for validation)
- Jobs/ (for queued jobs like IncrementTotalEventsCreated, DecrementTotalEventsCreated)

Also create database/migrations/ for the events and ticket_tiers tables, and routes/api.php will contain all the endpoint definitions.

This structure keeps concerns separated and makes the codebase easy to navigate as the feature grows.
