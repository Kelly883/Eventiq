We need to set up two fraud detection SDKs that will power the fraud detection system: Sift Science for comprehensive fraud analysis and Stripe Radar for payment-specific fraud detection.

On the backend (Laravel):
1. Install the Sift Science PHP SDK via Composer: `composer require sift/sift-php`
2. Store your Sift Science API key in .env as SIFT_API_KEY (never commit this to version control)
3. Install the Stripe PHP SDK: `composer require stripe/stripe-php`
4. Store your Stripe API key in .env as STRIPE_API_KEY and STRIPE_WEBHOOK_SECRET
5. Create a configuration file at config/fraud.php that exports SIFT_API_KEY, STRIPE_API_KEY, and fraud thresholds (HIGH_RISK_THRESHOLD=75, MEDIUM_RISK_THRESHOLD=31, VELOCITY_LIMIT_24H=10, VELOCITY_LIMIT_1H=3, CARD_TESTING_THRESHOLD=5)
6. Create a FraudDetectionService in app/Features/Fraud/Services/ that wraps both SDKs and provides a unified interface for fraud detection

On the frontend (React):
1. Install Stripe.js: `npm install @stripe/stripe-js`
2. Store your Stripe publishable key in .env.local as VITE_STRIPE_PUBLISHABLE_KEY
3. Create an API client service at src/features/fraud/services/fraudApi.ts that will call the backend endpoints

The FraudDetectionService should expose methods like: detectFraudRisk(transaction), checkVelocity(userId, amount), detectDuplicateTickets(ticketTierId, qrCode), and getTransactionDetails(fraudEventId). This keeps all fraud logic centralized and testable.
