We need to define the data structures for our analytics feature on both frontend and backend.

On the frontend (React/TypeScript), create types in src/features/analytics/types/:

1. AnalyticsMetrics interface — Represents the summary metrics from analytics_events_metrics. Fields: id, eventId, organizerId, totalRevenue, totalTicketsSold, totalPageViews, totalTicketPageViews, conversionRate, averageTicketPrice, peakSalesHour (optional), topTicketTier (optional), lastUpdatedAt, createdAt, updatedAt. Add helper methods: formatRevenue() (returns '$X,XXX.XX'), formatConversionRate() (returns 'X.X%'), getTrendIndicator() (compares current to previous period and returns 'up'|'down'|'flat').

2. SalesTimelineEntry interface — Represents a single sale from analytics_sales_timeline. Fields: id, eventId, ticketTierId, pricingWindowId (optional), saleTimestamp, quantity, unitPrice, totalAmount, buyerEmail (optional), source (optional), createdAt.

3. TierPerformance interface — Represents per-tier metrics from analytics_tier_performance. Fields: id, eventId, ticketTierId, totalSold, totalRevenue, averagePrice, percentageOfTotalSales, percentageOfTotalRevenue, conversionRate, lastUpdatedAt, createdAt, updatedAt.

4. SalesVelocityDataPoint interface — For the sales velocity chart. Fields: timestamp (ISO8601), cumulativeSales (number), cumulativeRevenue (number), periodSales (number), periodRevenue (number).

On the backend (Laravel), create Eloquent models in app/Models/:

1. Analytics model — Maps to analytics_events_metrics table. Define relationships: belongsTo Event, belongsTo Organizer. Add computed properties for trend calculations. Add a scope method scopeForEvent($query, $eventId) for filtering.

2. SalesTimeline model — Maps to analytics_sales_timeline table. Define relationships: belongsTo Event, belongsTo TicketTier, belongsTo PricingWindow. Mark as immutable (no updates after creation). Add scope methods: scopeForEvent(), scopeByDateRange($startDate, $endDate), scopeByTier($tierId).

3. TierPerformance model — Maps to analytics_tier_performance table. Define relationships: belongsTo Event, belongsTo TicketTier. Add scope methods: scopeForEvent(), scopeForTier($tierId).

All models should use UUIDs as primary keys. Add proper timestamps (createdAt, updatedAt). Use Laravel's fillable or guarded properties to control mass assignment.
