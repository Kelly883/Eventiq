We need six reusable components that the organizer profile pages will share:

1. ProfileHeader — Displays the organizer's avatar (circular, 120px), display name, bio, and branding colors applied to the background. Takes props: organizer (Organizer type), isEditable (boolean), onEditClick (callback). Shows a pencil icon if isEditable. The background uses the organizer's primaryColor from brandingColors. Responsive: full width on mobile, fixed width on desktop.

2. BrandingColorPicker — A form section with two color pickers (primary and accent) using react-colorful. Shows a live preview of how the colors look on the header background. Takes props: primaryColor (string), accentColor (string), onChange (callback with {primaryColor, accentColor}). Validates hex format and shows error if invalid.

3. AvatarUploadField — Drag-and-drop avatar upload using react-dropzone and react-easy-crop. Shows a preview of the cropped circular image. Takes props: currentAvatarUrl (string), onUpload (callback with File), isLoading (boolean). Shows a progress indicator while uploading. Validates file type (image/*) and size (max 5MB) on the client before sending.

4. SocialLinksForm — A form section with input fields for Twitter, Instagram, LinkedIn, and YouTube URLs. Takes props: socialLinks (SocialLinks type), onChange (callback with updated socialLinks). Validates URL format on blur. Shows error message if invalid.

5. PrivacyToggle — A toggle switch with a label and explanation text. Takes props: label (string), description (string), checked (boolean), onChange (callback with boolean). Used for emailPublic, phonePublic, and isPublic toggles.

6. AuditLogViewer — A collapsible section showing recent profile changes. Displays a table with columns: Date, Action, Changed Fields, Old Value, New Value. Takes props: auditLogs (array of auditLog objects), isLoading (boolean). Shows 'No changes yet' if empty. Formats dates and action names for readability.
