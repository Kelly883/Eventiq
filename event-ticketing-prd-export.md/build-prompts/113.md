We need to define the routes for the three event pages so users can navigate between them.

Using react-router, add these routes to your router configuration:

1. /organizer/events — OrganizerEventListPage
This is the main dashboard for organizers. It should be a protected route (only accessible to authenticated users with the 'organizer' role). This page displays all events created by the authenticated user, with tabs for 'Upcoming', 'Past', and 'Drafts'.

2. /organizer/events/create — EventCreatePage
A protected route for creating a new event. This page renders the EventForm component in create mode (isEditMode={false}). After successfully creating an event, redirect to /organizer/events.

3. /organizer/events/:eventId/edit — EventEditPage
A protected route for editing an existing event. The :eventId parameter is extracted from the URL and used to fetch the event data. This page renders the EventForm component in edit mode (isEditMode={true}) with the event's data pre-filled. After successfully updating, redirect to /organizer/events.

All three routes should be protected by a PrivateRoute or similar guard that checks if the user is authenticated and has the 'organizer' role. If not authenticated, redirect to the login page. If authenticated but not an organizer, show an 'Access Denied' page.

The routes should be nested under a /organizer path to keep organizer-specific pages grouped together.

Example route structure:
```
/organizer
  /events (OrganizerEventListPage)
    /create (EventCreatePage)
    /:eventId/edit (EventEditPage)
```
