We need to set up the frontend libraries that will power data fetching and QR code generation.

On the frontend, install TanStack Query (React Query) for managing server state — this will handle fetching tickets, dashboard data, and preferences with built-in caching, background refetching, and error handling. Install qrcode.react for rendering scannable QR codes on the TicketDetailPage. Install axios for HTTP requests to the Laravel backend (or use fetch if you prefer, but axios is cleaner for intercepting auth tokens).

Set up a React Query client at src/lib/queryClient.ts with default options: staleTime of 30 seconds (matches our real-time update requirement), cacheTime of 5 minutes, and retry logic that backs off exponentially. Create an axios instance at src/lib/api.ts that automatically includes the Authorization header with the bearer token from localStorage or your auth context.

On the Laravel backend, make sure you have Laravel Eloquent set up (it comes by default). Install laravel/sanctum if you haven't already for bearer token authentication. Create a middleware that validates the bearer token on protected routes.
