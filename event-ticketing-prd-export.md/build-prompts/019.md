We're building a push notifications system for the app. This includes user-facing settings and admin template management.

On the frontend (React + Vite), create a push-notifications feature folder at src/features/push-notifications/ with these subfolders:
- components (for PushNotificationSettingsSection and AdminPushTemplateManagementPage)
- hooks (for managing notification preferences and template state)
- services (for API calls to the backend)
- types (for TypeScript interfaces)
- utils (for notification helpers like permission requests)

On the backend (Laravel), create a new feature module at app/Features/PushNotifications/ with these folders:
- Models (PushNotificationDevice, PushNotificationTemplate, DeliveryPreferences)
- Controllers (DeviceTokenController, AdminPushTemplateController)
- Requests (FormRequest validation classes)
- Jobs (for queued notification sending)
- Policies (for authorization)
- Routes (feature-specific routes)

This keeps the push notification logic isolated and maintainable as the feature grows.
