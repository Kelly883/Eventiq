We need five reusable React components that will be shared across the checkout pages.

1. OrderSummary component — Displays the order summary (subtotal, fees, total). Takes props: items (array of OrderItems), subtotal (number), fees (number), total (number), currency (string). Shows a clean breakdown with each line item's name, quantity, and price. Displays the total prominently. Used on CheckoutPage and OrderConfirmationPage.

2. PaymentForm component — Wraps Stripe's CardElement (or PayPal's payment form) and handles payment submission. Takes props: clientSecret (string), onSuccess (callback), onError (callback), isLoading (boolean). Renders the payment provider's UI element styled to match the site theme. Handles the payment confirmation flow (e.g., stripe.confirmCardPayment). Shows loading state on the submit button. Used on CheckoutPage.

3. TicketCard component — Displays a single ticket. Takes props: ticket (Ticket object), event (Event object), ticketTier (TicketTier object). Shows the event name, date, venue, ticket tier, and QR code. Includes buttons to download as PDF and add to mobile wallet (if supported). Used on UserTicketsPage.

4. QRCodeDisplay component — Renders a QR code from qr_code_data. Takes props: data (string), size (number, default 200). Uses the qrcode.react library to render the QR code as an image. Used inside TicketCard.

5. CartItemRow component — Displays a single item in the cart. Takes props: item (cart item with ticket tier and event info), quantity (number), onQuantityChange (callback), onRemove (callback). Shows the ticket tier name, event, quantity with +/- buttons, price per ticket, and line total. Includes a remove button. Used on CartPage.
