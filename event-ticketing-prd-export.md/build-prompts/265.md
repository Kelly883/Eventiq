Now we need to connect the payout and settlement pages to the rest of the app so users can access them.

Add routes using React Router:
- /organizer/payouts → OrganizerPayoutDashboardPage (organizer-only)
- /admin/settlements/dashboard → AdminSettlementDashboardPage (admin-only)

Create a route guard that checks the user's role before allowing access. If an organizer tries to access /admin/settlements/dashboard, redirect to /organizer/payouts with a 'Access Denied' toast. If an admin tries to access /organizer/payouts, redirect to /admin/settlements/dashboard.

Add navigation links:
- In the organizer sidebar or main navigation, add a 'Payouts' link that goes to /organizer/payouts
- In the admin sidebar or main navigation, add a 'Settlements' link that goes to /admin/settlements/dashboard

Wire up these connections:
- When a user clicks 'Download Statement' on the organizer page, trigger a PDF export that includes all payouts in the current filtered view
- When a user clicks 'Export Settlement Report' on the admin page, trigger a CSV export that includes all settlements in the current filtered view
- When an admin clicks 'Approve' or 'Reject' on a settlement, show a confirmation dialog before executing the action
- When an admin clicks 'Manual Payout Trigger', show a modal form to select the organizer and confirm the manual payout
- When a payout or settlement action succeeds, show a success toast with the action details (e.g., 'Payout approved for $5,000')
- When a payout or settlement action fails, show an error toast with the failure reason
- Deep links to /organizer/payouts/:payoutId or /admin/settlements/:settlementId should load that specific payout/settlement and expand its details

Make sure the route guards also handle the case where the user's session expires (401 error) — redirect to login and then back to the payout/settlement page after they log in again.
