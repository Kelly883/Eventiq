Now we need to connect the admin pages to the rest of the app's routing and navigation.

**Routing Setup** — Add four new routes to your React Router config:
- `/admin/dashboard` → AdminDashboardPage
- `/admin/users` → AdminUserManagementPage
- `/admin/events` → AdminEventModerationPage
- `/admin/payments` → AdminPaymentReconciliationPage

Wrap all four routes with an admin-only guard: check that the user has the 'Admin' role. If not, redirect to the home page with a 'Access Denied' toast. If the user is not authenticated (no token), redirect to the login page.

**Navigation Integration** — Add an 'Admin' link to the main app navigation (top nav bar or sidebar) that only shows for admin users. Clicking it should navigate to `/admin/dashboard`. From the dashboard, the six navigation tiles should link to the other three pages: clicking 'User Management' goes to `/admin/users`, 'Event Moderation' goes to `/admin/events`, 'Payment Reconciliation' goes to `/admin/payments', etc.

**Cross-Page Navigation** — From AdminUserManagementPage, when an admin clicks 'View Profile' on a user row, navigate to a user detail page (if one exists) or open a modal with the user's full profile. Similarly, from AdminEventModerationPage, clicking 'View Event' should navigate to the event detail page or open a modal. From AdminPaymentReconciliationPage, clicking 'View Order' should navigate to the order detail page.

**Action Confirmations** — When an admin performs a destructive action (suspend user, flag event, refund payment), show a confirmation dialog before executing. The dialog should show what will happen and ask for a reason (for audit logging). On confirm, execute the mutation. On cancel, close the dialog.

**Success/Error Notifications** — After mutations (suspend, approve, refund, etc.), show a toast notification: success shows 'User suspended' or 'Payment refunded', error shows the error message from the backend. Errors should include a 'Retry' button if appropriate.

**Deep Linking** — Support deep links to specific admin pages: `/admin/dashboard?period=7d`, `/admin/users?role=organizer&status=suspended`, `/admin/events?status=flagged`, `/admin/payments?status=failed`. Parse these query params and apply filters/settings on page load.

**Back Navigation** — Ensure back buttons work correctly. From a detail page or modal, back should return to the list page with the same filters/sort/pagination state intact. Use browser history or React Router's navigate(-1).

**Session Expiration** — If the user's auth token expires while they're on an admin page, the next API call will return 401. Catch this globally and redirect to the login page with a 'Session expired' toast. After login, redirect back to the admin page they were on.
