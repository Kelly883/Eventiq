We need to add three routes to the React Router configuration for the organizer profile feature:

1. /organizer/:organizerId — OrganizerPublicProfilePage (public route, no auth required). This displays a public organizer's profile with their events. The :organizerId parameter is a UUID that gets passed to the page via useParams().

2. /organizer/profile/edit — OrganizerProfileEditPage (protected route, requires Organizer role). This is the form for editing the organizer's own profile. Only the organizer can access this page. If not authenticated, redirect to /login. If authenticated but not an organizer, show an access denied message.

3. /organizer/profile/settings — OrganizerProfileSettingsPage (protected route, requires Organizer role). This is the settings page for profile management, notification preferences, and profile deletion. Same auth requirements as the edit page.

Add these routes to your React Router configuration (likely in src/App.tsx or src/router.tsx). Use React Router's <Route> component with path and element props. For protected routes, wrap them with a ProtectedRoute component that checks authentication and role.

Also add a navigation link in the app's main navigation or user menu that goes to /organizer/profile/edit for authenticated organizers.
