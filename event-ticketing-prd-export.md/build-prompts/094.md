We need to create the data models that represent fraud events in both the backend and frontend.

On the backend (Laravel), create an Eloquent model at app/Features/Fraud/Models/FraudEvent.php:
- Map to the fraud_events table
- Cast JSON columns (fraud_factors, payment_details, velocity_metrics, device_info, duplicate_ticket_info) to arrays
- Cast risk_score to decimal
- Define relationships: belongsTo Order, belongsTo User, belongsTo ReviewedByUser (polymorphic for the admin who reviewed)
- Add accessor methods: getRiskLevelBadgeColor() (returns 'green', 'amber', 'red'), getFormattedRiskScore(), getReadableEventType()
- Add scope methods: flagged(), reviewed(), approved(), rejected(), autoBlocked(), highRisk(), mediumRisk(), lowRisk(), createdInDateRange($start, $end)
- Implement SoftDeletes trait for soft deletion
- Add fillable properties for mass assignment

On the frontend (React), create TypeScript types at src/features/fraud/types/fraud.ts:
- FraudEvent interface with all fields from the database (id, orderId, userId, eventType, riskScore, riskLevel, detectionMethod, fraudFactors, paymentDetails, velocityMetrics, deviceInfo, duplicateTicketInfo, status, reviewedBy, reviewNotes, reviewedAt, createdAt, updatedAt)
- FraudFactors interface (duplicateTicketDetected, velocityCheckFailed, paymentPatternSuspicious, deviceFingerprintMismatch, geolocationAnomaly, cardTestingPattern, highRiskPaymentMethod)
- PaymentDetails interface (cardLast4, issuer, country, cardFingerprint)
- VelocityMetrics interface (ordersIn24h, totalSpendIn24h, averageOrderValue, ordersInLastHour)
- DeviceInfo interface (ipAddress, userAgent, deviceFingerprint, country, city)
- DuplicateTicketInfo interface (matchingTicketIds, matchingQRCodes, matchingEventIds)
- RiskLevel type ('low' | 'medium' | 'high')
- EventType type (union of all event types)
- DetectionMethod type (union of all detection methods)
- FraudEventStatus type ('flagged' | 'reviewed' | 'approved' | 'rejected' | 'auto_blocked')

Add utility functions in src/features/fraud/utils/fraudFormatters.ts:
- formatRiskScore(score: number): string (e.g., '85.50')
- getRiskLevelColor(level: RiskLevel): string (returns CSS color class)
- getEventTypeLabel(type: EventType): string (human-readable event type)
- getDetectionMethodLabel(method: DetectionMethod): string
- formatCurrency(amount: number, currency: string): string
