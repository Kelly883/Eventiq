We need to set up the libraries and authentication infrastructure for the admin panel.

Frontend setup:
1. Install React Router (already likely present, but ensure it's available). Install TanStack Query (React Query) for server state management — this handles data fetching, caching, and real-time updates for the dashboard metrics, user lists, event tables, and payment data.
2. Install React Table (TanStack Table) for building the complex data tables with sorting, filtering, and expandable rows used in AdminUserManagementPage, AdminEventModerationPage, and AdminPaymentReconciliationPage.
3. Create an API client at src/lib/apiClient.ts that wraps fetch with automatic bearer token injection from localStorage. This client should handle 401 responses by redirecting to login.
4. Create an auth context at src/contexts/AuthContext.tsx that exposes the current user and a checkAdminAccess() function. This function checks if the user has the 'Admin' role.

Backend setup (Laravel):
1. Ensure Laravel's built-in authentication is configured (API token or Sanctum for bearer tokens).
2. Create an AdminPolicy at app/Policies/AdminPolicy.php with methods: viewDashboard(), manageUsers(), moderateEvents(), reconcilePayments(). Each checks if the authenticated user has the 'Admin' role.
3. Create a middleware at app/Http/Middleware/AdminOnly.php that checks the user's role and returns 403 if not admin.
4. Register the middleware in app/Http/Kernel.php so it can be applied to admin routes.
5. Set up rate limiting in config/rate-limit.php: 20/min for read operations, 5/min for write operations on admin endpoints.
