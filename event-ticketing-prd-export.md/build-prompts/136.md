We need to build four API endpoints for the authentication system in Laravel. All endpoints should be in app/Http/Controllers/AuthController.php and registered in routes/api.php.

1. POST /api/auth/login — Takes email and password. Validate the input format (email must be valid, password required). Query the users table by email. If not found, return 401 with message 'Invalid email or password' (don't reveal which field is wrong). If found, use Hash::check() for constant-time password comparison. If password doesn't match, return 401 with the same message. If password matches, create a new Session record with a 7-day expiry, update user.lastLoginAt to now, and return 200 with { token, user: { id, email, name, role } }. Implement rate limiting: 5 attempts per 15 minutes per IP (use Laravel's throttle middleware). Return 429 if rate limited.

2. POST /api/auth/register — Takes email, password, and name. Validate: email must be valid format, password minimum 8 characters, name minimum 2 characters. Check if email already exists in users table. If yes, return 409 with 'This email is already registered'. If no, hash the password with bcrypt (cost 12), create a new User with role='attendee' by default, and return 201 with { id, email, name, role } (no token — user must login). Do NOT return the password hash.

3. POST /api/auth/forgot-password — Takes email. Validate email format. Query users table by email. If found, generate a random token (use Str::random(64)), hash it with bcrypt, create a PasswordResetToken record with 1-hour expiry, and send a password reset email with the plain token in a link like /reset-password?token=... (or just log it for development). Always return 200 with { message: 'If an account exists, a reset link has been sent' } regardless of whether the email was found (prevents email enumeration). Implement rate limiting: 3 requests per hour per IP. Return 429 if rate limited.

4. POST /api/auth/reset-password — Takes token and newPassword. Validate: token required, newPassword minimum 8 characters. Query passwordResetTokens by hashed token (you'll need to hash the incoming token to compare). Check the token is not expired (expiresAt > now) and not already used (usedAt is null). If invalid, return 400 with 'This link has expired or is invalid'. If valid, find the associated user, hash the new password with bcrypt (cost 12), update user.passwordHash, set token.usedAt to now, call user.invalidateAllSessions() to revoke all existing sessions, and return 200 with { message: 'Password reset successfully' }.

All endpoints should validate input and return appropriate error codes (400 for validation, 401 for auth, 409 for conflict, 429 for rate limit, 500 for server error). Use Laravel's validation rules and exception handling.
