We need a few libraries to handle API communication and form management on the frontend.

On the React side, install axios for HTTP requests (or use fetch if you prefer, but axios handles interceptors better for auth). Also install react-hook-form for managing the pricing window form state — it's lightweight and works well with validation. Install zod for client-side validation schemas that match the backend rules.

On the Laravel side, make sure you have the standard Laravel packages: laravel/framework (already included), and ensure you're using Laravel's built-in validation and policy system. No extra packages needed — we'll use Laravel's native FormRequest and Policy classes.

Set up an axios instance in src/features/pricing/services/api.ts that automatically includes the bearer token from localStorage in all requests. This instance will be used by all pricing API calls. The token should be stored when the user logs in and cleared on logout.
