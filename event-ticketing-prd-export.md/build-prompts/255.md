Now we need to connect the dashboard to the rest of the app and set up the real-time auto-refresh behavior.

Add a route for /dashboard that renders OrganizerDashboardPage. This route should be protected — only users with the 'Organizer' role can access it. If a non-organizer tries to access it, redirect to a 'Not Authorized' page or home.

Add navigation links to the dashboard from the main app navigation (header or sidebar). If the app has a navigation menu, add a 'Dashboard' link that goes to /dashboard.

Wire up the quick-action buttons on event cards:
- 'Edit Event' button should navigate to /organizer/events/:eventId/edit
- 'View Analytics' button should navigate to /organizer/events/:eventId/analytics
- 'Manage Inventory' button should navigate to /organizer/events/:eventId/inventory

Wire up the EventDetailWidget action buttons:
- 'View Full Analytics' navigates to /organizer/events/:eventId/analytics
- 'Manage Inventory' navigates to /organizer/events/:eventId/inventory
- 'Edit Event' navigates to /organizer/events/:eventId/edit

Wire up the 'Create New Event' button to navigate to /organizer/events/create.

For the auto-refresh behavior, use the useAutoRefreshActivityFeed() hook in OrganizerDashboardPage. This should refetch the activity feed every 30 seconds when autoRefreshEnabled is true. Also, set up a separate interval to refetch the overview metrics every 30 seconds when auto-refresh is enabled. Show the live indicator badge with a pulse animation when auto-refresh is active.

When a user clicks 'Export Activity' in SalesActivityFeed, generate a CSV file with columns: Event Name, Tier Name, Quantity, Unit Price, Total Amount, Sale Timestamp, Buyer Email. Use a library like papaparse or a simple CSV formatter. Trigger a download with the filename 'activity-export-{timestamp}.csv'.

Set up deep linking: if a user navigates directly to /dashboard?eventId=xyz, the dashboard should load and automatically expand EventDetailWidget for that event.

When the user's auth token expires (401 error), redirect to the login page with a 'Session expired' toast notification.
