# Step 115 of 345: Set up routing for pricing pages

We need to add routes for the two pricing pages to the React router.

Add these routes:
- /organizer/events/:eventId/pricing → EventPricingConfigPage (the main pricing configuration page)
- /organizer/events/:eventId/pricing/preview → PricingPreviewModal (shown as a modal overlay, not a separate page)

The EventPricingConfigPage should be accessible from the event detail page or event settings. Add a 'Pricing' tab or link in the event management area that navigates to /organizer/events/:eventId/pricing.

The PricingPreviewModal is triggered from EventPricingConfigPage via a 'Preview' button — it doesn't need its own route, but can be accessed via route if needed for deep linking. When the modal closes, return to the pricing config page.

Both pages require authentication (check that user is logged in) and event ownership (check that user owns the event). If not authenticated, redirect to login. If not authorized, show 'Access Denied' message.

Use react-router's useParams hook to extract eventId from the URL. Pass it to the pages so they can fetch the correct event's pricing data.
