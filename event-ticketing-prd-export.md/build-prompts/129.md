We need to add routes for the two payout dashboards to the React Router configuration.

Add these routes to your router configuration (typically in src/router.tsx or src/App.tsx):

1. /organizer/payouts — OrganizerPayoutDashboardPage. This is the organizer-facing dashboard. Requires the user to be authenticated and have the 'organizer' role. If not, redirect to /login with a 'Session expired' toast.

2. /admin/settlements/dashboard — AdminSettlementDashboardPage. This is the admin-only dashboard. Requires the user to be authenticated and have the 'admin' role. If not, redirect to /login with 'Access Denied — only admins can view settlements' message.

Both routes should be protected by a PrivateRoute or ProtectedRoute wrapper that checks authentication and role. If the user's session expires (401 response from API), redirect to /login and show a 'Session expired' toast.

Add navigation links:
- In the organizer sidebar/menu, add a link to /organizer/payouts labeled 'Payouts' or 'Revenue'
- In the admin sidebar/menu, add a link to /admin/settlements/dashboard labeled 'Settlements' or 'Revenue Management'

Use React Router's useNavigate() hook to handle redirects after login. Use TanStack Query's useQuery hook to fetch payout data and cache it so navigating back to the dashboard doesn't refetch.
