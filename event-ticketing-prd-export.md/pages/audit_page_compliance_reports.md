## Description

FUNCTIONALITY: Admin-only compliance reporting dashboard generating pre-built and custom audit reports for regulatory requirements (GDPR, PCI-DSS, SOX). Pre-built report templates include: Data Access Report (who accessed what data when), User Activity Report (login/logout/permission changes), Payment Audit Trail (all payment transactions with fraud flags), Refund Audit Trail (all refunds with approval chain), Data Retention Report (what data is stored and for how long), and Incident Report (failed transactions, fraud events, system errors). Each report shows date range selector, data classification filter (public/internal/sensitive/pci), and export format options (PDF, CSV, JSON). Report generation shows progress indicator and estimated completion time. Generated reports display in a preview pane with summary statistics and detailed data table. Reports can be scheduled for automatic generation (daily/weekly/monthly) and emailed to compliance team. Audit trail shows who generated each report and when. Search and filter generated reports by type, date range, or recipient. Delete old reports with confirmation. Compliance checklist shows status of key compliance requirements (data retention, access logging, encryption, etc.) with green/amber/red indicators.
