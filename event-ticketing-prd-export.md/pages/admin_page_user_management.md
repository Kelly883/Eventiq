## Description

FUNCTIONALITY: Admin interface for managing platform users (organizers and attendees). Displays paginated table of all users with columns: user ID, email, name, role (organizer/attendee), account status (active/suspended/pending), registration date, last login date, and action buttons. Color-coded role badges (blue=organizer, gray=attendee). Status badges (green=active, amber=pending, red=suspended). Bulk actions to suspend/unsuspend multiple users at once. Expandable row details show user profile info, account history, associated events (for organizers), ticket purchases (for attendees), and audit trail of admin actions on this user. Filters by role, status, registration date range, or last login date range. Search by email or user ID. Sort by any column. Real-time updates every 60 seconds showing user status changes. Action buttons: 'View Profile', 'Suspend Account', 'Unsuspend Account', 'Reset Password', 'Send Message', 'View Audit Trail'. For suspended users, shows suspension reason and date. Bulk suspend/unsuspend with reason field. Export user list as CSV.
DESIGN APPROACH: Dense scannable layout for power users. Summary card at top showing total users, active users, suspended users, pending approvals. Data table below with sortable columns (user ID, email, name, role, status, registered, last login). Expandable rows show full user details without leaving page. Sticky filter bar with role, status, date range, search filters. Mobile: stacked cards instead of table, collapsible details.
STATES: Loading shows skeleton metric card and placeholder table rows with shimmer. Empty state (no users) shows 'No users found' with illustration. Error 401 redirects to login. Error 403 shows 'Access Denied — only admins'. Error 500 shows error banner with retry. Success displays full user table with live-updating status badges and action buttons.
SECURITY: Admin-only (requires 'Admin' role via Policy). Auth required (bearer token). Rate limit 20/min per user for read operations, 5/min for write operations (suspensions, resets). All user management actions logged to auditLogs with admin ID and timestamp. Sensitive user data (email, phone) masked in exports.
