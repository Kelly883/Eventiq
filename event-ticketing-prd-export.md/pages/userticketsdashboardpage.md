## Description

FUNCTIONALITY: Displays all purchased tickets grouped by event in chronological order (upcoming first, then past). Each event section shows event title, date, venue, and a list of individual tickets purchased. Each ticket card displays: ticket tier name, QR code (scannable), unique ticket ID, delivery status badge (sent/pending/failed with color coding), and action buttons: 'Download PDF', 'Resend Ticket', 'View Details' (links to /my-tickets/:ticketId/status), 'Add to Wallet' (if supported). Filters allow viewing by event status (all/upcoming/past) and date range. Search by event title or ticket ID. Real-time delivery status updates every 30 seconds showing if tickets have been sent/viewed. For failed deliveries, shows inline error message with 'Resend' CTA. Empty state shows 'No tickets yet' with 'Browse Events' button linking to /events.
DESIGN APPROACH: Vertical scrollable layout with event sections as collapsible cards. Each event shows ticket count and total value. Tickets within event displayed as horizontal cards with QR code on left, details in middle, actions on right. Delivery status badge color-coded (green=sent, amber=pending, red=failed). Mobile: stacked single-column with full-width ticket cards and collapsible event sections. Sticky header with filter/search bar.
STATES: Loading shows skeleton event cards (3 events) with shimmer ticket placeholders. Empty state shows illustration with 'No tickets purchased yet' and 'Browse Events' CTA button. Error 401 redirects to login with 'Sign in to view your tickets' toast. Error 403 shows 'Access Denied' with back button. Error 500 shows error banner with retry button. Success displays all tickets grouped by event with live-updating delivery status badges.
SECURITY: Authenticated users only (requires bearer token). Users can only view their own tickets (enforced by Policy). Rate limit 20/min per user for read operations to prevent abuse.
