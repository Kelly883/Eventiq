## Description

FUNCTIONALITY: Organizer-only form to create and edit their public profile. Sections: Avatar upload (circular crop, drag-drop or file picker), display name field, bio textarea (max 500 chars with counter), contact info fields (email, phone, website URL), social media links (Twitter, Instagram, LinkedIn, YouTube URLs), branding customization (primary color picker, accent color picker with live preview), privacy toggles (show email, show phone, show contact form). Form has 'Save' button with loading state and 'Cancel' button. On save, shows 'Profile updated' toast and redirects to public profile view. Unsaved changes warning on page exit.
DESIGN APPROACH: Vertical form layout with grouped sections (Basic Info, Contact, Branding, Privacy). Avatar upload at top with preview. Color pickers show live preview of header background. Privacy toggles clearly labeled with explanations. Form validation on blur with inline error messages. Save button sticky at bottom on mobile.
STATES: Loading on mount shows skeleton form fields. Saving shows spinner on button, fields disabled. Avatar uploading shows progress indicator. Validation error highlights field with red border and error message below. Success shows 'Profile updated' toast and redirects. Error 401 redirects to login. Error 403 shows 'Access Denied'. Error 500 shows error banner with retry.
SECURITY: Organizer-only (requires 'Organizer' role via Policy). Auth required. Rate limit 5 updates/min per user to prevent spam. Avatar upload validated server-side (file type, size). All changes logged to auditLogs.
