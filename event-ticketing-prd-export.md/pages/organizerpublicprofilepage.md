## Description

FUNCTIONALITY: Public-facing organizer profile displaying customizable branding elements. Shows organizer avatar (circular image), display name, bio/description, contact information (email, phone, website), social media links (Twitter, Instagram, LinkedIn), and a curated list of upcoming and past events organized by this user. Profile includes a 'Follow' button (if attendee viewing) or edit controls (if profile owner). Events section shows event cards with thumbnail, title, date, ticket availability status. Search and filter events by category or date range. Share profile button generates shareable link. Contact organizer button opens a contact form modal.
DESIGN APPROACH: Hero section at top with organizer avatar, name, and bio. Branding colors customizable by organizer (primary color, accent color) applied to header background and buttons. Two-column layout on desktop (profile info left, events right), stacked on mobile. Event cards use consistent grid layout. Minimal visual hierarchy — profile info prominent, events secondary.
STATES: Loading shows skeleton profile card with placeholder avatar and shimmer event cards. Empty state (no events) shows 'No events yet' with illustration. Error 401 redirects to login. Error 403 shows 'Access Denied' (shouldn't happen on public profile). Error 404 shows 'Organizer not found' with back button. Error 500 shows error banner with retry. Success displays full profile with all events.
SECURITY: Public page (no auth required). Rate limit 20/min per IP to prevent scraping. Sensitive contact info (phone, email) only shown if organizer has made it public in settings.
