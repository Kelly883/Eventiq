## Description

FUNCTIONALITY: An admin-only interface for managing all transactional and promotional email templates. The page displays a list of existing templates (e.g., 'Order Confirmation', 'Event Reminder') with their type and status (active/inactive). Admins can create new templates, edit existing ones, or delete them. The core feature is a rich-text editor (e.g., TipTap or TinyMCE with an MJML plugin) for crafting responsive HTML emails. A sidebar shows available placeholder variables (like {{user.name}}, {{event.title}}) that can be inserted. A 'Send Test Email' button allows admins to send a preview to a specified email address to verify rendering. Changes are saved via PATCH requests.
DESIGN APPROACH: A two-column layout. The left column lists all email templates. The main content area on the right contains the template editor form. The form includes fields for template name, subject, and the rich-text editor. A separate tab or section shows the list of available variables for the selected template type. The 'Send Test' action opens a small modal to input the recipient's email.
STATES: Loading: Skeleton list items and a disabled editor form. Empty: An illustration with 'No email templates created yet' and a 'Create Template' CTA. Saving: Spinner on the 'Save' button, form disabled. Error 401: Redirect to login modal. Error 403: 'Access Denied' page. Error 500: Error banner with retry button.
SECURITY: Protected route for users with the 'Admin' role, enforced by a Laravel Policy. All template content is sanitized on the backend before saving to prevent XSS.
