## Description

FUNCTIONALITY: Organizer settings page for profile management and preferences. Sections: Profile visibility toggle (public/private), email notification preferences (new ticket sales, event reminders, platform updates), profile deletion warning with confirmation button. Shows current profile status (active/inactive), member since date, total events created, total tickets sold (read-only stats). Link to edit profile form. Link to view public profile. Audit log section showing recent profile changes (who changed what, when) for organizers with admin role.
DESIGN APPROACH: Settings-style layout with toggle switches and checkboxes. Stats displayed as cards at top. Destructive actions (delete profile) in red section at bottom with clear warning. Audit log as collapsible section. Mobile-friendly with full-width toggles.
STATES: Loading shows skeleton stat cards and toggle placeholders. Empty state (no audit log) shows 'No changes yet'. Error 401 redirects to login. Error 403 shows 'Access Denied'. Error 500 shows error banner. Success shows updated toggles and confirmation toasts.
SECURITY: Organizer-only. Auth required. Profile deletion requires email confirmation. Changes logged to auditLogs. Rate limit 10 setting changes/min per user.
