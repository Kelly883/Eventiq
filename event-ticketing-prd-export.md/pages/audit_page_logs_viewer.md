## Description

FUNCTIONALITY: Admin-only real-time audit log viewer displaying all system transactions, user actions, and data modifications with full compliance context. Dense scannable table lists audit events with columns: timestamp, action type (user_login, event_created, payment_processed, refund_approved, etc.), actor (admin/system/user ID), target type (user/event/order/payout), target ID, status (success/failed), and metadata summary. Color-coded action badges (blue=user action, green=system action, orange=admin action, red=error). Expandable row details show full event context: request/response data, IP address, user agent, geolocation, affected data fields (before/after for updates), and compliance classification (PCI-DSS, GDPR, SOX). Filters by date range, action type, actor role, target type, status, or compliance classification. Search by target ID, actor email, or action description. Sort by timestamp, action type, or status. Real-time updates every 30 seconds showing new events. Export filtered audit log as CSV or JSON for external compliance audits. Retention policy indicator shows how long logs will be retained based on admin settings. Bulk actions to tag events for compliance review or mark as reviewed.
