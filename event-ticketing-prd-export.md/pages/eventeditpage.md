## Description

FUNCTIONALITY: Identical to the EventCreatePage but for editing an existing event. The `eventId` is extracted from the URL. On page load, it fetches the event data and pre-fills all form fields, including the event details, venue, and existing ticket tiers. The banner image upload component shows a preview of the current banner and allows replacement. The actions are 'Save Changes' and potentially 'Archive Event'.
DESIGN APPROACH: Reuses the exact same form component as EventCreatePage, passed an `isEditMode` prop and initial data. This ensures consistency and reduces code duplication. The page title dynamically includes the event name, e.g., 'Editing: My Awesome Concert'.
STATES: Loading state shows skeleton versions of the form sections while data is fetched. Success shows the fully populated form. 'Saving' state disables the form and shows a spinner on the 'Save Changes' button. Error 404 (if event not found or not owned by user) shows a 'Not Found' page. Error 401/403 are handled as usual.
SECURITY: Protected route for organizers. The backend Policy ensures the user can only edit events they own.
