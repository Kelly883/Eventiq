## Description

FUNCTIONALITY: Displays a summary of the successfully completed order. It fetches order details using the `orderId` from the URL via the `/api/orders/:orderId` endpoint. It shows a prominent 'Thank You' message, the order ID, a breakdown of items purchased, total amount paid, and payment method used. It provides clear next steps, such as 'Your tickets have been sent to your email' and a button to 'View My Tickets' which navigates to `/my-tickets`.
DESIGN APPROACH: A clean, centered confirmation message layout. An icon (like a checkmark) provides quick visual feedback. The order summary is presented in a clear, receipt-like format. The primary call-to-action is to view the purchased tickets.
STATES: Loading: A skeleton layout of the confirmation details. Success: Displays the full order summary and thank you message. Error 401: Redirects to login. Error 403: Shows 'You do not have permission to view this order'. Error 404: Shows 'Order not found' with a link back to the user's main dashboard.
SECURITY: Requires authentication. The backend Policy ensures a user can only view their own order confirmation.
