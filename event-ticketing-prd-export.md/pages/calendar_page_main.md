## Description

FUNCTIONALITY: Visual calendar interface displaying published events by date. Month view shows event count per day with color-coded indicators (green=available, amber=low stock, red=sold out). Click a date to see all events for that day in a sidebar or modal. Filter sidebar with category dropdown, price range slider (min/max), and location search. Search bar with autocomplete for event titles. Sort options: date, price, popularity. Real-time inventory updates every 30 seconds showing ticket availability changes. Week and day view toggles for granular scheduling. Clicking an event navigates to /events/:eventId for full details. 'Create Event' button visible only to authenticated organizers (routes to /organizer/events/create).
DESIGN APPROACH: Calendar grid centered with month/week/day view toggles at top. Filter sidebar sticky on desktop (left), collapsible drawer on mobile. Search bar above calendar. Event indicators on calendar dates use color coding (green/amber/red) for quick visual scanning. Clicking a date shows event list in right sidebar on desktop, modal on mobile. Event cards in sidebar show thumbnail, title, organizer, date/time, price, availability status. Organizer branding colors applied to event cards.
STATES: Loading shows skeleton calendar grid with shimmer effect while fetching events. Empty state (no events in selected date range/filters) shows 'No events found' with 'Clear filters' button. Error 401 redirects to login modal. Error 500 shows error banner with retry button. Success displays full calendar with color-coded event indicators and live-updating availability.
SECURITY: Public page (no auth required). Rate limit 30/min per IP to prevent scraping. Only displays published events. Sensitive organizer data filtered based on privacy settings.
