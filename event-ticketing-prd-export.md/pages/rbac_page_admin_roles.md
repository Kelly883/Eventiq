## Description

FUNCTIONALITY: Admin-only dashboard for managing user roles and permissions. Displays a table of all users with their current role (Admin, Organizer, Attendee, Support Staff) and permission status. Bulk actions to assign/revoke roles — select multiple users, choose role from dropdown, apply. Individual user cards show detailed permissions breakdown (can_create_events, can_manage_tickets, can_access_analytics, etc.) with toggle switches to grant/revoke specific permissions. Search and filter by role, email, or permission status. Audit log section at bottom shows recent role changes with timestamp, who made the change, and what changed. Inline role change confirmation with reason field (optional) before applying.
DESIGN APPROACH: Dense scannable layout for power users — table view with sortable columns, bulk selection checkboxes, inline actions. Expandable rows show permission details without leaving the page. Filter bar always visible at top. Audit log as collapsible section below. Color-coded role badges (Admin=red, Organizer=blue, Attendee=green, Support=orange) for quick visual scanning.
STATES: Loading shows skeleton table with 5 placeholder rows. Empty state shows 'No users found' with search reset button. Error 401 redirects to login with 'Session expired' toast. Error 403 shows 'Access Denied — only admins can manage roles' with back button. Error 500 shows error banner with retry button. Success shows 'Role updated for X users' toast and refreshes table.
SECURITY: Admin-only page enforced by Policy. All role changes logged with admin ID and timestamp. Rate limit 10/min per admin to prevent abuse. Changes require confirmation to prevent accidental bulk updates.
