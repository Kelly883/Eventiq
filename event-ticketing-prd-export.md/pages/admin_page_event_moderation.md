## Description

FUNCTIONALITY: Admin interface for moderating events across the platform. Displays paginated table of all events with columns: event ID, title, organizer name, status (published/draft/cancelled/flagged), attendee count, ticket sales, revenue, creation date, and action buttons. Color-coded status badges (green=published, gray=draft, red=cancelled, orange=flagged). Flagged events highlighted with warning icon. Expandable row details show full event info (description, venue, dates, ticket tiers, pricing windows), organizer details, sales breakdown by tier, attendee list, and moderation history (flags, approvals, rejections). Filters by status, organizer, date range, revenue range, or flagged status. Search by event title or organizer name. Sort by any column. Real-time updates every 60 seconds showing event status changes. Action buttons: 'View Event', 'Approve Event', 'Flag Event', 'Cancel Event', 'View Attendees', 'View Sales', 'View Moderation History'. For flagged events, shows flag reason and date. Bulk approve/flag/cancel with reason field. Export event list as CSV. Moderation notes field for documenting decisions.
DESIGN APPROACH: Dense scannable layout for power users. Summary card at top showing total events, published events, flagged events, total revenue. Data table below with sortable columns (event ID, title, organizer, status, attendees, revenue, created). Expandable rows show full event details without leaving page. Sticky filter bar with status, organizer, date range, revenue range, flagged filters. Mobile: stacked cards instead of table, collapsible details.
STATES: Loading shows skeleton metric card and placeholder table rows with shimmer. Empty state (no events) shows 'No events found' with illustration. Error 401 redirects to login. Error 403 shows 'Access Denied — only admins'. Error 500 shows error banner with retry. Success displays full event table with live-updating status badges and action buttons.
SECURITY: Admin-only (requires 'Admin' role via Policy). Auth required (bearer token). Rate limit 20/min per user for read operations, 5/min for write operations (approvals, flags, cancellations). All event moderation actions logged to auditLogs with admin ID and timestamp. Sensitive organizer data (email, phone) masked.
