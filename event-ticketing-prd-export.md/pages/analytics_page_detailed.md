## Description

FUNCTIONALITY: Deep-dive analytics page showing granular sales data and performance metrics. Displays a detailed table of all sales transactions (timestamp, ticket tier, price, buyer email if available) with sorting and filtering capabilities. Conversion funnel visualization showing event page views → ticket page views → purchases with drop-off rates at each stage. Cohort analysis showing repeat attendees vs. first-time buyers. Time-series data allowing drill-down by hour, day, or week. Pricing window performance comparison showing which pricing tiers drove the most revenue and had the highest conversion rates. Attendee acquisition channels (if tracked) showing which marketing channels drove sales. Export detailed analytics as CSV for external analysis.
DESIGN APPROACH: Two-column layout on desktop (filters/controls left, data/charts right). Sticky filter panel with date range, tier filter, pricing window filter. Main content area with tabbed sections (Transactions, Funnel, Cohorts, Pricing Performance, Channels). Transaction table uses virtualization for performance with large datasets. Charts use interactive tooltips for detailed data inspection. Mobile: stacked single-column with collapsible filter panel.
STATES: Loading shows skeleton table rows and placeholder charts. Empty state (no detailed data) shows 'No transaction data available'. Error 401 redirects to login. Error 403 shows 'Access Denied'. Error 404 shows 'Event not found'. Error 500 shows error banner with retry. Success displays full detailed analytics with all tabs and data.
SECURITY: Organizer-only (requires event ownership via Policy). Auth required. Rate limit 10/min per user for read operations. Sensitive buyer data (emails) only shown if organizer has permission.
