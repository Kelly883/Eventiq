## Description

FUNCTIONALITY: Real-time sales analytics dashboard for organizers to monitor ticket sales velocity, revenue trends, and conversion metrics. Displays summary cards showing total revenue, tickets sold, average ticket price, and conversion rate (tickets sold vs. page views). Interactive charts visualize sales velocity over time (line chart showing cumulative sales by hour/day), revenue by ticket tier (bar chart), and sales distribution across pricing windows (pie chart). Real-time event tracking via Mixpanel SDK logs ticket sales events with tier, price, and timestamp data. Filters allow viewing analytics by date range, ticket tier, or pricing window. Export analytics report as CSV or JSON. Demographic insights section shows attendee breakdown by ticket tier and geographic distribution (if available). Refresh button for manual data updates; auto-refresh every 30 seconds via polling.
DESIGN APPROACH: Dense scannable layout optimized for power users. Summary metric cards at top (revenue, tickets sold, conversion rate, avg price) with color-coded trend indicators (green=up, red=down). Charts arranged in a 2-column grid below metrics (sales velocity left, revenue by tier right). Demographic section as collapsible card at bottom. Sticky header with date range picker and tier filter. Mobile: stacked single-column with collapsible sections. Real-time indicator badge shows 'Live' with pulse animation when data updates.
STATES: Loading shows skeleton metric cards and placeholder charts with shimmer effect. Empty state (no sales yet) shows 'No sales data yet' with illustration and link to event page. Error 401 redirects to login with 'Session expired' toast. Error 403 shows 'Access Denied — only event organizers can view analytics' with back button. Error 404 shows 'Event not found' with link to events list. Error 500 shows error banner with retry button. Success displays full dashboard with live-updating metrics and charts.
SECURITY: Organizer-only (requires event ownership via Policy). Auth required (bearer token). Rate limit 20/min per user for read operations to prevent abuse. All analytics events logged server-side with timestamp and user ID.
