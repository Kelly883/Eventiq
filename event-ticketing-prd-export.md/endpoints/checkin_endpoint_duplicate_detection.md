# Checkin Endpoint Duplicate Detection

POST /api/venue/check-in/detect-duplicate

## Description

REQUEST: { eventId (string, required, UUID), qrCodeData (string, required - encrypted payload from QR scan), ticketId (string, optional - for manual entry fallback) }
PROCESS: 1. Verify auth token and extract userId 2. Check user has 'VenueStaff' or 'Organizer' role via Policy 3. Decrypt qrCodeData using AES-256 server-side key to extract ticketId 4. Query tickets by ticketId and eventId 5. Check if ticket already checked-in (status='checked_in') 6. Query fraud_events for this ticketId to check for duplicate detection flags 7. If duplicate detected, return warning with previous check-in details 8. Return ticket status and any duplicate warnings
SUCCESS (200): { ticketId (string), isDuplicate (boolean), previousCheckInAt (timestamp, optional), previousCheckInBy (string, optional), riskLevel (string: 'low'|'medium'|'high'), message (string) }
ERRORS: 400 (invalid qrCodeData, decryption failed), 401 (unauthenticated), 403 (user not venue staff), 404 (ticket not found), 500 (decryption error)
SECURITY: Auth required (bearer token). Venue staff role enforced via Policy. Rate limit 60 detections/min per user. Decryption happens server-side only.
