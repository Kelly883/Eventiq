# Payment Gateway Integration Endpoint Add Payment Method

POST /api/users/me/payment-methods/add

## Description

Adds a new payment method to the authenticated user's account. The frontend uses Stripe.js to create a PaymentMethod and sends its ID ('pm_...') in the request body. The backend, using Laravel Cashier, adds this payment method to the user's Stripe Customer object. If the user is not yet a Stripe customer, Cashier creates one automatically. It also creates a record in the local `payment_methods` table.
