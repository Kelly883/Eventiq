# Pricing Endpoint Preview

GET /api/organizer/events/:eventId/pricing/preview

## Description

REQUEST: URL param eventId (UUID)
PROCESS: 1. Verify auth token 2. Query events by eventId 3. Check user owns event via Policy 4. Query pricing_windows filtered by eventId, ordered by ticketCategoryId, startDateTime 5. Eager load ticket_tiers for category details 6. For each window, compute isActive based on current time 7. Group windows by ticketCategoryId 8. Return structured preview showing how attendees will see pricing
SUCCESS (200): { eventTitle, eventDate, categories: [{categoryName, basePrice, windows: [{windowName, startDateTime, endDateTime, price, quantitySold, quantityLimit, isActive}]}] }
ERRORS: 400 (invalid eventId), 401 (unauthenticated), 403 (user doesn't own event), 404 (event not found), 500 (database error)
SECURITY: Auth required. Event ownership enforced. Rate limit 20/min per user.
