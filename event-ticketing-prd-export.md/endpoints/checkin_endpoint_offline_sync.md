# Checkin Endpoint Offline Sync

POST /api/venue/check-in/offline-sync

## Description

REQUEST: { eventId (string, required, UUID), localCheckIns (array of {ticketId, checkedInAt, checkedInBy}, required), lastSyncAt (ISO8601, optional) }
PROCESS: 1. Verify auth token and extract userId 2. Check user has 'VenueStaff' or 'Organizer' role via Policy 3. Query events by eventId 4. Verify user is authorized for this event 5. For each localCheckIn: verify ticket exists, check if already synced (compare checkedInAt), update status to 'checked_in' if not already, create auditLog entry 6. Return sync results with success/conflict per item 7. Return server's current check-in state for client cache update
SUCCESS (200): { synced: integer, conflicts: integer, results: [{ticketId, status: 'synced'|'conflict'|'error', serverCheckInAt (if conflict)}], serverCheckIns: [{ticketId, checkedInAt, checkedInBy}] }
ERRORS: 400 (invalid eventId, malformed localCheckIns), 401 (unauthenticated), 403 (user not authorized), 404 (event not found), 409 (sync conflicts), 500 (database error)
SECURITY: Auth required (bearer token). Venue staff role enforced via Policy. Event authorization validated. Rate limit 10 syncs/min per user to prevent abuse. Handles offline-first architecture with conflict resolution.
