# Payment Gateway Integration Endpoint Delete Payment Method

DELETE /api/users/me/payment-methods/:id

## Description

Deletes a saved payment method for the authenticated user. It uses a Laravel Policy to verify the user owns the payment method record. It then calls the appropriate Laravel Cashier method to detach the payment method from the Stripe Customer object and deletes the local record from the `payment_methods` table.
