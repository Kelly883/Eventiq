# Payment Gateway Integration Endpoint Set Default Payment Method

PATCH /api/users/me/payment-methods/:id/set-default

## Description

Sets a specific payment method as the default for future charges for the authenticated user. It uses a Policy to verify ownership. Laravel Cashier's `updateDefaultPaymentMethod` is used to update the default payment method on the Stripe Customer object and update the local `users` and `payment_methods` tables.
