# Calendar Endpoint Date Range

GET /api/events/public/calendar/range

## Description

REQUEST: Query params: ?startDate=2024-03-01 (ISO8601, required), ?endDate=2024-03-31 (ISO8601, required), ?category=concerts (optional), ?priceMin=0&priceMax=500 (optional), ?location=New York (optional)
PROCESS: 1. Validate date range (startDate < endDate, both valid ISO8601) 2. Query events collection filtered by status='published' and event date between startDate and endDate 3. Apply optional filters 4. Join with pricing_windows and ticket_inventory 5. Group events by date 6. Calculate availability status per date (available/low/sold_out based on aggregate stock) 7. Return calendar data for entire range
SUCCESS (200): { startDate: ISO8601, endDate: ISO8601, dates: [{date: ISO8601, eventCount: number, availability: string, events: [...]}], totalEvents: number }
ERRORS: 400 (invalid date format, startDate >= endDate), 500 (database error)
SECURITY: Public endpoint. Rate limit 30/min per IP.
