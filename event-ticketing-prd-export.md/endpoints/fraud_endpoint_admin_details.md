# Fraud Endpoint Admin Details

GET /api/admin/fraud/transaction-details/:fraudEventId

## Description

REQUEST: URL param fraudEventId (UUID)
PROCESS: 1. Verify auth token and extract userId 2. Check user has 'Admin' role via Policy 3. Query fraud_events by fraudEventId 4. Eager load related orders, users, payments, tickets 5. Query orders by orderId to get full order details 6. Query payments by orderId to get payment history 7. Query tickets by orderId to check for duplicates 8. Calculate velocity metrics for this user (orders in 24h, total spend) 9. Return comprehensive fraud analysis
SUCCESS (200): { fraudEvent: {id, orderId, userId, riskScore, riskLevel, detectionMethod, fraudFactors, status, reviewedBy, reviewNotes, createdAt}, order: {id, amount, currency, status, createdAt}, user: {id, email, name, createdAt}, payment: {id, status, gateway, cardLast4, country}, velocityMetrics: {ordersIn24h, totalSpendIn24h, averageOrderValue}, duplicateTickets: array<{ticketId, qrCode, userId}> }
ERRORS: 400 (invalid fraudEventId), 401 (unauthenticated), 403 (user not admin), 404 (fraud event not found), 500 (database error)
SECURITY: Admin-only. Auth required. Rate limit 20/min per user.
