# Qr Endpoint Sync

GET /api/venue/check-in/sync

## Description

REQUEST: Query params: ?eventId=uuid (required), ?lastSyncAt=ISO8601 (optional - for incremental sync)
PROCESS: 1. Verify auth token and extract userId 2. Check user has 'VenueStaff' or 'Organizer' role via Policy 3. Query events by eventId 4. Verify user is authorized for this event (organizer or assigned venue staff) 5. Query tickets filtered by eventId, status='checked_in', checkedInAt > lastSyncAt (if provided) 6. Eager load related event and user (checkedInBy) details 7. Return paginated list of recent check-ins with timestamps and staff names 8. Include real-time counter: totalCapacity, totalCheckedIn, remainingCapacity
SUCCESS (200): { checkIns: [{ticketId, attendeeName, tier, checkedInAt, checkedInBy (staff name)}], totalCapacity (integer), totalCheckedIn (integer), remainingCapacity (integer), lastSyncAt (timestamp), syncStatus: 'synced' }
ERRORS: 400 (invalid eventId or lastSyncAt format), 401 (unauthenticated), 403 (user not authorized for this event), 404 (event not found), 500 (database error)
SECURITY: Auth required (bearer token). Venue staff role enforced via Policy. Event authorization validated. Rate limit 30 syncs/min per user. Supports offline-first architecture - venue staff can cache this data locally and sync when connection restored.
