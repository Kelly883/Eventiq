# Localization Endpoint Get Preferences

GET /api/users/me/language-preferences

## Description

REQUEST: No body, auth token in Authorization header. PROCESS: 1. Verify auth token and extract userId 2. Query localization_preferences by userId 3. If not found, return default localization preferences (English, US, MM/DD/YYYY, 12-hour, USD, comma format) 4. Return preferences with all current settings. SUCCESS (200): { language (string, ISO 639-1), region (string, ISO 3166-1), dateFormat (string), timeFormat (string), currency (string, ISO 4217), numberFormat (string), rtlEnabled (boolean) }. ERRORS: 401 (unauthenticated - attempt token refresh → if fails, redirect to login), 403 (user does not have permission), 500 (database error). SECURITY: Auth required (bearer token). User can only view their own preferences (enforced by Policy). Rate limit 20/min per user to prevent abuse.
