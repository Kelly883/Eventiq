# Organizer Endpoint Get My Profile

GET /api/organizers/me

## Description

REQUEST: No body, auth token in Authorization header
PROCESS: 1. Verify auth token (bearer token) 2. Extract userId from token 3. Query organizers collection by userId 4. Check user has Organizer role via Policy 5. Return full profile data (including private fields) 6. Eager load related user data
SUCCESS (200): { id, userId, displayName, bio, avatarUrl, email, phone, website, socialLinks, brandingColors, isPublic, emailPublic, phonePublic, notificationPreferences, totalEventsCreated, totalTicketsSold, createdAt, updatedAt }
ERRORS:
- 401: User not authenticated (attempt token refresh → if fails, redirect to login)
- 403: User does not have Organizer role

- 500: Database error
