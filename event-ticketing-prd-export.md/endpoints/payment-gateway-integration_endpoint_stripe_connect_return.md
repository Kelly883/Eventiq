# Payment Gateway Integration Endpoint Stripe Connect Return

GET /api/organizer/settings/stripe-connect-return

## Description

The callback endpoint for the Stripe Connect onboarding flow. Stripe redirects the user here after they complete or skip the process. This endpoint retrieves the organizer's details from Stripe, saves the `stripe_account_id` and `stripe_connect_status` to the `organizers` table, and then redirects the user back to the OrganizerPaymentSettingsPage.
