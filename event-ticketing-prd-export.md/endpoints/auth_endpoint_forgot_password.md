# Auth Endpoint Forgot Password

POST /api/auth/forgot-password

## Description

REQUEST: { email (string, required, valid format) }
PROCESS: 1. Validate email format 2. Query users table by email 3. If found, generate random token, hash it, create passwordResetTokens record with 1-hour expiry 4. Send reset email with token link (or log for dev) 5. Always return success regardless of whether email exists
SUCCESS (200): { message: 'If an account exists, a reset link has been sent' }
ERRORS:
- 400: Missing email or invalid format
- 429: Rate limit exceeded (3 requests per hour per IP)
- 500: Email service failure (still return 200 to client)
SECURITY: Always return success to prevent email enumeration. Rate limit to prevent abuse. Hash token before storing (never store plain token). Token expires in 1 hour.
