# Auth Endpoint Register

POST /api/auth/register

## Description

REQUEST: { email (string, required, valid format), password (string, required, min 8 chars), name (string, required, min 2 chars) }
PROCESS: 1. Validate input format and length 2. Check email uniqueness in users table 3. Hash password with bcrypt (cost 12) 4. Create user record with role='attendee' by default 5. Return user info (no token — user must login)
SUCCESS (201): { id, email, name, role }
ERRORS:
- 400: Missing fields, invalid format, password too short, name too short
- 409: Email already registered
- 500: Database error
SECURITY: Hash password before storing. Enforce email uniqueness at database level (unique constraint). Do not return password hash.
