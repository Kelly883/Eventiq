# Dashboard Endpoint Ticket Detail

GET /api/tickets/:ticketId/details

## Description

REQUEST: URL param ticketId (UUID)
PROCESS: 1. Verify auth token and extract userId 2. Query tickets by ticketId 3. Check user owns ticket via Policy 4. Eager load related events, ticket_tiers, orders 5. Query delivery_events by ticketId to get delivery history 6. Query order details for related tickets 7. Return comprehensive ticket details
SUCCESS (200): { id, eventId, eventTitle, eventDate, eventVenue, eventOrganizer: {name, avatar}, tierId, tierName, status, purchaseDate, orderId, qrCodeData, ticketPdfUrl, deliveryStatus, deliveryMethod, deliveryTimestamp, deliveryHistory: [{timestamp, status, method, errorMessage}], relatedTickets: [{id, tierId, tierName, status}] }
ERRORS: 400 (invalid ticketId format), 401 (user not authenticated), 403 (user does not own ticket), 404 (ticket not found), 500 (database error)
SECURITY: Auth required (bearer token). Ticket ownership enforced via Policy. Rate limit 20/min per user to prevent abuse.
