# Inventory Endpoint Get Detailed

GET /api/organizer/events/:eventId/inventory

## Description

REQUEST: URL param eventId (UUID), query params: ?tierFilter=uuid (optional), ?sortBy=allocated|sold|available (optional, default: allocated), ?sortOrder=asc|desc (optional, default: desc)
PROCESS: 1. Verify auth token 2. Query events by eventId 3. Check user owns event via Policy 4. Query ticket_inventory filtered by eventId, optionally by tierFilter 5. For each tier, eager load related pricing_windows with quantityLimit and quantitySold 6. Sort by requested field 7. Return detailed inventory with all pricing windows nested
SUCCESS (200): { tiers: [{tierId, tierName, basePrice, totalAllocated, totalSold, totalAvailable, utilizationPercentage, isLowStock, lowStockThreshold, pricingWindows: [{windowId, windowName, startDateTime, endDateTime, quantityLimit, quantitySold, quantityAvailable, isActive, priority}]}] }
ERRORS: 400 (invalid query params), 401 (unauthenticated), 403 (forbidden), 404 (event not found), 500 (database error)
SECURITY: Auth required. Event ownership enforced. Rate limit 20/min per user.
