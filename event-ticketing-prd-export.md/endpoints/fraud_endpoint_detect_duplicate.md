# Fraud Endpoint Detect Duplicate

POST /api/fraud/detect-duplicate-tickets

## Description

REQUEST: { ticketTierId: string, eventId: string, qrCodeData: string, userId: string }
PROCESS: 1. Query tickets collection by eventId and ticketTierId 2. Search for matching QR codes using qrCodeData 3. If matches found, check if any are from same user (duplicate attempt) or different users (potential fraud ring) 4. Calculate duplicate risk score based on: number of matching QR codes, time between purchases, geographic distance between purchases, payment method similarity 5. If duplicate detected from same user, flag as 'duplicate_ticket_attempt' 6. Create fraud_events record with duplicateTicketInfo containing matching ticket IDs and QR codes 7. Return fraud risk assessment
SUCCESS (200): { isDuplicate: boolean, matchingTickets: array<{ticketId, userId, purchaseTime, qrCode}>, riskScore: number, riskLevel: string }
ERRORS: 400 (invalid input), 401 (unauthenticated), 404 (event or tier not found), 500 (database error)
SECURITY: Auth required. Duplicate detection runs before ticket generation. All duplicates logged to fraud_events. Rate limit 20/min per user to prevent abuse.
