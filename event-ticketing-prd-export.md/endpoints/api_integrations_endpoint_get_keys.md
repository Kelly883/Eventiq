# Api Integrations Endpoint Get Keys

GET /api/developer/api-keys

## Description

Retrieves a list of API keys for the authenticated organizer. The full key is never returned, only the name, prefix, scopes, and metadata. Uses a Laravel Policy to ensure the user is an organizer and can only see their own keys. Data is returned via an API Resource to control exposed fields.
