# Payment Gateway Integration Endpoint Stripe Webhook

POST /api/webhooks/stripe

## Description

Handles incoming webhooks from Stripe. This endpoint is configured in the Stripe dashboard. It uses Laravel Cashier's built-in webhook controller to automatically handle various events. The controller verifies the Stripe signature, parses the event, and dispatches jobs or updates models accordingly. For example, 'charge.succeeded' updates the corresponding 'orders' and 'payments' records to 'completed'. 'charge.refunded' updates the 'refund_requests' and 'payments' tables. This must be a server-side endpoint to securely handle signature verification and database updates.
