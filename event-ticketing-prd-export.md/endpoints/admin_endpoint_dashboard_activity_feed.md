# Admin Endpoint Dashboard Activity Feed

GET /api/admin/dashboard/activity-feed

## Description

REQUEST: Query params: ?limit=20&offset=0 (optional, for pagination)
PROCESS: 1. Verify auth token and extract userId 2. Check user has 'Admin' role via Policy 3. Query auditLogs collection filtered by action in ['user_suspended', 'user_unsuspended', 'event_approved', 'event_flagged', 'event_cancelled', 'payout_approved', 'payout_rejected', 'payment_refunded'], order by createdAt descending 4. Eager load related users (for performedBy), events, orders, payouts 5. Paginate with limit/offset 6. Return activity items with human-readable descriptions
SUCCESS (200): { activities: [{id, action, description, performedBy (admin name), targetType (user|event|order|payout), targetId, timestamp}], total, limit, offset }
ERRORS: 400 (invalid pagination params), 401 (unauthenticated), 403 (user not admin), 500 (database error)
SECURITY: Admin-only. Auth required. Rate limit 20/min per user.
