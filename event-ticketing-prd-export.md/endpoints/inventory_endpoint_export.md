# Inventory Endpoint Export

GET /api/organizer/events/:eventId/inventory/export

## Description

REQUEST: URL param eventId (UUID), query params: ?format=csv|json (optional, default: csv), ?includeHistory=true|false (optional, default: false)
PROCESS: 1. Verify auth token 2. Query events by eventId 3. Check user owns event via Policy 4. Query ticket_inventory and pricing_windows for this event 5. If includeHistory=true, also query inventory_adjustments 6. Format data as CSV or JSON based on format param 7. Set appropriate Content-Type and Content-Disposition headers 8. Return file stream
SUCCESS (200): CSV or JSON file with inventory data
ERRORS: 400 (invalid format param), 401 (unauthenticated), 403 (forbidden), 404 (event not found), 500 (export generation failed)
SECURITY: Auth required. Event ownership enforced. Rate limit 10 exports/min per user to prevent abuse.
