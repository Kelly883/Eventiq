# Push Notifications Endpoint Admin Crud

GET, POST, PATCH, DELETE /api/admin/push-templates and /api/admin/push-templates/:templateId

## Description

Provides full CRUD functionality for push notification templates. Mirrors the existing endpoints for email templates. Authorization is handled by a Laravel Policy, ensuring only users with the 'Admin' role can access these endpoints. GET /api/admin/push-templates lists all templates. POST creates a new one. The routes with :templateId handle retrieving, updating (PATCH), and deleting a specific template. Validation is performed using a FormRequest.
