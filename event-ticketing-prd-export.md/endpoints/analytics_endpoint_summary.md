# Analytics Endpoint Summary

GET /api/organizer/events/:eventId/analytics/summary

## Description

REQUEST: URL param eventId (UUID), query params: ?startDate=ISO8601 (optional), ?endDate=ISO8601 (optional)
PROCESS: 1. Verify auth token and extract userId 2. Query events by eventId 3. Check user owns event via Policy 4. Query analytics_events_metrics filtered by eventId 5. If date range provided, filter sales_timeline by date range and recalculate metrics on-the-fly 6. Calculate trend indicators (compare current period to previous period) 7. Return summary metrics with trend data
SUCCESS (200): { totalRevenue (decimal), totalTicketsSold (integer), conversionRate (decimal %), averageTicketPrice (decimal), totalPageViews (integer), revenueTrend (string: 'up'|'down'|'flat'), ticketsTrend (string), conversionTrend (string), lastUpdatedAt (timestamp) }
ERRORS: 400 (invalid eventId or date format), 401 (user not authenticated), 403 (user does not own event), 404 (event not found), 500 (database error)
SECURITY: Auth required (bearer token). Event ownership enforced via Policy. Rate limit 20/min per user to prevent abuse.
