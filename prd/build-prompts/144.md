We need six endpoints to power the dashboard. Here's what each one does:

1. GET /api/organizer/dashboard/overview — Returns aggregated metrics across all organizer's events. Takes optional query params: dateRange (7days|30days|90days|all, default 30days) and eventFilter (all|upcoming|past|draft, default all). Returns totalRevenue, totalTicketsSold, averageConversionRate, upcomingEventCount, totalEventCount, plus trend indicators (revenueTrend, ticketsTrend, conversionTrend) by comparing current period to previous period. Trends are 'up', 'down', or 'flat'.

2. GET /api/organizer/dashboard/events — Returns paginated list of organizer's events with metrics. Query params: status (all|upcoming|past|draft, default all), limit (default 20), offset (default 0), sortBy (date|revenue|tickets, default date). Returns events array with id, title, date, status, thumbnailUrl, totalRevenue, totalTicketsSold, ticketsAvailable, utilizationPercentage, conversionRate, plus total count.

3. GET /api/organizer/dashboard/events/:eventId — Returns detailed metrics for a single event. Includes event info, tier breakdown (Regular, VIP, VVIP, Early Bird) with sales progress and revenue per tier, and pricing windows with countdown timers. Returns tiers array and pricingWindows array with isActive flag.

4. GET /api/organizer/dashboard/activity-feed — Returns real-time sales activity feed. Query params: limit (default 20), offset (default 0), eventFilter (UUID optional), tierFilter (UUID optional), startDate (ISO8601 optional), endDate (ISO8601 optional). Returns activities array sorted by saleTimestamp descending (most recent first), with eventName, tierName, quantity, unitPrice, totalAmount, buyerEmail.

5. GET /api/organizer/dashboard/preferences — Returns organizer's dashboard preferences (filters, expanded sections, refresh settings). If no preferences exist, return defaults. Returns defaultEventFilter, defaultDateRange, expandedEventId, showActivityFeed, autoRefreshEnabled.

6. PATCH /api/organizer/dashboard/preferences — Updates organizer's preferences. Takes optional fields: defaultEventFilter (must be all|upcoming|past|draft), defaultDateRange (must be 7days|30days|90days|all), expandedEventId (UUID or null), showActivityFeed (boolean), autoRefreshEnabled (boolean). Creates a new preferences record if one doesn't exist. Returns updated preferences.

All endpoints require authentication (bearer token in Authorization header). All endpoints enforce Organizer role via Laravel Policy. All endpoints only return data for the authenticated organizer's own events. Rate limits: 20/min for GET endpoints, 10/min for PATCH. Return 401 for missing/invalid auth, 403 for non-organizers, 400 for invalid parameters, 500 for server errors.
