We need to set up the PostgreSQL table for ticket tiers with all the fields specified in the schema.

Create a Laravel migration that creates the ticket_tiers table with these columns:
- id (auto-incrementing primary key)
- event_id (unsigned big integer, foreign key to events table)
- name (string, required)
- price (decimal 8,2, required)
- quantity (unsigned integer, required)
- sales_start_date (nullable datetime)
- sales_end_date (nullable datetime)
- benefits_description (text, nullable)
- tier_image_url (string, nullable)
- early_bird_price (decimal 8,2, nullable)
- early_bird_end_date (nullable datetime)
- max_per_customer (unsigned integer, nullable)
- created_at and updated_at timestamps

Add indexes on:
- event_id (for fast lookups of all tiers for an event)
- event_id + sales_start_date (for filtering active tiers)
- created_at (for sorting)

Add a foreign key constraint on event_id that cascades deletes (if an event is deleted, its tiers are too).

Run the migration: php artisan migrate. Verify the table structure in your database.
