We need to add routes for the two payment pages and ensure they're accessible from the right places.

Add these routes to your React Router configuration:
1. /settings/payment-methods — PaymentMethodsPage (this is a section within the user settings, so it should be nested under a settings layout)
2. /organizer/settings/payments — OrganizerPaymentSettingsPage (this is a section within organizer settings, nested under an organizer layout)

Both routes should require authentication — if a user tries to access them without being logged in, redirect to the login page.

For /organizer/settings/payments, also check that the user has the 'organizer' role. If not, show an 'Access Denied' message or redirect to the home page.

Add navigation links:
- In the user settings menu/sidebar, add a 'Payment Methods' link that goes to /settings/payment-methods
- In the organizer settings menu/sidebar, add a 'Payment Settings' link that goes to /organizer/settings/payments

When the user completes the Stripe Connect flow (GET /api/organizer/settings/stripe-connect-return), they should be redirected back to /organizer/settings/payments so they can see the updated connection status.

Make sure the back button and breadcrumbs work correctly — users should be able to navigate back to the main settings page from either payment page.
