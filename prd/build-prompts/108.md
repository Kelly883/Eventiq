We need to create the data models and TypeScript types for the payment system.

Backend (Laravel models):
1. PaymentMethod model at app/Features/Payment/Models/PaymentMethod.php — represents a saved payment method. Fields: id, user_id, gateway, gateway_payment_method_id, type, details (cast to array), is_default, created_at, updated_at. Add a belongsTo relationship to User. Add a scope to get only the user's payment methods: scope forUser($query, $userId). Add a method to check if this is the default: isDefault(). Add soft deletes.

2. Enhance the User model — Add a hasMany relationship to PaymentMethod. Add a method getDefaultPaymentMethod() that returns the default payment method or null. Add a method to check if the user is a Stripe customer: isStripeCustomer().

3. Enhance the Organizer model — Add stripe_account_id and stripe_connect_status as fillable attributes. Add a method to check if connected: isStripeConnected(). Add a method to get the connection status: getConnectionStatus().

Frontend (TypeScript types):
1. Create src/features/payment/types/payment.ts with these interfaces:
   - PaymentMethod: { id: string, type: string, brand?: string, lastFour?: string, expiryMonth?: number, expiryYear?: number, isDefault: boolean }
   - StripePaymentMethodResponse: { id: string, object: string, type: string, card?: { brand: string, last4: string, exp_month: number, exp_year: number } }
   - OrganizerPaymentSettings: { stripeAccountId?: string, stripeConnectStatus?: 'enabled' | 'pending' | 'not_connected', connectedAt?: string }

2. Create src/features/payment/types/stripe.ts with Stripe-specific types:
   - StripeElementsOptions: configuration for Stripe Elements
   - StripeError: { code: string, message: string }

All models should be immutable where appropriate (created_at, user_id, gateway_payment_method_id should not be mutable). Add proper validation in the models.
