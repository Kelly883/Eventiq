Now we need to connect the compliance pages to the rest of the app.

Add routes for: /admin/compliance/audit-logs (AuditLogsViewerPage) and /admin/compliance/reports (ComplianceReportsPage). Both routes should be protected — only users with the 'Admin' role can access them. If a non-admin tries to access these routes, redirect to a 'Not Authorized' page or the home page.

Add a navigation link to the compliance section in the admin sidebar or main navigation. The link should only appear for admins. You might organize it under an 'Admin' or 'Compliance' section.

Wire up these connections:
- When an audit log export succeeds, show a confirmation message with a download link
- When bulk tagging logs succeeds, show a confirmation message and refresh the list
- When a compliance report is generated, automatically download it or show a link to download
- When scheduling a report, show a confirmation message
- If the user's auth token expires while viewing these pages (401 response), redirect to login, then back to the compliance page after signing in
- Deep links to /admin/compliance/audit-logs or /admin/compliance/reports should work for admins (redirect to login first if not authenticated, then to the compliance page)

Make sure the admin role check happens on every page load, not just on navigation — this prevents admins from accessing these pages if their role is revoked while they're viewing.
