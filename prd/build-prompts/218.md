# Step 218 of 345: Set up auth state management and context

================================================================================

**Category:** State Management

================================================================================

We need a centralized way for the entire app to know whether a user is logged in, who they are, and what their role is. This prevents prop drilling and makes it easy for any page to check auth status.

Create an AuthContext that exposes: the current user object (id, email, name, role) or null if not logged in, a loading boolean (true while checking initial auth state on app startup), an isAuthenticated boolean, and methods for login, register, logout, and checking if the user has a specific role.

Build an AuthProvider component that wraps the entire app. On mount, it should check if there's a stored token in localStorage and validate it with the backend (you can do this by making a simple GET request to a protected endpoint, or by decoding the JWT client-side if it's a JWT). While this check is in progress, set loading to true. Once complete, populate the user object or set it to null. If the token is invalid or expired, clear localStorage.

Implement the login method: call POST /api/auth/login with email and password, store the returned token in localStorage, populate the user object from the response, and return success or throw an error with a user-friendly message.

Implement the register method: call POST /api/auth/register with name, email, and password, then return success (don't auto-login — user must go to /login).

Implement the logout method: clear the token from localStorage, clear the user object, and optionally call a POST /api/auth/logout endpoint if the backend tracks sessions.

Store the token in localStorage with a key like 'authToken'. Include it in the Authorization header (Bearer token) for all subsequent API requests — use an axios interceptor to add this automatically to every request.

Handle token expiration: if any API request returns 401, clear the token and user, and redirect to /login.

Make sure the AuthContext is available to all pages and components via useAuth hook.
