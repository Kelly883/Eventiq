We need to set up the tools for handling payments and complex data queries.

On the frontend (React + Vite), install:
- TanStack Query (for server state management and caching of payout data)
- recharts (for visualizing settlement metrics and payout method breakdowns)
- React Router (for navigation between organizer and admin dashboards)

On the backend (Laravel), ensure these are installed:
- Laravel Eloquent (already included, but we'll use it heavily for complex queries)
- Laravel Policy authorization (already included)
- A payment gateway SDK — if you're using Stripe for payouts, install the Stripe PHP SDK. If using another gateway, install that SDK instead. Store the API keys in .env (STRIPE_SECRET_KEY, etc.)

Set up environment variables on the backend:
- PAYMENT_GATEWAY (e.g., 'stripe')
- PAYMENT_GATEWAY_SECRET_KEY
- PAYOUT_HOLD_DAYS (default 3)
- PAYOUT_MAX_RETRIES (default 3)
- AUDIT_LOG_ENABLED (true for logging all payout actions)

Create a PaymentGatewayService class at app/Services/PaymentGatewayService.php that abstracts the payment gateway. This service will handle initiating payouts, checking payout status, and handling retries. We'll use this in the controllers.
