- notifications (for push notification device handling)
- tickets (for ticket display and caching)

Within src/features/notifications/, create: services/ (for device token registration and management), types/ (for push notification device types).

Within src/features/tickets/, create: components/ (for ticket cards and lists), hooks/ (for useTickets), and types/ (for ticket types).

On the backend, create a Laravel feature folder at app/Features/OfflineSync/ with Controllers/, Requests/, Resources/, and Models/ subdirectories. This keeps offline sync logic separate from the main app.

Also create app/Features/Notifications/ with Controllers/, Requests/, Resources/, and Models/ for push notification device management.

This structure keeps responsive design concerns separate from offline functionality, making it easier to maintain and test both independently.
