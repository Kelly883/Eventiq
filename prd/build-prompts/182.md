We need several reusable React components that both the organizer and admin dashboards will use.

1. SummaryCards — A grid of metric cards showing key numbers. Takes an array of card configs: { label, value, trend (up/down/neutral), trendPercentage }. Each card shows the label, a large number, and a colored trend indicator (green for up, red for down, gray for neutral). Used on both dashboards to show total revenue, pending payouts, success rate, etc.

2. PayoutTable — A sortable, filterable table of payouts. Props: payouts (array), columns (array of column configs), isLoading (boolean), onSort (callback), onRowExpand (callback). Each row shows payout details with a status badge (color-coded: amber=pending, blue=processing, green=completed, red=failed). Clicking a row expands it to show details. On mobile, collapses to a card layout. Handles empty state (shows 'No payouts' message).

3. StatusBadge — A small badge showing payout status with appropriate color. Props: status (string), size (small/medium). Maps status to color: pending→amber, calculated→blue, approved→green, processing→purple, completed→gray, failed→red.

4. ExpandablePayoutRow — Details view for a single payout. Shows breakdown: ticket sales by tier, refunds applied, commission calculation, tax withholding, payment method. Props: payout (object), calculationDetails (object). Renders as a collapsible section below the main row.

5. FilterBar — Sticky filter controls. Props: filters (object), onFilterChange (callback). Includes: date range picker (start/end), status dropdown (multi-select), payout period selector. On mobile, collapses to a 'Filters' button that opens a modal.

6. ExportButton — Button to export payout history as PDF or CSV. Props: payouts (array), format ('pdf'|'csv'), filename (string). Calls a backend endpoint to generate the file, then downloads it.

7. PayoutMethodDisplay — Shows the payout method with masked bank account info. Props: payoutMethod (string), accountLastFour (string). Displays: 'ACH - ****1234' or 'Wire Transfer - ****5678'.

All components should use TypeScript for type safety. Use React hooks (useState, useCallback) for local state. Export from src/features/payouts/components/index.ts for easy importing.
