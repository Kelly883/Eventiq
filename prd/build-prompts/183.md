We need to build reusable components that will be shared across all four admin pages. These components handle the common UI patterns for the admin panel.

Common components at src/features/admin/components/common/:

1. AdminHeader — Sticky header with app logo, search bar (searches users, events, orders by ID or email), date range picker (for filtering dashboard data), and user menu (profile, settings, logout). Takes props: onSearch(query), onDateRangeChange(startDate, endDate). Used on all admin pages.

2. StatusBadge — Color-coded badge showing status. Takes props: status (string), type ('user'|'event'|'payment'|'payout'). Maps status to color: active/published/completed=green, pending/draft=amber, suspended/cancelled/failed=red, flagged=orange, refunded=blue. Used throughout all pages.

3. RoleBadge — Color-coded badge for user roles. Takes props: role ('admin'|'organizer'|'attendee'). Maps to colors: admin=purple, organizer=blue, attendee=gray. Used in user management.

4. LoadingSkeletons — Shimmer placeholder components for loading states. Includes: MetricCardSkeleton (3 cards in a row), TableRowSkeleton (full-width row), ActivityItemSkeleton. Used on all pages during data fetch.

5. EmptyState — Friendly message when no data exists. Takes props: title, description, illustration (icon name), actionButton (optional). Used when tables are empty.

6. ErrorBanner — Full-width error message with retry button. Takes props: error (string), onRetry (callback). Used when API calls fail.

Dashboard-specific components at src/features/admin/components/dashboard/:

7. MetricCard — Shows a single metric (e.g., 'Total Revenue', '$45,230'). Takes props: title, value, trend ('up'|'down'|'flat'), trendPercent (number), icon (icon name). Displays trend indicator with color (green for up, red for down). Used in AdminDashboardPage overview section.

8. NavigationTiles — 2x3 grid of clickable tiles linking to core admin functions (User Management, Event Moderation, Payment Reconciliation, Dispute Resolution, System Configuration, Reports). Each tile has icon, title, and description. Takes props: onTileClick(tileId). Used in AdminDashboardPage.

9. ActivityFeed — Collapsible section showing recent admin actions. Takes props: activities (array of AuditLog items), isLoading, error, onRefresh. Displays activity items with admin name, action description, timestamp. Used in AdminDashboardPage.

10. AlertsSection — Collapsible section showing system alerts. Takes props: alerts (array), severity filter options, onSeverityChange. Color-codes alerts by severity. Used in AdminDashboardPage.

11. QuickStatsSection — Shows platform health metrics (uptime %, API response time, database query performance). Takes props: stats (object). Used in AdminDashboardPage.

Table components at src/features/admin/components/common/:

12. AdminTable — Reusable data table component using React Table. Supports: sorting (click column headers), filtering (via filter bar), expandable rows (click row to expand details), pagination (next/prev buttons), bulk actions (checkboxes). Takes props: columns (array of column definitions), data (array of rows), isLoading, error, onRowExpand (callback), onBulkAction (callback), pagination (current page, total pages). Used in AdminUserManagementPage, AdminEventModerationPage, AdminPaymentReconciliationPage.

13. ExpandableRowDetails — Panel that slides out when a table row is expanded. Takes props: data (full record details), type ('user'|'event'|'payment'). Displays full details without leaving the page. Used with AdminTable.

14. BulkActionBar — Sticky bar that appears when rows are selected. Shows count of selected items and action buttons (Suspend, Unsuspend, Flag, Refund, etc.). Takes props: selectedCount, actions (array of action buttons), onAction (callback). Used in AdminUserManagementPage, AdminEventModerationPage, AdminPaymentReconciliationPage.

All components should:
- Use TanStack Query for data fetching where needed
- Support loading and error states
- Be fully typed with TypeScript
- Use consistent styling (colors, spacing, typography)
- Be accessible (ARIA labels, keyboard navigation)
- Work on mobile (responsive design)
