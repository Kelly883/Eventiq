We're building a complete user authentication system with login, registration, and password reset flows. For this step, I need you to set up the folder structure for both frontend and backend.

On the frontend (React + Vite), create a features/auth/ folder with these subfolders:
- pages/ (for LoginPage, RegisterPage, ForgotPasswordPage, ResetPasswordPage)
- components/ (for reusable form components like PasswordStrengthMeter, FormField, PasswordVisibilityToggle)
- hooks/ (for custom hooks like useAuth, usePasswordStrength)
- services/ (for API calls like authService.login(), authService.register())
- utils/ (for validation helpers like validateEmail, validatePassword)
- context/ (for AuthContext to manage global auth state)

On the backend (Laravel), create a folder structure:
- app/Http/Controllers/AuthController.php (for all auth endpoints)
- app/Models/User.php (already exists, we'll extend it)
- app/Models/Session.php (new model for session management)
- app/Models/PasswordResetToken.php (new model for reset tokens)
- database/migrations/ (for creating the sessions and passwordResetTokens tables)
- routes/api.php (we'll add auth routes here)

This keeps auth logic isolated and easy to maintain as the app grows.
