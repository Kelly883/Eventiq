We need to set up the push notification infrastructure so the app can send and receive notifications.

On the frontend (React + Vite):
1. Install firebase package: npm install firebase
2. Create a Firebase config file at src/config/firebase.ts with your Firebase project credentials (get these from the Firebase Console). Initialize Firebase and the Cloud Messaging service.
3. Create a service worker file at public/firebase-messaging-sw.js that handles incoming push notifications when the app is in the background. This worker listens for messages and displays them to the user.
4. In your main app initialization (src/main.tsx or App.tsx), request notification permission from the browser using Notification.requestPermission(). Store the result so we know if the user granted or denied permission.
5. After getting permission, retrieve the FCM token using getToken() from the Firebase Messaging service. This token uniquely identifies the user's device.

On the backend (Laravel):
1. Install the Firebase Admin SDK: composer require kreait/firebase-php
2. Create a Firebase service provider at app/Providers/FirebaseServiceProvider.php that initializes the Firebase Admin SDK with your service account credentials (download the JSON key from Firebase Console and store it securely in your .env or config).
3. Create a helper class at app/Services/PushNotificationService.php that wraps the Firebase Admin SDK. This will handle sending notifications to device tokens.
4. Set up Laravel Queue for background job processing. Update your .env to use a queue driver (redis or database). We'll use this to send notifications without blocking API responses.
