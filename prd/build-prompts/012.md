We're building a secure checkout and payment processing system for an event ticketing platform. For this step, I need you to set up the folder structure that will organize all the pieces.

On the frontend (React + Vite), create a checkout feature area under src/features/checkout/ with these subfolders:
- pages/ (for CartPage, CheckoutPage, OrderConfirmationPage, UserTicketsPage)
- components/ (for reusable UI pieces like OrderSummary, PaymentForm, TicketCard, QRCodeDisplay)
- hooks/ (for custom React hooks like useCart, useCheckout, usePaymentIntent)
- context/ (for CartContext and any other shared state)
- services/ (for API client functions that call the backend endpoints)
- types/ (for TypeScript interfaces matching the orders, order_items, tickets, and payments schemas)

On the backend (Laravel), create a checkout module under app/Http/Controllers/ with:
- CartController (for the verify endpoint)
- CheckoutController (for creating payment intents)
- OrderController (for retrieving order details)
- TicketController (for listing user tickets)
- WebhookController (for handling payment provider webhooks)

Also create app/Models/ with Eloquent models for Order, OrderItem, Ticket, and Payment that map to the database tables.

This structure keeps payment logic separate from the rest of the app and makes it easy to find and test each piece.
