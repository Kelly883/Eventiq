We're building an organizer profile and branding system. For this step, I need you to build three pages that let organizers showcase themselves and manage their public presence.

OrganizerPublicProfilePage at /organizer/:organizerId — This is the public-facing profile that anyone can visit. At the top, create a hero section with the organizer's avatar (circular image), display name, and bio. Apply the organizer's custom branding colors (primaryColor for the header background, accentColor for buttons). Below that, show contact information (email, phone, website) but only if the organizer has made those fields public via their privacy settings. Include social media links (Twitter, Instagram, LinkedIn, YouTube) if they've added them. On the right side (desktop) or below (mobile), show a grid of event cards — each with thumbnail image, title, date, and ticket availability status. Let users filter events by category and date range using chips or a dropdown. Add a 'Follow' button if an attendee is viewing, or edit controls if the profile owner is viewing. Include a 'Share Profile' button that generates a shareable link and a 'Contact Organizer' button that opens a modal with a contact form. Handle loading state with skeleton cards and shimmer placeholders. Empty state (no events) shows 'No events yet' with a friendly illustration. Error states: 404 shows 'Organizer not found' with a back button, 500 shows an error banner with retry, 401 redirects to login.

OrganizerProfileEditPage at /organizer/profile/edit — This is the organizer-only form to create and edit their public profile. Start with an avatar upload section at the top with circular crop preview, drag-drop support, and a file picker. Below that, organize the form into sections: Basic Info (display name field, bio textarea with 500-char counter), Contact (email, phone, website URL fields), Branding (primary color picker and accent color picker with live preview of how the header will look), and Privacy (toggles for show email, show phone, show contact form). Each field should validate on blur with inline error messages. The Save button should be sticky at the bottom on mobile and show a loading spinner while saving. Include a Cancel button that goes back. Show an 'Unsaved changes' warning if the user tries to leave with unsaved data. On success, show a 'Profile updated' toast and redirect to the public profile view. Error states: 401 redirects to login, 403 shows 'Access Denied', 500 shows an error banner with retry.

OrganizerProfileSettingsPage at /organizer/profile/settings — This is the settings hub for profile management. At the top, display read-only stats as cards: current profile status (active/inactive), member since date, total events created, and total tickets sold. Below that, add a toggle for profile visibility (public/private). Then email notification preferences with checkboxes for: new ticket sales, event reminders, and platform updates. Include a link to the edit profile form and a link to view the public profile. For organizers with admin role, show an audit log section (collapsible) displaying recent profile changes with who changed what and when. At the bottom in a red section, add a profile deletion warning with a confirmation button — deletion requires email confirmation. Handle loading state with skeleton stat cards and toggle placeholders. Empty state for audit log shows 'No changes yet'. Error states: 401 redirects to login, 403 shows 'Access Denied', 500 shows an error banner.
