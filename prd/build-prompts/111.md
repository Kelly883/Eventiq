We need to add two routes to the React Router configuration for the role and permission pages.

1. /admin/roles — AdminRoleManagementPage (admin-only). This is the main dashboard for managing user roles and permissions. Protect this route with a guard that checks if the current user is an admin. If not, redirect to /settings/permissions (the user's own permissions page) with a toast message 'Access Denied — only admins can manage roles'.

2. /settings/permissions — UserPermissionsPage (all authenticated users). This shows the current user's role and permissions, and allows them to request elevated permissions. Protect this route with a guard that checks if the user is authenticated. If not, redirect to /login.

Both routes should be added to the main router configuration (likely using React Router's createBrowserRouter or similar). The admin route should be nested under an /admin layout if one exists, or created as a top-level route.

When a user's role or permissions change (detected via the audit log or a real-time update), invalidate the TanStack Query cache for the user's permissions so the page refreshes automatically.
