We need three things set up before building the check-in feature:

1. Encryption for QR codes — Install openssl (Laravel has this built-in) and configure AES-256 encryption in Laravel's config/app.php. We'll use this to encrypt ticket IDs in QR codes on the backend and decrypt them during check-in. Store the encryption key in .env as APP_KEY (Laravel handles this automatically).

2. QR code generation and scanning — On the frontend, install qrcode.react for generating QR codes and jsqr for decoding them from camera input. On the backend, install bacon/bacon-qr-code for generating QR codes server-side if needed.

3. Real-time updates — Install Laravel WebSockets or use a service like Pusher for real-time check-in stats. Configure the broadcasting driver in config/broadcasting.php. On the frontend, install laravel-echo and pusher-js to listen for real-time events. This lets venue staff see live check-in counts without refreshing.

4. Offline support — Install idb (IndexedDB wrapper) on the frontend for storing check-ins locally when offline, and a sync manager to reconcile with the server when back online.
