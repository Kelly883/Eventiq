We need TypeScript interfaces that match the data structures returned by the three calendar endpoints. Create these in src/features/events-calendar/types/index.ts:

1. Event — The main event object. Fields: id (string), title (string), description (string), status (enum: 'published' | 'draft' | 'cancelled'), eventDate (ISO8601 string), startTime (ISO8601 string), endTime (ISO8601 string), category (string), venue (object with name, address, latitude, longitude), bannerUrl (string), organizer (object with id, name, avatar, brandingColors), ticketTiers (array of TicketTier), ticketsSold (number), trending (boolean).

2. TicketTier — Represents a ticket type. Fields: id (string), name (string), currentPrice (number), ticketsAvailable (number), totalTickets (number).

3. PricingWindow — Pricing rules. Fields: id (string), eventId (string), ticketTierId (string), startDate (ISO8601), endDate (ISO8601), price (number).

4. TicketInventory — Stock tracking. Fields: id (string), eventId (string), ticketTierId (string), totalTickets (number), ticketsSold (number), ticketsAvailable (computed: totalTickets - ticketsSold).

5. Organizer — Event organizer profile. Fields: id (string), name (string), avatar (string), brandingColors (object with primary, secondary), privacySettings (object).

6. CalendarDate — A date with events and availability. Fields: date (ISO8601), eventCount (number), availability (enum: 'available' | 'low' | 'sold_out'), events (array of Event).

7. CalendarResponse — Response from /api/events/public/calendar. Fields: dates (array of CalendarDate), month (string), week (string).

8. DayDetailResponse — Response from /api/events/public/calendar/day/:date. Fields: date (ISO8601), events (array of Event), total (number).

9. RangeResponse — Response from /api/events/public/calendar/range. Fields: startDate (ISO8601), endDate (ISO8601), dates (array of CalendarDate), totalEvents (number).

Make all types immutable where possible (use readonly). Add helper functions: isEventAvailable(), getAvailabilityStatus(), formatEventDate(), groupEventsByDate().
