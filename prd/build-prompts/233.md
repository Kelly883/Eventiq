We need state management to handle the complex check-in workflow without making the pages messy.

Create three state managers using React Context or a state library (your choice — Zustand, Redux, or Context API all work):

1. CheckInStatsState — Tracks real-time statistics for an event: totalCapacity, totalCheckedIn, totalRemaining, totalVoid, checkInRate, and lastUpdateAt. Exposes methods: fetchStats(eventId), startAutoRefresh(eventId, intervalMs), stopAutoRefresh(). The auto-refresh should use the lastUpdateAt parameter to only fetch deltas (incremental updates). Handles loading and error states.

2. SearchState — Tracks search results and search history. Stores: currentQuery, results (array of ticket objects), isSearching, searchError, recentSearches (last 10 queries). Exposes methods: search(eventId, query), clearSearch(), addToRecentSearches(query). Debounces the search call (300ms) so it doesn't fire on every keystroke.

3. OfflineSyncState — Tracks offline check-ins and sync status. Stores: queuedCheckIns (array of {ticketId, checkedInAt, checkedInBy}), isSyncing, syncError, lastSyncAt. Exposes methods: queueCheckIn(ticketId), syncQueuedCheckIns(eventId), clearQueue(). When the app detects it's back online (navigator.onLine), automatically call syncQueuedCheckIns(). The sync endpoint (POST /api/venue/check-in/offline-sync) returns the server's current check-in state, so update the local cache with that.

4. BulkCheckInState — Tracks bulk check-in progress. Stores: ticketIds (array), isProcessing, progress (current index / total), results (array of {ticketId, status, message}), summary (checkedIn count, failed count). Exposes methods: setBulkTickets(ids), processBulk(eventId), clearResults().

All state managers should handle auth errors (401) by clearing the token and redirecting to login. Handle rate limits (429) by showing a user-friendly message and backing off.

The pages should import these state managers and call their methods — the pages themselves should be thin and mostly just render what the state tells them to.
