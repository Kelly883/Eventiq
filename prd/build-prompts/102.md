We need three Eloquent models to represent the payout system.

1. SettlementPolicy model (app/Models/SettlementPolicy.php) — Represents commission rules for organizer tiers. Should have:
- Fillable fields: organizerTier, platformCommissionPercentage, processingFeePercentage, payoutFrequency, minimumPayoutThreshold, payoutHoldDays, requiresApproval, autoApproveThreshold, maxRetries, retryBackoffMultiplier, taxWithholdingPercentage, allowedPayoutMethods, isActive
- Casts: allowedPayoutMethods as array, decimals as float
- Scopes: active() to filter isActive = true, byTier($tier) to find by organizerTier
- Methods: canAutoApprove($amount) to check if payout is below autoApproveThreshold

2. Payout model (app/Models/Payout.php) — Main payout record. Should have:
- Fillable fields: organizerId, settlementPeriodStartDate, settlementPeriodEndDate, grossRevenue, refundsDeducted, netRevenue, platformCommissionPercentage, platformCommissionAmount, processingFeePercentage, processingFeeAmount, taxWithholdingPercentage, taxWithholdingAmount, payoutAmount, payoutMethod, paymentGatewayPayoutId, paymentGatewayResponse, status, calculatedAt, approvedBy, approvedAt, processingStartedAt, completedAt, failureReason, retryCount, nextRetryAt
- Casts: paymentGatewayResponse as array, all decimals as float, dates as datetime
- Relationships: belongsTo(Organizer), belongsTo(User, 'approvedBy'), hasMany(PayoutCalculation)
- Scopes: byOrganizer($organizerId), byStatus($status), byDateRange($startDate, $endDate), pending(), completed(), failed()
- Methods: isPending(), isCompleted(), isFailed(), canRetry(), calculateNetAmount() (for display)
- Mutators: ensure payoutAmount is never negative, status transitions are valid

3. PayoutCalculation model (app/Models/PayoutCalculation.php) — Immutable audit trail. Should have:
- Fillable fields: payoutId, organizerId, settlementPeriodStartDate, settlementPeriodEndDate, eventIds, orderIds, refundRequestIds, totalOrderCount, totalTicketsSold, totalRefundsProcessed, calculationDetails, calculatedAt, calculatedBy
- Casts: eventIds, orderIds, refundRequestIds, calculationDetails as array, calculatedAt as datetime
- Relationships: belongsTo(Payout)
- No update/delete methods (immutable)
- Methods: getCalculationSummary() to return a formatted breakdown

All three models should use UUID primary keys. Add proper timestamps (created_at, updated_at). Use Laravel's authorization policies (we'll build PayoutPolicy separately).
