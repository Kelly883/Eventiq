We need to set up the database table for pricing windows in Laravel.

Create a migration file (run `php artisan make:migration create_pricing_windows_table`) that creates the pricing_windows table with these columns:
- id (UUID primary key, auto-generated)
- event_id (UUID, foreign key to events table, indexed)
- ticket_category_id (UUID, foreign key to ticket_tiers table, indexed)
- window_name (string, max 100)
- start_date_time (timestamp)
- end_date_time (timestamp)
- price (decimal 10,2)
- quantity_limit (integer, nullable)
- quantity_sold (integer, default 0)
- is_active (boolean, default false)
- priority (integer, default 0)
- created_at (timestamp, auto-set)
- updated_at (timestamp, auto-set)
- deleted_at (timestamp, nullable for soft deletes)

Create indexes on: (event_id), (ticket_category_id), (event_id, ticket_category_id), (start_date_time), (end_date_time), and (deleted_at) for soft delete queries.

Add foreign key constraints: event_id references events(id) on delete cascade, ticket_category_id references ticket_tiers(id) on delete cascade.

Run the migration with `php artisan migrate`.
