We're building an organizer dashboard — a real-time command center for event organizers to monitor sales, revenue, and event metrics across all their events.

Create a dashboard feature area under src/features/dashboard/ with these subfolders:

- pages/ — for OrganizerDashboardPage (the main dashboard view)
- components/ — for reusable widgets like EventDetailWidget, SalesActivityFeed, MetricCard, EventCard, and filter/header components
- hooks/ — for custom React hooks that manage dashboard data fetching and state (useOrganizerMetrics, useDashboardPreferences, useActivityFeed, etc.)
- types/ — for TypeScript interfaces matching the dashboard schemas and API responses
- services/ — for API client functions that call the backend endpoints
- utils/ — for helper functions like formatting currency, calculating trends, formatting timestamps

On the backend side (Laravel), create a folder structure under app/Http/Controllers/ for DashboardController, and under app/Models/ for the OrganizerDashboardPreferences model. Create database migrations for the organizer_dashboard_preferences table.

This structure keeps the dense, data-heavy dashboard logic organized and makes it easy to reuse components across the feature.
