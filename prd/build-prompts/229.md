We need state management so the fraud dashboard and modal don't handle data fetching themselves. Create three state managers:

**Flagged Transactions State** — Manages the list of flagged transactions shown in the FraudDetectionDashboardPage table. Track: the list of transactions, loading state (initial load vs. loading more), pagination (page, limit, total count), active filters (riskLevel, dateRange, paymentMethod, reason), sort options (sortBy field, sortOrder asc/desc), and any errors. Should support: loading the first page of transactions, changing filters (clears pagination and reloads), changing sort order (reloads), loading the next page (append, don't replace), and toggling real-time updates (auto-refresh every 30 seconds). When real-time updates are enabled, poll GET /api/admin/fraud/flagged-transactions with current filters every 30 seconds and merge new transactions into the list (don't replace the whole list — just update changed rows and add new ones). Handle pagination internally using page/limit.

**Transaction Details State** — Manages the detailed fraud analysis for a single transaction shown in the FraudTransactionReviewModal. Track: the fraud event details, loading state, and errors. Loads from GET /api/admin/fraud/transaction-details/:fraudEventId. Should support: loading a transaction by ID, and clearing the details when the modal closes.

**Review Action State** — Manages the approve/reject action in the modal. Track: whether a review is in progress (submitting), any errors from the backend, and the result of the last action (approved/rejected). Should support: submitting an approve or reject decision with optional notes via POST /api/admin/fraud/review-transaction, handling success (close modal, refresh the transactions list), and handling errors (show error message, keep modal open so admin can retry).

Keep all business logic out of the components — pages should just call methods on the state managers and react to state changes. Use React hooks (useState, useEffect, useCallback) or a state management library like Zustand or Redux if the project already uses one.
