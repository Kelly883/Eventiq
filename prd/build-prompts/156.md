We need to build the GET /api/organizer/payouts/list endpoint that organizers use to see their payout history.

Create OrganizerPayoutController at app/Http/Controllers/OrganizerPayoutController.php with a list() method that:

1. Authenticates the request — Extract the bearer token and verify it's valid. If not, return 401 with 'Unauthenticated' message.

2. Authorizes the user — Check that the authenticated user is an organizer (has 'organizer' role). If not, return 403 with 'Access Denied — only event organizers can view payouts'.

3. Validates query parameters — Accept: page (default 1), limit (default 50, max 100), status (optional, one of: pending/calculated/approved/processing/completed/failed), startDate (optional, ISO8601), endDate (optional, ISO8601), sortBy (default 'createdAt', one of: createdAt/payoutAmount), sortOrder (default 'desc', one of: asc/desc). Return 400 if any param is invalid.

4. Queries payouts — Use Eloquent to fetch the organizer's payouts:
   - Filter by organizerId = authenticated user's organizerId
   - If status is provided, filter by status
   - If startDate/endDate provided, filter settlementPeriodStartDate/EndDate within range
   - Eager load settlement_policies for commission display
   - Sort by the requested field and order
   - Paginate with limit and offset (not cursor-based for simplicity)

5. Formats response — Return 200 with JSON:
   {
     "payouts": [
       {
         "id": "uuid",
         "settlementPeriodStartDate": "ISO8601",
         "settlementPeriodEndDate": "ISO8601",
         "grossRevenue": 5000.00,
         "platformCommissionAmount": 500.00,
         "refundsDeducted": 200.00,
         "payoutAmount": 4300.00,
         "status": "completed",
         "payoutMethod": "ach",
         "completedAt": "ISO8601"
       }
     ],
     "total": 42,
     "page": 1,
     "limit": 50
   }

6. Enforces rate limiting — 20 requests per minute per user. Return 429 if exceeded.

7. Logs the action — Log to auditLogs table: action='payout_list_viewed', organizerId, timestamp, query params (for audit trail).

Create a PayoutResource class at app/Http/Resources/PayoutResource.php to format the response consistently. Use Laravel's form request validation (PayoutListRequest) to validate query params.
