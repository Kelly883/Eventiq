We need two reusable components that will be used across the push notification feature.

1. NotificationToggle component at src/features/push-notifications/components/NotificationToggle.tsx:
   - Takes props: label (string), checked (boolean), onChange (callback), disabled (boolean), loading (boolean)
   - Renders a single row with a label on the left and a toggle switch on the right
   - When loading, shows a skeleton placeholder
   - When disabled, the toggle is grayed out and non-interactive
   - Matches the existing design system (use the same switch component as the rest of the app)
   - Used in PushNotificationSettingsSection for each notification type toggle

2. TemplateEditor component at src/features/push-notifications/components/TemplateEditor.tsx:
   - Takes props: template (PushNotificationTemplate or null for new), onSave (callback), onCancel (callback), loading (boolean), error (string or null)
   - Renders a form with fields: name (text input), type (dropdown), title (text input with character counter, max 65), body (textarea with character counter, max 178), variables (read-only JSON display)
   - Shows a sidebar with available placeholder variables ({{user.name}}, {{event.title}}, etc.)
   - Has a 'Save' button that calls onSave with the form data, and a 'Cancel' button
   - When loading, the form is disabled and the Save button shows a spinner
   - When error is present, shows an inline error message
   - Validates that name and type are not empty before allowing save
   - Character counters update in real-time as the user types
   - Used in AdminPushTemplateManagementPage for creating and editing templates

Both components should be simple, focused, and reusable. They should not handle API calls themselves — that's the responsibility of the parent page or hook.
