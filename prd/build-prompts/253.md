Add a route for /organizer/events/:eventId/inventory that renders TicketInventoryDashboardPage. This should be nested under the event detail page so the organizer can navigate between event settings, ticket tiers, pricing windows, and inventory management.

On the event detail page or event sidebar, add a link or navigation item called 'Inventory' that goes to /organizer/events/:eventId/inventory. Make sure it's only visible to the event organizer (check user ownership).

Wire up these connections:
- The 'Adjust Inventory' button in the dashboard opens the AdjustInventoryModal (this is local state, no navigation needed)
- The 'Export' button triggers a download of the CSV file
- If there are low-stock alerts, consider adding a badge or notification on the 'Inventory' link in the sidebar so organizers know at a glance if action is needed
- The modal's 'Apply' button should close the modal and refresh the dashboard data automatically (handled by query invalidation in state management)
- The 'Cancel' button just closes the modal

Make sure the route is protected: if the user isn't logged in, redirect to login. If the user doesn't own the event, show 'Access Denied' and don't render the page.

Consider adding a breadcrumb trail: Events > [Event Name] > Inventory so organizers know where they are.
