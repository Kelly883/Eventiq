We need to wire the dashboard into the app's routing so organizers can access it.

Add these routes to your React Router configuration:
- /dashboard — OrganizerDashboardPage (the main dashboard)
- /dashboard/events/:eventId — EventDetailWidget (or keep it as an expandable widget on the main dashboard, not a separate route)
- /organizer/events/:eventId/analytics — Full analytics page (link from EventDetailWidget's 'View Full Analytics' button)
- /organizer/events/:eventId/inventory — Inventory management page (link from EventDetailWidget's 'Manage Inventory' button)
- /organizer/events/:eventId/edit — Event edit page (link from EventDetailWidget's 'Edit Event' button)

Add a route guard so only authenticated users with the 'Organizer' role can access /dashboard. If a non-organizer tries to access it, show an 'Access Denied' message. If not authenticated, redirect to the login page.

Add a 'Dashboard' link in the main app navigation (header or sidebar) that takes organizers to /dashboard. This should only appear for users with the Organizer role.

Wire up the 'Create New Event' button on the dashboard to navigate to /organizer/events/create (or open a modal for quick event creation).

Ensure deep linking works: if an organizer opens a deep link to /dashboard?eventId=xyz, the EventDetailWidget should expand for that event automatically.
