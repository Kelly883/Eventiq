We need three things set up before we build the email template system:

1. Rich-text editor — Install TipTap (via npm) on the frontend. TipTap will be used in the TemplateEditor component to let admins write responsive HTML emails. Configure it with extensions for bold, italic, links, lists, and code blocks. We'll also need to support MJML syntax highlighting, so add a custom extension or use a code block extension that recognizes MJML.

2. MJML rendering — Install mjml (npm package) on the backend. This will compile MJML markup into responsive HTML. When an admin saves a template with MJML, the backend will automatically generate the HTML version and store both.

3. Email testing — On the backend, make sure Laravel's Mail facade is configured. We'll use it to send test emails synchronously (not queued) so admins get immediate feedback in the admin panel when they click 'Send Test Email'.

Add MJML_ENABLED=true to your .env file so the system knows to process MJML templates.
