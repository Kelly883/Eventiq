We need three things set up before we build the organizer profile feature:

1. Image upload and processing — On the frontend, install react-dropzone for drag-and-drop avatar uploads and react-easy-crop for circular image cropping. On the backend, Laravel already has Storage abstraction built-in, but we need to install the sharp package (npm install sharp) for server-side image resizing to 400x400 pixels. Configure your S3 or object storage credentials in the .env file (AWS_ACCESS_KEY_ID, AWS_SECRET_ACCESS_KEY, AWS_DEFAULT_REGION, AWS_BUCKET).

2. Color picker — Install react-colorful for the branding color picker component on the frontend. This gives us a lightweight, accessible color picker that works well in forms.

3. HTTP client setup — Make sure axios is installed and configured with a base URL pointing to your Laravel API. Set up an interceptor to automatically attach the Authorization header with the bearer token from localStorage (key: 'authToken'). This interceptor should also handle 401 responses by attempting token refresh, and if that fails, redirect to the login page.

4. Form validation — Install react-hook-form and zod for frontend form validation. These will validate inputs before sending to the backend (displayName required, bio max 500 chars, valid URLs, valid hex colors).
