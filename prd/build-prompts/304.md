We need to make sure things fail gracefully when something goes wrong in the developer portal.

DeveloperPortalPage:
- If the user is not authenticated, redirect to the login modal.
- If the user is not an organizer, show an 'Access Denied' page with a message like 'Only organizers can access the developer portal.'
- If loading keys, webhooks, or logs fails (network error or 500), show a global error banner at the top of the page with the error message and a 'Retry' button. Keep any previously loaded data on screen.

API Keys tab:
- If creating a key fails (validation error, server error), show an error notification with a specific message (e.g., 'Key name is required' or 'Failed to create key. Please try again.').
- If revoking a key fails, show an error notification and keep the key in the table.
- If the key display modal fails to copy to clipboard, show a fallback message like 'Copy failed. Please copy manually.'

Webhooks tab:
- If creating a webhook fails (invalid URL, validation error), show an error notification with the specific issue.
- If deleting a webhook fails, show an error notification and keep the webhook in the table.
- If sending a test payload fails, show an error notification with details (e.g., 'Webhook endpoint returned 500' or 'Connection timeout').
- If the webhook URL is unreachable, show a warning in the webhook row (e.g., 'Last failure: 2 minutes ago').

API Logs tab:
- If loading logs fails, show an error notification but keep any previously loaded logs on screen.
- If loading more logs fails (pagination), show a notification but keep the existing logs.

Documentation tab:
- This is static content, so no error handling needed.

General:
- All error notifications should be dismissible (user can close them).
- Error messages should be user-friendly, not technical jargon (e.g., 'Connection failed' instead of 'ECONNREFUSED').
- If a 401 error occurs (session expired), redirect to the login modal.
- If a 403 error occurs (permission denied), show 'Access Denied'.
- If a 500 error occurs, show a generic 'Something went wrong' message with a retry option.
