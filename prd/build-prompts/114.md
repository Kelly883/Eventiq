We need to add routes for the ticketing feature so organizers can manage their ticket tiers.

Add these routes to your React Router configuration:
- /organizer/events/:eventId/ticketing — The main ticket tier management page (we'll build this in frontend_pages). This is where organizers see all tiers for an event and can create/edit/delete them.
- /organizer/events/:eventId/ticketing/tier/:tierId/edit — Edit a specific tier (optional, could also use a modal on the main page)

Both routes should:
- Require authentication (redirect to login if not authenticated)
- Check that the user is the event organizer (redirect to 403 page if not)
- Load the event and its tiers from the backend

Add a navigation link in the event management sidebar or header that goes to /organizer/events/:eventId/ticketing. Label it 'Ticket Tiers' or 'Pricing'.

When the organizer saves changes to tiers (via the PATCH endpoint), the page should:
- Show a success notification
- Refresh the tier list
- Clear any unsaved changes indicator

If the organizer navigates away with unsaved changes, show a confirmation dialog: 'You have unsaved changes. Leave anyway?'
