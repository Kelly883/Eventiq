We need six reusable components that EventCalendarPage and CalendarDayDetailModal will use. Build these in src/features/events-calendar/components/:

1. CalendarGrid — The main calendar view powered by react-big-calendar. Takes props: events (array of Event), onDateSelect (callback when user clicks a date), view (month|week|day), onViewChange (callback), filters (current filter state). Renders the calendar with color-coded event indicators (green/amber/red for availability). Shows event count on each date. Clicking a date triggers onDateSelect with the selected date. Include month/week/day view toggle buttons at the top.

2. EventCard — Displays a single event in a compact card format. Props: event (Event object), onClick (callback). Shows: event thumbnail/banner, title (truncated if long), organizer avatar and name, date/time, venue name, starting price, and availability status (X tickets remaining or 'Sold Out'). Uses organizer's branding colors for accent elements. Clicking the card triggers onClick.

3. FilterSidebar — Sticky sidebar (desktop) or collapsible drawer (mobile) with filter controls. Props: categories (array), selectedCategory (string|null), onCategoryChange (callback), priceRange ({min, max}), onPriceChange (callback), location (string), onLocationChange (callback), onClearFilters (callback). Shows: category dropdown, price range slider (min/max inputs), location search field, and 'Clear Filters' button. On mobile, collapses to a hamburger menu.

4. SearchBar — Autocomplete search for event titles. Props: onSearch (callback with query), onSelectResult (callback with selected event), placeholder (string). Shows a search input with a magnifying glass icon. As user types, fetch matching events from /api/events/public/search (or use local filtering if data is already loaded). Display results in a dropdown below the input. Debounce search to avoid excessive API calls (300ms delay).

5. DateHeader — Displays the selected date in a readable format. Props: date (ISO8601 string), eventCount (number). Shows formatted date (e.g., 'Friday, March 15, 2024') and event count. Used at the top of CalendarDayDetailModal.

6. AvailabilityIndicator — Small visual indicator showing ticket availability status. Props: availability (available|low|sold_out), ticketsRemaining (number, optional). Renders a colored dot (green/amber/red) with optional text (e.g., '5 tickets left'). Used on EventCard and calendar date cells.

All components should be responsive (work on mobile and desktop), accessible (proper ARIA labels, keyboard navigation), and use consistent styling with the rest of the app.
