We need several reusable components that will be shared across the three analytics pages (SalesAnalyticsDashboardPage, DetailedAnalyticsPage, AnalyticsComparisonPage).

1. MetricCard — A card displaying a single metric (revenue, tickets sold, conversion rate, avg price). Shows the metric value prominently, a label, and a trend indicator (green up arrow for 'up', red down arrow for 'down', gray dash for 'flat'). Takes props: label (string), value (number or string), trend ('up'|'down'|'flat'), format (function to format the value), icon (optional). Used in the summary section of SalesAnalyticsDashboardPage.

2. SalesVelocityChart — A Recharts LineChart showing cumulative sales over time. X-axis is timestamp, Y-axis is cumulative sales count. Takes props: dataPoints (array of SalesVelocityDataPoint), granularity (hour/day/week), isLoading (boolean). Shows a loading skeleton while data loads. Includes interactive tooltips showing exact values on hover.

3. RevenueBreakdownChart — A Recharts BarChart showing revenue by ticket tier. X-axis is tier name, Y-axis is revenue. Takes props: tierData (array of TierPerformance), isLoading (boolean). Color-codes bars by tier. Includes tooltips.

4. SalesDistributionChart — A Recharts PieChart showing sales distribution across pricing windows. Takes props: distributionData (array with label and value), isLoading (boolean). Includes legend and tooltips.

5. ConversionFunnelChart — A custom component (or Recharts BarChart) showing the conversion funnel: page views → ticket page views → purchases. Shows drop-off rates at each stage. Takes props: pageViews (number), ticketPageViews (number), purchases (number), isLoading (boolean).

6. TransactionTable — A virtualized table (using react-window) showing detailed sales transactions. Columns: timestamp, ticket tier, price, buyer email (if available), source. Supports sorting by any column and filtering. Takes props: transactions (array of SalesTimelineEntry), isLoading (boolean), onSort (callback), onFilter (callback). Virtualization ensures it renders fast even with 10,000+ rows.

7. FilterPanel — A sticky sidebar with filter controls. Includes: date range picker (start/end dates), ticket tier multi-select dropdown, pricing window filter, and a 'Clear Filters' button. Takes props: onDateRangeChange (callback), onTierChange (callback), onPricingWindowChange (callback), tiers (array), pricingWindows (array). Used on both SalesAnalyticsDashboardPage and DetailedAnalyticsPage.

8. EventSelector — A component for selecting events to compare. Shows checkboxes for each event (max 3 selectable). Takes props: events (array), selectedEvents (array), onSelectionChange (callback), maxSelectable (number, default 3). Used on AnalyticsComparisonPage.

9. LiveIndicator — A small badge showing 'Live' with a pulsing animation. Indicates that data is being updated in real-time. Takes props: lastUpdatedAt (timestamp), isLive (boolean). Used in the header of SalesAnalyticsDashboardPage.

10. LoadingSkeletons — Placeholder components for loading states. Includes: MetricCardSkeleton, ChartSkeleton, TableRowSkeleton. These show shimmer animations while data loads.

All components should be responsive (work on mobile and desktop), handle loading and error states gracefully, and use consistent styling with the rest of the app.
