We need five reusable components that the dashboard pages will share:

1. MetricCard — A summary card showing a single metric (revenue, tickets sold, conversion rate, event count). Takes a label, value (formatted as currency or percentage), trend indicator (up/down/flat with color coding: green=up, red=down, gray=flat), and optional trend percentage. Used in the top summary section of OrganizerDashboardPage. Shows a loading skeleton while data loads.

2. EventCard — Displays a single event in the grid. Shows event thumbnail image (with fallback icon if missing), event title, date, status badge (color-coded: draft=gray, upcoming=blue, live=green, past=gray), ticket sales progress bar (visual bar showing utilizationPercentage), revenue to date (formatted as currency), attendee count, and three quick-action buttons (Edit, Analytics, Manage Inventory). Tapping the card expands the EventDetailWidget. Takes an event object and callbacks for the three actions.

3. EventDetailWidget — Expandable collapsible card showing detailed metrics for a single selected event. Displays event title, date, venue, status. Shows ticket tier breakdown as a horizontal bar chart with legend (Regular, VIP, VVIP, Early Bird), each tier showing sales progress, revenue, and conversion rate. Pricing window timeline shows current active window and upcoming price changes with countdown timers (color-coded: active=green, upcoming=blue, past=gray). Low-stock alerts highlight tiers below threshold. Three buttons: 'View Full Analytics', 'Manage Inventory', 'Edit Event'. Takes an eventId and callbacks for the three actions.

4. SalesActivityFeed — Real-time scrollable feed showing latest ticket sales. Each activity item is compact (one line per sale) with: event name (color-coded badge on left), ticket tier, quantity sold, price, buyer email (if available), and relative timestamp (e.g., '2 minutes ago'). Clicking an item expands to show full transaction details. Supports filters (by event, tier, date range). Auto-updates every 30 seconds with new sales appearing at top. 'Export Activity' button downloads feed as CSV. Takes optional filters and a callback for the export action.

5. DashboardHeader — Sticky header with filter bar. Shows 'Create New Event' button on left, status filter dropdown (All/Upcoming/Past/Draft) in center, date range picker (7 days/30 days/90 days/All) on right, and a live indicator badge with pulse animation showing 'Live' when auto-refresh is enabled. Takes current filter selections and callbacks for filter changes.

All components should show loading skeletons while data loads, handle empty states gracefully, and be fully responsive (mobile: stacked single-column with collapsible sections).
