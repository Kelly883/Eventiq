We need to set up the Laravel API routes for the two offline sync endpoints and ensure the React app can navigate to pages that use these endpoints.

On the backend, add these routes to routes/api.php inside a middleware group that requires Sanctum authentication:

1. Route::patch('/notifications/device-tokens/{token}/offline-status', [DeviceTokenController::class, 'updateOfflineStatus'])->middleware('auth:sanctum');

2. Route::get('/me/tickets/for-offline-sync', [OfflineSyncController::class, 'getTicketsForOfflineSync'])->middleware('auth:sanctum');

Both routes should be rate-limited. Use Laravel's rate limiting: Route::middleware('throttle:30,1')->patch(...) for the device token endpoint and Route::middleware('throttle:10,1')->get(...) for the sync endpoint.

On the frontend (React), set up axios interceptors to automatically include the X-Device-Token header on all requests. The device token should be retrieved from localStorage (or IndexedDB) and added to every request. If a request returns 401, redirect the user to the login page.

Create a custom hook useOfflineSync() in src/features/offline/hooks/ that handles calling GET /api/me/tickets/for-offline-sync and storing the response in IndexedDB. This hook should manage loading, error, and success states. It should be called when the app initializes and can be called manually by the user via a "Sync Now" button.

Create a custom hook useDeviceToken() that generates, stores, and retrieves the device token. On first app load, generate a unique token (using js-sha256 to hash a combination of user agent and timestamp). Store it in localStorage. Return the token so it can be used in the X-Device-Token header.
