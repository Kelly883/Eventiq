We're building a comprehensive admin panel for platform management. Create a feature folder structure under src/features/admin/ with the following organization:

Pages folder: AdminDashboardPage, AdminUserManagementPage, AdminEventModerationPage, AdminPaymentReconciliationPage — each will be its own file.

Components folder: Break down reusable UI pieces into subfolders:
- dashboard/ (MetricCard, ActivityFeed, AlertsSection, QuickStatsSection, NavigationTiles)
- users/ (UserTable, UserDetailsPanel, BulkActionBar, UserFilters)
- events/ (EventTable, EventDetailsPanel, EventFilters, ModerationNotes)
- payments/ (PaymentTable, PaymentDetailsPanel, PaymentFilters, ReconciliationReport, PaymentMethodChart)
- common/ (AdminHeader with search and date range picker, StatusBadge, RoleBadge, LoadingSkeletons, EmptyStates, ErrorBanner)

Hooks folder: useAdminDashboard, useUserManagement, useEventModeration, usePaymentReconciliation — each handles data fetching and state for its respective page.

Types folder: TypeScript interfaces for Admin, User, Event, Payment, AuditLog, AdminSettings, and API response shapes.

Utils folder: Helpers for formatting currency, dates, status labels, role labels, and audit log descriptions.

On the backend (Laravel), create routes/admin.php for all admin endpoints. Create Controllers/AdminDashboardController, AdminUserController, AdminEventController, AdminPaymentController. Create Models for AdminSettings, AuditLog (if not already present). Create Policies/AdminPolicy to enforce admin-only access.
