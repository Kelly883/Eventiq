We need to set up the routing structure so users can navigate between the dashboard and ticket pages.

Create routes for: /dashboard (UserDashboardPage), /my-tickets (UserTicketsDashboardPage), and /my-tickets/:ticketId (TicketDetailPage). All three routes should be protected — if the user isn't authenticated, redirect to /login with a toast message 'Sign in to view your tickets'.

Set up the route structure in your main router file (likely src/App.tsx or src/router.tsx using React Router v6). Use a ProtectedRoute wrapper component that checks if the user is authenticated (check your AuthContext or auth state). If not authenticated, redirect to /login and save the intended destination so we can return there after login.

Add navigation links: from /dashboard, there should be a 'View Tickets' button that goes to /my-tickets. From /my-tickets, clicking a ticket card should navigate to /my-tickets/:ticketId. From /my-tickets/:ticketId, a back button should return to /my-tickets. From /dashboard, a 'Browse Events' button should navigate to /events (or wherever your events page is).

Set up deep linking so users can share ticket URLs (e.g., /my-tickets/abc123) and when they open it, if they're not logged in, they log in first, then land on that ticket detail page.
