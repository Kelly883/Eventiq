We need to set up the tools for fetching and managing inventory data on the frontend, and ensure the backend is ready to handle requests.

Frontend setup:
1. Install TanStack Query (React Query) — this manages server state, caching, and real-time updates for inventory data. We'll use it to fetch the summary, detailed inventory, and audit logs.
2. Install axios for HTTP requests (or use fetch if preferred). Create an API client at src/features/ticketInventory/api/client.ts that exports functions for each of the five endpoints: getSummary(), getInventory(), adjustInventory(), exportInventory(), getAuditLog(). Each function should accept the eventId and any query parameters, and include the bearer token in the Authorization header.
3. Set up TanStack Query with a QueryClient configured for the inventory feature — cache time 30 seconds for summary/inventory (since it's real-time), 5 minutes for audit logs (less frequently updated).

Backend setup:
1. Ensure Laravel is configured with API authentication (Laravel Sanctum or similar). The InventoryController will check bearer tokens on every request.
2. Install any CSV export packages if not already present (Laravel has built-in CSV support, but confirm it's available).
3. Set up database connection to ensure migrations can run against your database.
