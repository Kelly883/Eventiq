We need to set up the database schema for payment-related data. Create Laravel migrations for the following tables:

1. Enhance the users table — Add these columns if they don't exist: stripe_id (nullable string), pm_type (nullable string), pm_last_four (nullable string), trial_ends_at (nullable timestamp). These fields support Laravel Cashier's functionality.

2. Enhance the organizers table — Add these columns: stripe_account_id (nullable string), stripe_connect_status (nullable string). These track the organizer's Stripe Connect account status.

3. Create the payment_methods table — This stores tokenized payment method records. Fields: id (uuid, primary key), user_id (foreign key to users), gateway (string, e.g., 'stripe'), gateway_payment_method_id (string, the Stripe payment method ID like 'pm_...'), type (string, e.g., 'card'), details (json, stores card brand, last four, expiration), is_default (boolean), created_at (timestamp), updated_at (timestamp). Add a unique index on (user_id, gateway_payment_method_id) to prevent duplicates. Add an index on user_id for fast lookups.

4. Enhance the payments table — Add these columns: refunded_amount (decimal 10,2, nullable), is_fully_refunded (boolean, default false). These track refund information.

For each migration, set up proper timestamps (created_at, updated_at) and soft deletes where appropriate (payment_methods should be soft-deleted, not hard-deleted, to maintain audit trails).

Run php artisan migrate to apply all migrations to your database.
