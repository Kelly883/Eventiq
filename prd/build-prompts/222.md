We need state management to handle the ticket tier form data and sync it with the backend.

Create a custom React hook called useTicketTiers that manages:
- The list of ticket tiers (array of tier objects)
- Loading state (initial load, saving)
- Error state (validation errors, API errors)
- Dirty flag (whether the form has unsaved changes)

The hook should expose these functions:
- loadTiers(eventId): Fetch existing tiers from the backend for a specific event
- addTier(): Add a new blank tier to the list
- updateTier(index, tierData): Update a tier at a specific index
- removeTier(index): Remove a tier from the list
- saveTiers(eventId): Send all tiers to PATCH /api/organizer/events/:eventId and update state on success
- resetTiers(): Discard unsaved changes and reload from the last saved state

The hook should validate each tier before saving: check that name and price are present, price is positive, quantity is positive, early bird price (if set) is less than regular price, dates are in logical order, max per customer is positive if set. Return validation errors so the UI can display them.

When saveTiers succeeds, clear the dirty flag and update the saved state. When it fails, keep the form data intact so the user can retry.

Use React Context or a state management library (like Zustand or Redux) to make this state available to the entire page without prop drilling.
