We need several libraries set up before we build the auth feature.

On the frontend (React), install these packages:
- react-router-dom (already listed, for routing between auth pages)
- axios (for making HTTP requests to the backend)
- Add a .env file with VITE_API_BASE_URL pointing to your Laravel backend (e.g., http://localhost:8000/api)

On the backend (Laravel), ensure these are installed:
- bcrypt (for hashing passwords — Laravel includes this by default)
- laravel-sanctum (for token-based authentication — run php artisan vendor:publish --provider="Laravel\Sanctum\SanctumServiceProvider")
- laravel-mail (for sending password reset emails — configure MAIL_DRIVER in .env, use 'log' for development)

Set up Laravel environment variables in .env:
- APP_KEY (generate with php artisan key:generate if not already set)
- DB_CONNECTION, DB_HOST, DB_PORT, DB_DATABASE, DB_USERNAME, DB_PASSWORD (for your database)
- MAIL_DRIVER=log (for development, so reset emails print to logs instead of actually sending)
- SANCTUM_STATEFUL_DOMAINS (set to localhost:5173 for local development)

Create a .env.example file documenting these variables so other developers know what to set.

On the frontend, create a src/lib/api.ts file that exports an axios instance configured with the base URL and interceptors to attach the auth token to every request.
