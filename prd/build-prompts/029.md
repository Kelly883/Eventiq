We need three libraries set up before building the role management feature:

1. Data fetching — Install TanStack Query (React Query) on the frontend. This will handle fetching users, roles, permissions, and audit logs with automatic caching and refetching. We'll use it to manage the loading, error, and success states for all the admin endpoints.

2. State management — Install Zustand on the frontend. We'll use it for global state like the current user's role and permissions, selected users in bulk actions, and filter/sort preferences on the admin dashboard.

3. Laravel authentication — On the backend, make sure Laravel's built-in authentication is configured. We'll use Laravel Policies to enforce admin-only access on all role and permission endpoints. Create a middleware that checks if the authenticated user is an admin before allowing access to /api/admin/* routes.

Set up environment variables: VITE_API_BASE_URL on the frontend (points to your Laravel API), and APP_KEY, DB_CONNECTION, and DB_HOST on the backend. Make sure CORS is configured so the React frontend can call the Laravel API.
