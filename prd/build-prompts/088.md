We need to define the data models on both the backend (Laravel Eloquent) and frontend (TypeScript) so we can work with inventory data consistently.

Backend (Laravel):
1. Create app/Models/TicketInventory.php as an Eloquent model with:
   - Fillable fields: total_allocated, total_sold, total_available, low_stock_threshold, is_low_stock, last_updated_at
   - Relationships: belongsTo(Event), belongsTo(TicketTier), hasMany(InventoryAdjustment)
   - Accessor for total_available: computed as total_allocated - total_sold
   - Accessor for is_low_stock: computed as total_available <= low_stock_threshold
   - Method updateFromPricingWindows() to recalculate totals from related pricing_windows

2. Create app/Models/InventoryAdjustment.php as an immutable Eloquent model with:
   - Fillable fields: event_id, ticket_tier_id, pricing_window_id, organizer_id, adjustment_type, quantity_before, quantity_after, reason
   - Accessor for quantity_delta: computed as quantity_after - quantity_before
   - Relationships: belongsTo(Event), belongsTo(TicketTier), belongsTo(PricingWindow, 'pricing_window_id'), belongsTo(User, 'organizer_id')
   - Scope: forEvent($eventId) to filter by event

Frontend (TypeScript):
1. Create src/features/ticketInventory/types/inventory.ts with interfaces:
   - TicketInventory: { id, eventId, ticketTierId, totalAllocated, totalSold, totalAvailable, lowStockThreshold, isLowStock, lastUpdatedAt, createdAt, updatedAt }
   - InventoryAdjustment: { id, eventId, ticketTierId, pricingWindowId, organizerId, adjustmentType, quantityBefore, quantityAfter, quantityDelta, reason, createdAt }
   - InventorySummary: { totalCapacity, totalSold, totalAvailable, utilizationPercentage, lowStockTierCount, tiers: TicketInventoryTierSummary[] }
   - TicketInventoryTierSummary: { tierId, tierName, allocated, sold, available, isLowStock }
   - AdjustmentType: 'manual_increase' | 'manual_decrease' | 'reallocation' | 'system_correction'

2. Create helper functions in src/features/ticketInventory/utils/:
   - formatUtilizationPercentage(sold, allocated): returns percentage string (e.g., '45%')
   - calculateLowStock(available, threshold): returns boolean
   - formatQuantityDelta(delta): returns '+50' or '-20' with color coding
