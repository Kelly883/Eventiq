We're building a tiered ticketing system for event organizers. This feature lets them create and manage multiple ticket tiers with different pricing, benefits, early bird discounts, and purchase limits.

On the frontend (React + Vite), create a ticketing feature area under src/features/ticketing/ with these subfolders:
- components/ — for reusable UI pieces like TicketTierCard, TicketTierForm, BenefitsDisplay, PricingComparison, and EarlyBirdBadge
- hooks/ — for custom React hooks like useTicketTiers, useUpdateTicketTiers, and useEarlyBirdCalculations
- types/ — for TypeScript interfaces matching the ticket_tiers schema
- utils/ — for helper functions like price formatting, date validation, and tier comparison logic
- pages/ — we'll add the tier management page here

On the backend (Laravel), create a ticketing feature area under app/Features/Ticketing/ with:
- Models/ — TicketTier model
- Requests/ — UpdateTicketTiersRequest for validation
- Resources/ — TicketTierResource for API responses
- Services/ — TicketTierService for business logic
- Controllers/ — EventTicketingController for the PATCH endpoint

This structure keeps ticketing logic separate from the rest of the event management system and makes it easy to test and maintain.
