We need to extend the existing tickets table with QR code-specific fields. Create a Laravel migration that adds these columns to the tickets table:

1. qrCodeData (text, nullable) — Stores the encrypted QR payload as base64
2. qrCodeSecret (string, nullable) — Stores the bcrypt-hashed secret for verification
3. qrCodeGeneratedAt (timestamp, nullable) — When the QR code was generated
4. qrCodeExpiresAt (timestamp, nullable) — When the QR code expires (typically event end + 7 days)
5. checkedInAt (timestamp, nullable) — When the ticket was checked in at the venue
6. checkedInBy (uuid, nullable, foreign key to users table) — Which staff member checked in the ticket
7. qrCodeScannedCount (integer, default 0) — How many times this QR has been scanned
8. lastQrScanAt (timestamp, nullable) — Last time this QR was scanned

Also add indexes on: (eventId, status) for fast filtering, (eventId, checkedInAt) for analytics queries, and (qrCodeExpiresAt) for finding expired QRs.

Run the migration to apply these changes to your database. Make sure the foreign key constraint on checkedInBy references the users table correctly.
