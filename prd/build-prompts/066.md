We need to set up the database tables that will store all checkout and payment data.

Create Laravel migrations for four tables:

1. orders table — Stores each purchase transaction. Fields: id (UUID primary key), user_id (foreign key to users), event_id (foreign key to events), total_amount (decimal 10,2), currency (string 3), status (enum: pending, completed, failed, refunded), payment_gateway (string), payment_intent_id (string, unique), created_at, updated_at. Add indexes on user_id and status for fast queries. The status field should default to 'pending'.

2. order_items table — Stores line items for each order. Fields: id (UUID), order_id (foreign key to orders), ticket_tier_id (foreign key to ticket_tiers), quantity (integer), unit_price (decimal 10,2), created_at, updated_at. Add an index on order_id.

3. tickets table — Stores the final, unique tickets issued to users. Fields: id (UUID), order_id (foreign key to orders), user_id (foreign key to users), event_id (foreign key to events), ticket_tier_id (foreign key to ticket_tiers), qr_code_data (text), status (enum: valid, checked_in, void), checked_in_at (nullable timestamp), created_at, updated_at. Add indexes on user_id and event_id for fast lookups.

4. payments table — Audit log of all payment attempts. Fields: id (UUID), order_id (foreign key to orders), payment_intent_id (string), amount (decimal 10,2), currency (string 3), status (string), gateway (string), gateway_response (JSON), created_at, updated_at. Add an index on order_id.

Run the migrations to create all tables. Verify that all foreign keys are set up correctly and that indexes are created.
