Now we need to connect the pricing pages to the rest of the organizer dashboard.

Add a route for /organizer/events/:eventId/pricing that renders EventPricingConfigPage. This route should be protected — only organizers who own the event can access it. If they try to access an event they don't own, show 'Access Denied'.

On the existing event detail page or event management dashboard, add a 'Pricing' tab or link that navigates to /organizer/events/:eventId/pricing. Make sure the link only appears for events that the organizer owns.

The PricingPreviewModal should be triggered from the 'Preview' button on EventPricingConfigPage. When the modal closes, the user should stay on the config page (not navigate away).

Wire up the success flow: after the user saves pricing changes, show a 'Pricing updated' toast. If they click 'View Pricing' in the toast (optional), navigate to the preview modal. After they close the preview modal, they should be back on the config page.

Handle the error flow: if the user gets a 401 (session expired), redirect to the login page. If they get a 403 (don't own the event), show 'Access Denied' and a link back to the event list. If they get a 404 (event not found), show 'Event not found' and a link back to the event list.
