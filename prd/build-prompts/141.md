We need six API endpoints for the pricing feature. All organizer endpoints require authentication and event ownership.

1. GET /api/organizer/events/:eventId/pricing/windows — List pricing windows for an event. Query params: ?categoryId=uuid (optional filter). Returns paginated list of windows with computed isActive field. Eager load ticket_tiers for category names. Sort by startDateTime ascending. Check event ownership via Policy.

2. POST /api/organizer/events/:eventId/pricing/windows — Create a new pricing window. Validate input: windowName required, startDateTime < endDateTime, endDateTime <= event.endDateTime, price > 0, quantityLimit > 0 if provided. Check for overlapping windows with same ticketCategoryId (return 409 if overlap exists). Verify ticketCategoryId belongs to this event. Create record with isActive computed, quantitySold=0. Return 201 with created window.

3. PATCH /api/organizer/events/:eventId/pricing/windows/:windowId — Update a pricing window. Validate dates if provided. Check for overlapping windows (excluding current window). Update only provided fields. Return 200 with updated window.

4. DELETE /api/organizer/events/:eventId/pricing/windows/:windowId — Soft-delete a pricing window (set deletedAt). Return 200 with success message.

5. GET /api/organizer/events/:eventId/pricing/preview — Get preview of pricing schedule for organizer. Returns structured data showing how attendees will see pricing, grouped by category with all windows. Requires event ownership.

6. GET /api/attendee/events/:eventId/pricing — Public endpoint (no auth required) for attendees. Returns only active pricing windows for published events. Returns current active price, next price, and quantity available per category. Rate limit 30/min per IP.

Create controllers at app/Features/Pricing/Controllers/PricingWindowController.php and app/Features/Pricing/Controllers/PricingController.php. Use FormRequest classes (StorePricingWindowRequest, UpdatePricingWindowRequest) for validation. Use PricingWindowPolicy for authorization. Return responses using PricingWindowResource. Add rate limiting middleware: 10/min for organizer creates/updates/deletes, 20/min for list, 20/min for preview, 30/min for attendee endpoint.
