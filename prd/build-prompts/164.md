We need six reusable React components that both AdminRoleManagementPage and UserPermissionsPage will use:

1. RoleTable — A sortable, filterable table showing users with their current role and permission count. Columns: checkbox (for bulk selection), email, name, role (color-coded badge: Admin=red, Organizer=blue, Attendee=green, Support=orange), permission count, created date. Clicking a row expands it to show permission details. Sorting by any column. Accepts props: users (array), isLoading (boolean), onSelectUser (callback), onSelectAll (callback), selectedUserIds (array). Used on AdminRoleManagementPage.

2. PermissionCard — A collapsible card showing a permission category (Event Management, Ticket Management, Analytics, User Management) with a list of specific permissions inside. Each permission shows as a row with: permission name, description, and a toggle switch (for admin) or read-only badge (for user). Accepts props: category (string), permissions (array), isAdmin (boolean), onTogglePermission (callback), isLoading (boolean). Used on both pages.

3. AuditLogViewer — A collapsible section showing recent role/permission changes. Displays as a table with columns: timestamp, admin name, target user, action (role_assigned, permission_granted, etc.), old value, new value, reason. Sortable by date. Accepts props: logs (array), isLoading (boolean), onLoadMore (callback). Used on AdminRoleManagementPage.

4. BulkActionBar — A sticky bar that appears when users are selected in the RoleTable. Shows: 'X users selected', a role dropdown to assign to all selected users, a 'Reason' text field (optional), and 'Apply' and 'Cancel' buttons. Accepts props: selectedCount (number), onApply (callback with {roleId, reason}), onCancel (callback), isLoading (boolean). Used on AdminRoleManagementPage.

5. PermissionRequestModal — A modal dialog for requesting elevated permissions. Shows: a dropdown to select which permission to request, a text area for optional reason (max 500 chars), and 'Request' and 'Cancel' buttons. Accepts props: permissions (array), onSubmit (callback with {permissionId, reason}), isOpen (boolean), onClose (callback), isLoading (boolean). Used on UserPermissionsPage.

6. RoleBadge — A simple badge component that displays a role name with color coding (Admin=red, Organizer=blue, Attendee=green, Support=orange). Accepts props: role (string), size ('sm' | 'md' | 'lg'). Used throughout both pages.

All components should handle loading states (skeleton placeholders), empty states (friendly messages), and error states (error messages with retry options). Use TanStack Query for data fetching where needed.
