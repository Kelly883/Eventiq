We need to set up the routing and navigation for the check-in feature in the React app.

Create these routes:
- /check-in — Main check-in page (the primary interface for venue staff)
- /check-in/search — Dedicated search page (for finding attendees by ticket/email/name)
- /check-in/stats — Statistics dashboard (real-time check-in metrics)
- /check-in/export — Export page (download check-in data as CSV or JSON)
- /check-in/history — Audit log viewer (see all check-in actions for compliance)

Add a top-level navigation item or menu that links to /check-in. This should only be visible to users with VenueStaff or Organizer roles — check the user's role from the auth context before rendering.

On the main check-in page (/check-in), add a navigation bar with tabs or buttons to switch between:
- Quick Check-In (QR scanner + search)
- Statistics (real-time stats)
- Export Data
- History (audit log)

Implement a breadcrumb or back button so users can navigate between pages. Make sure the event context is preserved across all pages (users should be able to select which event they're checking in for).

Add a loading state that shows while the app is verifying the user's role and fetching initial data. If the user doesn't have the required role, show a 'Not Authorized' message with a link back to the home page.
