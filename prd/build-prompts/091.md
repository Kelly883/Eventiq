We need to create Laravel Eloquent models that represent the events schema and related data. These models will handle all database queries and relationships.

Create the Event model (app/Models/Event.php) with:
- All fields from the events schema (id, status, title, description, category, banner_image_url, start_datetime, end_datetime, venue_name, venue_address, venue_latitude, venue_longitude, capacity, organizer_id, user_id, createdAt, updatedAt, deleted_at)
- Relationships: belongsTo(Organizer), hasMany(TicketTier), hasMany(PricingWindow), hasOne(AnalyticsEventsMetrics)
- Scopes: published() (filters status='published'), upcomingFirst() (orders by start_datetime ascending), byCategory($category), byOrganizer($organizerId)
- Soft delete trait (SoftDeletes)
- Fillable array with all mutable fields
- Casts for timestamps and decimal fields

Create the Organizer model (app/Models/Organizer.php) with:
- Fields: id, name, avatar_url, bio, website, social_links (JSON), branding_colors (JSON), privacy_settings (JSON), createdAt, updatedAt
- Relationships: hasMany(Event)
- Methods to get public profile data (filtering sensitive info based on privacy settings)

Create the TicketTier model (app/Models/TicketTier.php) with:
- Fields: id, event_id, name, base_price, quantity_total, quantity_sold, tier_order, createdAt, updatedAt
- Relationships: belongsTo(Event)

Create the PricingWindow model (app/Models/PricingWindow.php) with:
- Fields: id, event_id, tier_id, price, start_datetime, end_datetime, createdAt, updatedAt
- Relationships: belongsTo(Event), belongsTo(TicketTier)
- Scope: active() (filters current time between start_datetime and end_datetime)

Create the AnalyticsEventsMetrics model (app/Models/AnalyticsEventsMetrics.php) with:
- Fields: id, event_id, tickets_sold, trending_score, views_count, createdAt, updatedAt
- Relationships: belongsTo(Event)

Also create TypeScript interfaces on the frontend (src/features/events/types/index.ts) that mirror these models: Event, Organizer, TicketTier, PricingWindow, AnalyticsEventsMetrics. These will be used for type safety in React components.
