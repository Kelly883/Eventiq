We need five reusable React components for the ticketing feature:

1. TicketTierCard — Displays a single tier in a card format. Shows:
   - Tier name (prominent)
   - Regular price (large, formatted)
   - Early bird badge if active (e.g., 'Early Bird: $39.99')
   - Benefits description (if present, truncated with 'Read more' link)
   - Tier image (if present, with fallback placeholder)
   - Quantity remaining (e.g., '45 of 100 available')
   - Sales date range (e.g., 'On sale until Dec 25')
   - Max per customer limit (if set, e.g., 'Limit 5 per person')
   - A callback prop for when the card is clicked or a button is tapped
   - Loading state (skeleton)

2. TicketTierForm — A form for creating or editing a tier. Fields:
   - Name (text input, required)
   - Price (number input, required, > 0)
   - Quantity (number input, required, > 0)
   - Sales start date (datetime picker, optional)
   - Sales end date (datetime picker, optional, validated to be after start)
   - Benefits description (textarea, optional)
   - Tier image URL (text input or file upload, optional)
   - Early bird price (number input, optional, < regular price)
   - Early bird end date (datetime picker, optional)
   - Max per customer (number input, optional, > 0)
   - Submit and Cancel buttons
   - Validation errors displayed inline
   - Loading state on submit

3. BenefitsDisplay — Shows the benefits_description in a readable format. If the description is long, show a truncated version with an expandable 'Read more' button. Include a close button if it's in an expanded modal.

4. PricingComparison — Compares multiple tiers side-by-side. Shows each tier's name, regular price, early bird price (if active), and a visual indicator of which is the best value. Used to help customers choose.

5. EarlyBirdBadge — A small badge component that displays 'Early Bird' with the discounted price. Only renders if early bird is active. Shows the discount percentage (e.g., '20% off').

All components should:
- Accept a TicketTier object as a prop
- Use the helper functions from src/features/ticketing/types/index.ts for calculations
- Be responsive (work on mobile and desktop)
- Have loading and error states where appropriate
- Use consistent styling with the rest of the app
