We need several reusable React components that the fraud dashboard pages will share. These components handle the complex UI patterns for displaying fraud data and managing admin actions.

1. FraudMetricCard — Displays a single metric card (e.g., total flagged transactions, fraud risk distribution, blocked orders count). Props: title (string), value (number or string), trend (up/down/neutral), trendPercent (number), icon (React component), color (string for badge color). Shows the metric prominently with a trend indicator. Used in the summary section at the top of FraudDetectionDashboardPage.

2. RiskBadge — Displays a color-coded risk level badge. Props: riskLevel ('low' | 'medium' | 'high'), riskScore (number). Shows the risk level text with appropriate background color (green for low, amber for medium, red for high) and the numeric score. Reusable across the dashboard and modal.

3. FraudFactorsDisplay — Shows the fraud factors that triggered the flag. Props: fraudFactors (object with boolean flags), detectionMethod (string). Renders a list of human-readable factors (e.g., 'Duplicate ticket detected', 'Velocity check failed') with icons. Used in both the table and the detail modal.

4. VelocityMetricsPanel — Displays user velocity metrics in a readable format. Props: velocityMetrics (object), paymentMethodVelocity (object). Shows: orders in 24h, total spend in 24h, average order value, orders in last hour, and payment method velocity (users on same card, total spend on card). Used in the expandable row details and the detail modal.

5. FilterBar — Sticky filter controls for the dashboard. Props: onFilterChange (callback), filters (current filter state). Renders: risk level filter (dropdown: All, Low, Medium, High), date range picker (start/end dates), payment method filter (dropdown), and a clear filters button. Emits filter changes to parent. Used at the top of FraudDetectionDashboardPage.

6. FraudTransactionTable — Sortable, paginated table of flagged transactions. Props: transactions (array), isLoading (boolean), onRowClick (callback), sortBy (string), sortOrder (string), onSort (callback), page (number), limit (number), total (number), onPageChange (callback). Renders columns: order ID, amount, buyer email, timestamp, risk score (with badge), reason flagged (fraud factors), status, and expandable row for details. Shows skeleton rows while loading. Used in FraudDetectionDashboardPage.

7. ActionButtons — Approve/Reject buttons for reviewing flagged transactions. Props: status (string), onApprove (callback), onReject (callback), isLoading (boolean), disabled (boolean). Shows approve (green) and reject (red) buttons. Disabled if already reviewed or loading. Used in the detail modal.

8. ConfirmationDialog — Modal dialog for confirming approve/reject actions. Props: isOpen (boolean), title (string), message (string), confirmText (string), cancelText (string), onConfirm (callback), onCancel (callback), isLoading (boolean), isDangerous (boolean for red styling). Renders a centered modal with message and two buttons. Used when admin clicks approve/reject.

All components should handle loading states with skeleton/shimmer effects, error states with clear messages, and be fully responsive (mobile-friendly). Use TypeScript for type safety and export all components from src/features/fraud/components/index.ts for easy importing.
