We need to install and set up several packages to support event creation and management.

On the frontend (React + Vite), install these packages:
- react-router (already likely installed, but ensure it's up to date) — for routing to OrganizerEventListPage, EventCreatePage, and EventEditPage
- swr — for data fetching and caching from the API endpoints
- react-hook-form — for form state management in EventCreatePage and EventEditPage
- @tiptap/react, @tiptap/starter-kit — for the rich-text editor in the event description field
- axios (if not already installed) — for making HTTP requests to the backend

On the backend (Laravel), ensure these are installed:
- laravel-sanctum — for API token authentication (should already be part of Laravel)
- eloquent (built into Laravel) — for database queries and relationships
- laravel-storage — for file uploads (built into Laravel)

Set up Laravel Sanctum by running php artisan vendor:publish --provider="Laravel\Sanctum\SanctumServiceProvider" if not already done. This enables token-based authentication for API requests.

Create a .env file on the backend with these keys (if not already present):
- APP_URL (your backend URL)
- SANCTUM_STATEFUL_DOMAINS (your frontend domain)
- FILESYSTEM_DISK (set to 's3' or 'local' depending on your setup)
- AWS_* keys if using S3 for banner image storage

On the frontend, create a .env file with:
- VITE_API_BASE_URL (your backend API URL, e.g., http://localhost:8000/api)

This ensures both frontend and backend can communicate securely.
