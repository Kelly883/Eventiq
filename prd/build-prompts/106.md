We need two Eloquent models to represent the database tables and handle data access:

1. AccessibilityPreference model (app/Models/AccessibilityPreference.php):
- Extend Illuminate\Database\Eloquent\Model
- Use SoftDeletes trait for soft delete support
- Set $fillable to include all preference fields: fontSize, highContrast, screenReaderOptimized, focusIndicatorEnhanced, motionReduced, lineHeight, letterSpacing, wordSpacing, colorBlindnessMode
- Define a belongsTo relationship to User model
- Add a static method getOrCreateForUser($userId) that queries by userId, or creates a new record with defaults if not found
- Add a method toArray() that returns all preference fields in a clean format for API responses
- Add validation rules as a static property: fontSize must be 12-24, lineHeight 1.0-2.0, letterSpacing 0-0.2, wordSpacing 0-0.2, colorBlindnessMode must be one of 'none', 'protanopia', 'deuteranopia', 'tritanopia'

2. LanguagePreference model (app/Models/LanguagePreference.php):
- Extend Illuminate\Database\Eloquent\Model
- Use SoftDeletes trait
- Set $fillable to include: language, region, dateFormat, timeFormat, currency, numberFormat, rtlEnabled
- Define a belongsTo relationship to User model
- Add a static method getOrCreateForUser($userId) that queries by userId, or creates a new record with defaults if not found
- Add a method toArray() that returns all preference fields
- Add validation rules: language must be a supported ISO 639-1 code, dateFormat must be one of 'MM/DD/YYYY', 'DD/MM/YYYY', 'YYYY-MM-DD', timeFormat must be '12-hour' or '24-hour', numberFormat must be 'comma' or 'period'
- Add a method detectRTL() that returns true if language is Arabic (ar), Hebrew (he), or Urdu (ur)

Both models should use UUID as the primary key (set $keyType = 'string' and use HasUuids trait).
