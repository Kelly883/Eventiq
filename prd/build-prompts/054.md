We need to set up Stripe on both the frontend and backend, plus Laravel Cashier for payment processing.

Frontend setup (React + Vite):
1. Install @stripe/react-stripe-js and @stripe/stripe-js packages
2. Create a Stripe configuration file at src/features/payment/utils/stripe-config.ts that exports your Stripe public key (from environment variables, never hardcode it)
3. Wrap your app with the StripeProvider at the root level so all payment components can access Stripe
4. Store the Stripe public key in your .env.local file as VITE_STRIPE_PUBLIC_KEY

Backend setup (Laravel):
1. Install laravel/cashier and stripe/stripe-php via Composer
2. Publish Cashier's configuration: php artisan vendor:publish --tag=cashier-config
3. Add Stripe API keys to your .env file: STRIPE_PUBLIC_KEY and STRIPE_SECRET_KEY (get these from your Stripe dashboard)
4. Add STRIPE_WEBHOOK_SECRET to .env — you'll get this when you set up webhooks in Stripe
5. Ensure your User model uses the Billable trait from Laravel Cashier: use Laravel\Cashier\Billable
6. Create a Stripe webhook endpoint in your Stripe dashboard pointing to /api/webhooks/stripe on your server

Test that Stripe is initialized correctly by checking that the Stripe object is available in your frontend code and that the backend can connect to Stripe's API.
