We need three things set up before building the offline sync feature:

1. Offline storage — Install idb (IndexedDB wrapper) for client-side caching of tickets and sync metadata. This gives us a reliable way to store data for offline access without hitting localStorage size limits. We'll use this to cache the ticket data returned from GET /api/me/tickets/for-offline-sync.

2. Device token management — Install react-native-device-info (or a browser equivalent like js-sha256 for generating device identifiers). We need a way to generate and persist a unique device token that identifies this specific device. This token gets sent in the X-Device-Token header to the backend so it can track which device last synced.

3. HTTP client setup — Make sure axios is installed and configured with interceptors. We'll need to add the X-Device-Token header to requests automatically, and handle 401 responses by redirecting to login.

On the backend, Laravel Sanctum is already specified in the packages. Make sure it's installed and configured in config/sanctum.php. Sanctum handles bearer token authentication for the two endpoints we'll build.

Create a .env variable VITE_API_BASE_URL pointing to your Laravel backend (e.g., http://localhost:8000). This keeps the API URL configurable across environments.
