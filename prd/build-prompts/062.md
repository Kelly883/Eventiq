We need to set up three analytics tables in the database to store metrics, sales timeline data, and tier performance data.

Create three Laravel migrations:

1. analytics_events_metrics table — This stores aggregate metrics per event. Fields: id (UUID primary key), eventId (UUID, foreign key to events), organizerId (UUID, foreign key to organizers), totalRevenue (decimal 12,2), totalTicketsSold (integer), totalPageViews (integer), totalTicketPageViews (integer), conversionRate (decimal 5,2), averageTicketPrice (decimal 10,2), peakSalesHour (integer, nullable), topTicketTier (UUID, nullable), lastUpdatedAt (timestamp), createdAt (timestamp), updatedAt (timestamp). Add indexes on eventId and organizerId for fast lookups.

2. analytics_sales_timeline table — This is an immutable time-series log of every ticket sale. Fields: id (UUID primary key), eventId (UUID, foreign key), ticketTierId (UUID, foreign key), pricingWindowId (UUID, nullable, foreign key), saleTimestamp (timestamp), quantity (integer), unitPrice (decimal 10,2), totalAmount (decimal 12,2), buyerEmail (string, nullable, hashed), source (string, nullable), createdAt (timestamp). Add indexes on eventId and saleTimestamp for time-series queries. This table grows with every sale, so indexes are critical.

3. analytics_tier_performance table — This stores per-tier metrics. Fields: id (UUID primary key), eventId (UUID, foreign key), ticketTierId (UUID, foreign key), totalSold (integer), totalRevenue (decimal 12,2), averagePrice (decimal 10,2), percentageOfTotalSales (decimal 5,2), percentageOfTotalRevenue (decimal 5,2), conversionRate (decimal 5,2), lastUpdatedAt (timestamp), createdAt (timestamp), updatedAt (timestamp). Add indexes on eventId and ticketTierId.

Run php artisan migrate to apply all migrations. Set up database constraints so that deleting an event cascades to delete its analytics records (or soft-delete them).

Also set up a database trigger or Laravel observer to automatically create an analytics_events_metrics record when a new event is created, initializing all metrics to zero.
