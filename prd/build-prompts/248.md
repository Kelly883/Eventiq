Now we need to connect the DeveloperPortalPage to the rest of the app.

Add a route for /developer that renders DeveloperPortalPage. This route should be protected — only authenticated users with the 'organizer' role can access it. If a non-organizer tries to access it, they should see the 'Access Denied' page. If an unauthenticated user tries to access it, redirect to the login modal.

Add a navigation link to the developer portal in the main app navigation (sidebar, header menu, or settings). Label it 'Developer' or 'API & Integrations'. This link should only be visible to organizers.

Wire up these connections:
- When an API key is successfully created, show a success notification and display the key in the modal
- When a key is revoked, show a success notification and refresh the keys table
- When a webhook is created, show a success notification and refresh the webhooks table
- When a webhook is deleted, show a success notification and refresh the webhooks table
- When a test payload is sent, show a success or error notification depending on the result
- Deep linking to /developer should work for authenticated organizers; non-organizers see 'Access Denied'
