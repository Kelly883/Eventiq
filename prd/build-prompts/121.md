We need to add routes for the fraud detection pages and integrate them into the app's navigation.

Add two routes to your React router configuration:
1. /admin/fraud/dashboard — FraudDetectionDashboardPage (admin-only)
2. /admin/fraud/dashboard (with modal overlay) — FraudTransactionReviewModal (triggered from dashboard, admin-only)

Both routes require admin authentication. If a non-admin user tries to access /admin/fraud/dashboard, redirect to /login with a toast message 'Access Denied — only admins can view fraud dashboard'.

Add a navigation link in the admin sidebar or navigation menu that says 'Fraud Detection' or 'Fraud Dashboard' and links to /admin/fraud/dashboard. This link should only be visible to users with the 'Admin' role.

The FraudTransactionReviewModal should be rendered as a modal overlay on top of the dashboard page (not a separate route). When an admin clicks on a flagged transaction in the table, the modal opens with that transaction's details. Closing the modal returns focus to the dashboard table.

Implement route guards using React Router's ProtectedRoute or similar pattern to check user role before rendering the fraud pages. If the user's auth token expires while viewing the fraud dashboard, redirect to /login with a 'Session expired' toast.
