We need to add routes for the two inventory pages so organizers can access them from the app.

Add these routes to your React Router configuration:
- /organizer/events/:eventId/inventory → TicketInventoryDashboardPage (the main dashboard)
- /organizer/events/:eventId/inventory/adjust → AdjustInventoryModal (triggered from the dashboard, but also accessible directly if needed)

The TicketInventoryDashboardPage should be a protected route that checks:
1. User is authenticated (has a valid bearer token)
2. User owns the event (check via the event ownership check on the backend)
3. If either check fails, redirect to /login with a 'Session expired' or 'Access Denied' message

The AdjustInventoryModal is typically opened as a modal overlay from the dashboard (not a separate page), but it should also be accessible via the route above if needed.

Add a navigation link in the event organizer dashboard or sidebar that goes to /organizer/events/:eventId/inventory. The link text should be 'Inventory' or 'Manage Inventory'.

When the user navigates to the inventory page, the TicketInventoryDashboardPage should immediately fetch the summary and detailed inventory data using the API client functions (getSummary() and getInventory()).
