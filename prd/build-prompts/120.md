We need to add routes for the four checkout pages to the React Router configuration.

Add these routes to your router (using react-router-dom):

1. /cart — CartPage. This route is accessible to both authenticated and unauthenticated users (cart is stored in local storage). The page displays items from CartContext.

2. /checkout — CheckoutPage. This route requires authentication. If the user is not logged in, redirect to /login with a return URL so they come back to checkout after signing in. This page handles the multi-step checkout flow: verify cart, collect billing info, process payment.

3. /order/:orderId/confirmation — OrderConfirmationPage. This route requires authentication. The orderId comes from the URL params. The page fetches order details from GET /api/orders/:orderId. If the order doesn't exist (404) or the user doesn't own it (403), show an appropriate error message.

4. /my-tickets — UserTicketsPage. This route requires authentication. If not logged in, redirect to /login. The page fetches tickets from GET /api/my-tickets.

For the /checkout route, also add a guard that checks if the cart is empty. If it is, redirect to /cart with a message 'Your cart is empty'.

For the /order/:orderId/confirmation route, add a guard that verifies the user is authenticated before attempting to fetch the order.

Use react-router-dom's useNavigate hook to handle redirects and useParams to extract the orderId from the URL.
