We need to add three new routes to the app's router for the analytics pages. These routes should only be accessible to authenticated organizers.

Add these routes (using React Router or your framework's routing):

1. /organizer/events/:eventId/analytics — Routes to SalesAnalyticsDashboardPage. This is the main analytics dashboard showing summary metrics and charts.

2. /organizer/events/:eventId/analytics/detailed — Routes to DetailedAnalyticsPage. This is the deep-dive page with transaction tables and detailed breakdowns.

3. /organizer/analytics/compare — Routes to AnalyticsComparisonPage. This is the cross-event comparison page.

All three routes should be protected by an auth guard that checks:
- User is authenticated (has a valid bearer token)
- User is an organizer (has the organizer role)
- For the first two routes, the user owns the event (checked via the backend Policy)

If the user is not authenticated, redirect to /login. If the user is authenticated but doesn't own the event, show a 403 error page.

Add navigation links:
- From the event detail page, add a link to the analytics dashboard (/organizer/events/:eventId/analytics)
- From the organizer dashboard, add a link to the comparison page (/organizer/analytics/compare)
- From the analytics dashboard, add a link to the detailed analytics page (/organizer/events/:eventId/analytics/detailed)
- Add a back button on both detailed and comparison pages to return to the previous page

The routes should preserve query params (like date range filters) when navigating between pages, so users don't lose their filter state.
