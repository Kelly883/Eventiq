We need three libraries set up before building the dashboard:

1. TanStack Query (React Query) — Install @tanstack/react-query. This will handle all data fetching, caching, and real-time updates for the dashboard metrics, event cards, and activity feed. Initialize a QueryClient in your main app file with sensible defaults: staleTime of 30 seconds (since the dashboard auto-refreshes every 30 seconds), cacheTime of 5 minutes, and retry logic that backs off exponentially.

2. Zustand — Install zustand for lightweight client-side state management. We'll use this to store UI state like which event is expanded, filter selections, and whether the activity feed is visible. This keeps the state separate from server data (which React Query handles).

3. React Router — Install react-router-dom if not already present. We'll use this for navigation to the dashboard and for deep linking to specific events or analytics pages.

Set up a QueryClientProvider wrapper at the root of your app so all components can access React Query. Create a Zustand store for dashboard UI preferences (filters, expanded sections, etc.) that persists to localStorage so preferences survive page refreshes.
