We're building a comprehensive role and permission management system for admins and users. For this step, create a feature folder structure that separates admin-facing and user-facing functionality.

On the frontend (React + Vite), create src/features/roles/ with these subfolders:
- pages/ (for AdminRoleManagementPage and UserPermissionsPage)
- components/ (for reusable UI pieces like RoleTable, PermissionCard, AuditLogViewer, BulkActionBar, PermissionRequestModal)
- hooks/ (for custom hooks like useRoleList, usePermissionUpdate, useAuditLog, usePermissionRequests)
- types/ (for TypeScript interfaces: Role, Permission, AuditLog, PermissionRequest, User)
- services/ (for API client functions that call the backend endpoints)
- store/ (for Zustand state management if needed for global role/permission state)

On the backend (Laravel), create app/Http/Controllers/Admin/RoleController.php and app/Http/Controllers/Admin/PermissionController.php. Create app/Models/Role.php, Permission.php, AuditLog.php, and PermissionRequest.php. Create app/Policies/RolePolicy.php and PermissionPolicy.php to enforce admin-only access.

This structure keeps admin operations separate from user-facing permission views, making it easier to maintain and secure.
