We need to set up the SDKs and libraries that power ticket delivery across multiple channels.

Frontend: Install qrcode.react via npm. This generates QR codes for the TicketStatusPage display. Also install axios (if not already present) for making API calls to the backend.

Backend: Install the bam-ticketing-sdk via Composer (composer require bam-ticketing-sdk). This SDK handles the actual delivery of tickets via email, SMS, and dashboard channels. Configure it in a new config file at config/bam-ticketing.php with environment variables for API keys and credentials. Store sensitive credentials (API keys, sender IDs) in your .env file, never in code.

Set up environment variables in .env:
- BAM_TICKETING_API_KEY (for the SDK)
- BAM_TICKETING_EMAIL_FROM (sender email address)
- BAM_TICKETING_SMS_FROM (SMS sender ID)
- BAM_TICKETING_WEBHOOK_SECRET (for delivery status callbacks from the provider)

Create a service class at app/Services/TicketDeliveryService.php that wraps the bam-ticketing-sdk and provides a clean interface for sending tickets via different methods. This service will be used by the delivery jobs.
