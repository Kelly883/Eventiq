Add a relationship to the User model (belongsTo). Add a method getPublicProfile() that returns only the fields safe to show publicly (id, userId, displayName, bio, avatarUrl, website, socialLinks, brandingColors, totalEventsCreated, totalTicketsSold, createdAt, and conditionally email/phone based on emailPublic/phonePublic flags). Add a method getPrivateProfile() that returns all fields (used only by the organizer themselves). Add a method to soft delete (use SoftDeletes trait). Add a method to calculate totalEventsCreated and totalTicketsSold from related events and tickets.

2. TypeScript types — Create src/features/organizer-profile/types/organizer.ts with these interfaces:
- Organizer (full profile with all fields)
- OrganizerPublic (public-facing profile with filtered fields)
- SocialLinks {twitter?: string, instagram?: string, linkedin?: string, youtube?: string}
- BrandingColors {primaryColor: string, accentColor: string}
- NotificationPreferences {ticketSales: boolean, eventReminders: boolean, platformUpdates: boolean}
- OrganizerStats {totalEventsCreated: number, totalTicketsSold: number, memberSince: Date}

Add Zod schemas for validation: OrganizerUpdateSchema (displayName required, bio max 500, URLs valid format, hex colors valid), AvatarUploadSchema (file required, MIME type image/*, size max 5MB).
