We need to add two routes to the app's router so users can access the push notification settings and admins can manage templates.

Add a route for PushNotificationSettingsSection at /settings/delivery-preferences. This is not a standalone page — it's a new section integrated into the existing DeliverySettingsPage. When the user navigates to /settings/delivery-preferences, the DeliverySettingsPage should render with the PushNotificationSettingsSection displayed as a card below the existing 'Email Notifications' section. The section should be part of the same page layout, not a separate route.

Add a route for AdminPushTemplateManagementPage at /admin/settings/push-templates. This is a standalone admin-only page. Protect this route with a role check — only users with the 'Admin' role should be able to access it. If a non-admin tries to access it, redirect to an 'Access Denied' page or the home page.

Both routes should require authentication (use the existing auth guard). If the user is not logged in, redirect to the login page.
