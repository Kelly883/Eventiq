We need eight reusable components that will be shared across the dashboard and ticket pages.

1. SummaryCards — Displays four metric cards in a 2x2 grid (desktop) or stacked (mobile). Takes props: totalTickets, upcomingEventsCount, pastEventsCount, totalSpent. Each card shows a label, large number, and optional trend indicator. Used on UserDashboardPage.

2. ActivityFeed — Scrollable list of recent ticket purchases. Takes array of ActivityItem objects. Each item shows event title, tier name, purchase date, and delivery status badge. Clicking an item navigates to ticket detail. Used on UserDashboardPage.

3. RecommendationsCarousel — Horizontal scrollable carousel of recommended events. Takes array of Event objects. Each event shows image, title, date, and 'View Event' button. Used on UserDashboardPage.

4. TicketCard — Individual ticket display in a horizontal card layout. Shows: QR code thumbnail on left, ticket details (tier name, ticket ID, event name) in middle, delivery status badge, and action buttons (Download PDF, Resend, View Details, Add to Wallet) on right. Takes Ticket object and callbacks for each action. Mobile: stacked vertical layout. Used in UserTicketsDashboardPage.

5. EventSection — Collapsible event group header showing event title, date, venue, ticket count, and total value. Clicking expands/collapses the ticket list below. Takes Event object and array of Tickets. Used in UserTicketsDashboardPage.

6. DeliveryStatusBadge — Small badge showing delivery status with color coding: green for sent, amber for pending, red for failed. Takes status string. Used in TicketCard, ActivityFeed, and TicketDetailPage.

7. QRCodeDisplay — Large, centered QR code with ticket ID below. Takes qrCodeData string. Renders scannable QR code using qrcode.react. Used on TicketDetailPage.

8. DeliveryTimeline — Vertical timeline showing delivery attempt history. Each item shows timestamp, status (sent/failed/pending), method (email/SMS), and error message if failed. Takes array of DeliveryEvent objects. Used on TicketDetailPage.

All components should handle loading states (skeleton/shimmer), empty states, and error states gracefully. Use consistent styling with the organizer's branding colors.
