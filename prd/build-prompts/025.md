We're building a comprehensive accessibility and localization system for the app. For this step, create a feature folder structure under src/features/accessibility-localization/ with the following subfolders:

1. pages — Will contain AccessibilitySettingsPage, LanguagePreferencePage, and DeviceLocalizationSyncPage
2. components — Reusable UI components like AccessibilityPreview, LanguageSelector, LocaleFormatPreview, DeviceCard, SyncStatusBadge, and SettingCard
3. hooks — Custom React hooks for managing accessibility and localization state: useAccessibilityPreferences, useLanguagePreferences, useDeviceLocalization, and useLocalizationSync
4. types — TypeScript interfaces for accessibility preferences, localization preferences, device data, and sync status
5. services — API client functions and utilities: accessibilityService, localizationService, deviceSyncService
6. utils — Helper functions for formatting dates/times/numbers, color blindness simulation, RTL detection, and preference validation
7. i18n — i18next configuration and translation files organized by language (en, es, fr, de, pt, zh, ja, ar)

On the backend (Laravel), create a folder structure under app/Http/Controllers/Api/Users/ with AccessibilityPreferencesController and LanguagePreferencesController. Create app/Models/AccessibilityPreference and LanguagePreference models. Create app/Policies/AccessibilityPreferencePolicy and LanguagePreferencePolicy for authorization.

This structure keeps accessibility and localization concerns separate but co-located, making it easy to maintain and extend.
