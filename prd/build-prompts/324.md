We need to make sure payment errors don't break the user experience. Handle these scenarios:

PaymentMethodsPage:
- Network failure on initial load → show a full-screen error with a 'Retry' button (not a small notification — the page has no content yet)
- Failure while fetching the list → show an error banner at the top with a retry option
- Adding a payment method fails because the card was declined → show a friendly error in the modal: 'Your card was declined. Please try a different card.'
- Adding a payment method fails because the Stripe API is down → show 'Payment service temporarily unavailable. Please try again later.'
- Adding a payment method fails with a network error → show a notification with a retry option
- Removing a payment method fails → show a notification: 'Could not remove this payment method. Please try again.' Keep the card in the list.
- Setting a default fails → show a notification: 'Could not set as default. Please try again.' Don't change the UI.
- User's login expires (401) → redirect to the login page

OrganizerPaymentSettingsPage:
- Network failure on initial load → show a full-screen error with a 'Retry' button
- Failure to check Stripe Connect status → show an error banner with a retry option
- Stripe Connect onboarding fails or is cancelled → show a notification: 'Stripe connection was not completed. Please try again.' Stay on the page.
- Stripe Connect return flow fails → show an error: 'Could not complete Stripe connection. Please try again.' with a link to retry
- User's login expires (401) → redirect to the login page
- User is not an organizer (403) → show 'Access Denied - Only organizers can configure payments.' with a link to go back

Stripe Elements form (in the Add New Card modal):
- Invalid card number → show 'Invalid card number' below the field
- Expired card → show 'Your card has expired'
- Missing CVC → show 'CVC is required'
- Stripe.js fails to load → show 'Payment form is unavailable. Please refresh the page.'
- stripe.createPaymentMethod fails → show the Stripe error message (e.g., 'Your card was declined')

All pages: If the user's login expires (401), redirect to the login page. If a 500 error occurs, show a generic 'Something went wrong' message and suggest contacting support.
