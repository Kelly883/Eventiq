We need three packages set up before we build the QR code feature:

1. QR Code Generation (Backend) — Install the qrcode package in Laravel (via Composer). This will generate QR code images from encrypted payloads. We'll use it in the POST /api/tickets/generate-qr endpoint to create QR images that get uploaded to storage.

2. QR Code Scanning (Frontend) — Install jsQR in the React app (via npm). This library will decode QR codes from the camera stream in real-time on the VenueCheckInPage. It runs client-side so scanning works even with slight network delays.

3. Encryption & Hashing (Backend) — Laravel comes with crypto utilities built-in, but make sure the crypto extension is enabled in your PHP config. We'll use Laravel's Crypt facade for AES-256 encryption of QR payloads and bcrypt for hashing secrets. Also install the bcrypt package via Composer if not already included.

On the frontend, you'll also need to install crypto-js for any client-side validation or offline verification (though most decryption happens server-side). Set up environment variables for any API endpoints and encryption keys that need to be accessible to the frontend (though the actual encryption key stays server-side only).
