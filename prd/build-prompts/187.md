We need several reusable React components that the DeveloperPortalPage will use. These components are shared across multiple tabs and handle significant UI logic.

1. TabContainer — A wrapper component that manages tab state (which tab is active). Accepts children (tab panels) and a list of tab names. Renders a tab bar at the top with the tab names, and shows/hides the corresponding panel. On mobile, collapses into a dropdown select instead of a horizontal tab bar. Used by DeveloperPortalPage to switch between 'API Keys', 'Webhooks', 'API Logs', and 'Documentation' tabs.

2. DataTable — A reusable table component for displaying lists of items (API keys, webhooks, logs). Accepts columns (array of column definitions with key, label, render function), data (array of items), loading state, empty state message, and actions (array of action buttons like 'Edit', 'Delete', 'Revoke'). Shows skeleton rows while loading. Shows an empty state illustration and CTA when there are no items. Each row has action buttons that trigger callbacks. Supports pagination with next/previous buttons.

3. KeyModal — A modal that displays a newly generated API key. Shows the raw key in a code block with a 'Copy to Clipboard' button. Includes a warning: 'This is the only time you'll see this key. Copy it now and store it somewhere safe.' Has a 'Done' button that closes the modal. Used after creating a new API key.

4. WebhookForm — A form for creating or editing a webhook. Fields: url (text input, required, must be valid URL), subscribedEvents (multi-select checkboxes for event types like 'order.created', 'ticket.checked_in', 'ticket.scanned'). Submit button says 'Create Webhook' or 'Update Webhook' depending on mode. Cancel button closes the form. Validates that url is a valid URL and at least one event is selected. Used in a modal or inline on the Webhooks tab.

5. ApiKeyForm — A form for creating a new API key. Fields: name (text input, required), scopes (multi-select checkboxes for scopes like 'events:read', 'orders:read', 'tickets:read', 'tickets:write'), expiresAt (optional date picker). Submit button says 'Create Key'. Cancel button closes the form. Validates that name is not empty and at least one scope is selected. Used in a modal.

6. TestWebhookButton — A button that sends a test webhook payload to a webhook URL. Shows a loading spinner while sending. On success, shows a toast notification 'Test sent successfully'. On failure, shows an error toast with the response code and message. Used in the Webhooks tab next to each webhook.

7. CopyButton — A small button with a copy icon that copies text to the clipboard. Shows a brief 'Copied!' tooltip on success. Used for copying API key prefixes, webhook URLs, and other values.

8. EmptyState — A component that displays when a tab has no data. Shows an illustration, a heading (e.g., 'No API Keys Yet'), a description, and a CTA button (e.g., 'Create Your First API Key'). Used in each tab when the list is empty.

9. LoadingSkeletons — Skeleton placeholder components for tables and forms. Shows 3-5 shimmer rows while data is loading. Used in the DataTable component.
