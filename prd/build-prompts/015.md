Inside tickets, create folders for: pages (UserTicketsDashboardPage, TicketDetailPage), components (TicketCard, EventSection, DeliveryStatusBadge, QRCodeDisplay, DeliveryTimeline, FilterBar), hooks (useTickets, useTicketDetail), and types.

On the Laravel backend, create a feature folder structure under app/Features/ with: Dashboard (Controllers, Requests, Resources), Tickets (Controllers, Requests, Resources, Policies), and Preferences (Controllers, Requests, Resources). Create a database/migrations folder for the user_dashboard_preferences migration. Create app/Models/ for the UserDashboardPreference model.

This separation keeps dashboard logic distinct from ticket management while sharing common authentication and authorization patterns.
