We need to add routes for the calendar feature to the React app's router. Set up these routes in your routing configuration (likely using React Router):

1. /events/calendar — EventCalendarPage. This is the main calendar view. Should be publicly accessible (no auth required). Add a link to this route from the main navigation or home page (e.g., 'Browse Events' or 'Calendar' in the header/nav bar).

2. /events/:eventId — EventDetailPage (already exists, referenced from calendar). When a user clicks an event on the calendar or in CalendarDayDetailModal, navigate to this route with the event ID.

3. /organizer/events/create — Event creation page (already exists, for organizers only). The 'Create Event' button on EventCalendarPage should navigate here, but only if the user is authenticated as an organizer. If not authenticated, show a login modal first.

For the CalendarDayDetailModal, it's not a separate route — it's a modal/sidebar that appears on the same /events/calendar page when the user clicks a date. Use React Router's location state or a URL query param (?selectedDate=2024-03-15) to track which date is selected, so the modal state persists if the user refreshes.

Add a 'Create Event' button to EventCalendarPage that's only visible to authenticated organizers. Clicking it should either navigate to /organizer/events/create or open a login modal if not authenticated.

Make sure the calendar page is linked from the main app navigation (header, sidebar, or bottom nav depending on the app's layout).
