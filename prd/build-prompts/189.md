We need several reusable components that the TicketInventoryDashboardPage and AdjustInventoryModal will use. These components handle the visual presentation and user interactions for inventory management.

1. InventorySummaryCard — Displays the high-level overview at the top of the dashboard. Shows four key metrics: total capacity, tickets sold, tickets remaining, and utilization percentage. Each metric is in its own card with a large number and a label. The utilization percentage should have a progress bar (green for 0-70%, amber for 70-90%, red for 90-100%). Takes props: { totalCapacity, totalSold, totalAvailable, utilizationPercentage }.

2. LowStockAlert — Inline alert component that appears when a tier or pricing window is low on stock. Shows an icon (warning or info), a message (e.g., 'Only 15 tickets left in VIP tier'), and a color-coded background (amber for low, red for critical). Takes props: { message, severity: 'low' | 'critical' }.

3. InventoryTable — Main data table showing all ticket tiers with their inventory levels. Columns: tier name, base price, quantity limit (total allocated), sold, available, utilization %. Each row is sortable by clicking the column header. Rows can be expanded to show pricing windows nested underneath. Takes props: { tiers, onSort, sortBy, sortOrder, onExpandRow }. Shows a loading skeleton while data is fetching.

4. PricingWindowRow — Nested row within InventoryTable showing a single pricing window. Displays: window name, start/end dates, quantity limit, quantity sold, quantity available, and whether it's active. Takes props: { window, isExpanded }.

5. InventoryExportButton — Button that triggers the export modal or directly downloads the inventory report. Supports CSV and JSON formats. Shows a loading spinner while exporting. Takes props: { eventId, onExportStart, onExportComplete }.

6. InventoryAuditLog — Paginated table showing the audit trail of all inventory adjustments. Columns: date/time, organizer name, adjustment type, quantity before/after, delta (with +/- formatting), and reason. Supports filtering by tier, organizer, and adjustment type. Takes props: { eventId, filters, onFilterChange, page, onPageChange }.

7. AdjustInventoryForm — Form component used inside AdjustInventoryModal. Contains: dropdown to select tier or pricing window, numeric input for new quantity (with increment/decrement buttons), optional reason textarea, current vs. proposed quantity display side-by-side. Validates that new quantity >= 0 and <= event capacity. Takes props: { eventId, onSubmit, onCancel, isLoading }.

All components should:
- Accept loading and error states and display appropriate UI (skeleton, spinner, error message)
- Be responsive (stack on mobile, full layout on desktop)
- Use consistent styling and spacing
- Handle edge cases (empty data, very long names, zero quantities)
