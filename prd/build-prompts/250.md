Now we need to connect the organizer profile pages to the rest of the app so users can actually navigate to them.

Add routes for: /organizer/:organizerId (OrganizerPublicProfilePage), /organizer/profile/edit (OrganizerProfileEditPage), and /organizer/profile/settings (OrganizerProfileSettingsPage). Make sure the edit and settings routes are protected — only logged-in organizers can access them. Redirect to login if not authenticated, and show 'Access Denied' if the user doesn't have the Organizer role.

Wire up these connections:
- From the organizer's own public profile, show an 'Edit Profile' button that goes to /organizer/profile/edit
- From the edit page, add a link to /organizer/profile/settings
- From the settings page, add a link back to the public profile and to the edit page
- When 'Save' succeeds on the edit page, redirect to the public profile view (/organizer/:organizerId where organizerId is the current user's organizer ID)
- When 'Save' succeeds on the settings page, show a confirmation toast and stay on the page
- Add a way to get to the organizer profile from the main navigation (e.g., a 'My Profile' link in the user menu or organizer dashboard)
- Deep links to /organizer/:organizerId should work for anyone (public profile is public)
- Deep links to /organizer/profile/edit and /organizer/profile/settings should redirect to login if not authenticated
