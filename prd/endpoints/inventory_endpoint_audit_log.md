# Inventory Endpoint Audit Log

GET /api/organizer/events/:eventId/inventory/audit-log

## Description

REQUEST: URL param eventId (UUID), query params: ?tierFilter=uuid (optional), ?organizerFilter=uuid (optional), ?adjustmentType=manual_increase|manual_decrease|reallocation|system_correction (optional), ?page=1 (optional), ?limit=50 (optional)
PROCESS: 1. Verify auth token 2. Query events by eventId 3. Check user owns event via Policy 4. Query inventory_adjustments filtered by eventId, optionally by tierFilter, organizerFilter, adjustmentType 5. Eager load organizerId and ticketTierId user/tier details 6. Sort by createdAt descending (most recent first) 7. Paginate with limit/offset 8. Return paginated audit log
SUCCESS (200): { adjustments: [{id, tierId, tierName, organizerId, organizerName, adjustmentType, quantityBefore, quantityAfter, quantityDelta, reason, createdAt}], total, page, limit }
ERRORS: 400 (invalid query params), 401 (unauthenticated), 403 (forbidden), 404 (event not found), 500 (database error)
SECURITY: Auth required. Event ownership enforced. Rate limit 20/min per user.
