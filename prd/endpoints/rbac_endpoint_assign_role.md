# Rbac Endpoint Assign Role

POST /api/admin/roles/assign

## Description

REQUEST: { userIds: [string], roleId: string, reason?: string }
PROCESS: 1. Verify admin authorization via Policy 2. Validate roleId exists in roles collection 3. For each userId: a) Verify user exists b) Check if role change is allowed (prevent self-demotion) c) Store old role/permissions in auditLog d) Update user.roleId e) Invalidate user's sessions (set revokedAt) f) Create auditLog entry with before/after state 4. Return success with count of updated users
SUCCESS (200): { updated: number, message: 'Role assigned to X users' }
ERRORS:
- 400: Missing userIds or roleId, invalid roleId, userIds is empty
- 401: User not authenticated
- 403: User is not admin, or attempting to demote self
- 404: One or more users not found
- 429: Rate limit exceeded (10/min per admin)
- 500: Database error
SECURITY: Admin-only. Invalidate sessions on role change to enforce new permissions immediately. Log all changes with admin ID and reason. Prevent self-demotion.
