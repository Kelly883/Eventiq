# Calendar Endpoint Day Events

GET /api/events/public/calendar/day/:date

## Description

REQUEST: URL param date (ISO8601 format YYYY-MM-DD), query params: ?category=concerts (optional), ?priceMin=0&priceMax=500 (optional), ?location=New York (optional), ?sortBy=date|price|popularity (optional, default: date)
PROCESS: 1. Validate date format (ISO8601 YYYY-MM-DD) 2. Query events collection filtered by status='published' and event date matching the provided date 3. Apply optional filters (category, price range, location) 4. Join with pricing_windows to get current prices 5. Join with ticket_inventory for stock levels 6. Join with organizers for profile data 7. Sort by requested field 8. Return all events for that day
SUCCESS (200): { date: ISO8601, events: [{id, title, organizer: {id, name, avatar, brandingColors}, startTime, endTime, venue: {name, address, latitude, longitude}, description, bannerUrl, ticketTiers: [{id, name, currentPrice, ticketsAvailable}], ticketsSold, trending}], total: number }
ERRORS: 400 (invalid date format), 404 (no events for date), 500 (database error)
SECURITY: Public endpoint. Rate limit 30/min per IP. Only published events.
