# Push Notifications Endpoint Admin Send Test

POST /api/admin/push-templates/send-test

## Description

Sends a test push notification. An admin can provide a raw title and body along with a user_id. The backend will find all device tokens for that user_id and send the notification. This is used for immediate feedback in the admin panel. The actual sending is dispatched to a queued Laravel Job to avoid blocking the API response.
