PROCESS: 1. Verify admin authorization via Policy 2. Query users collection with optional filters (role, search by email/name) 3. Eager load roles and permissions for each user 4. Return paginated list with role badges and permission counts
SUCCESS (200): { users: [{id, email, name, role: {id, name}, permissionCount, createdAt}], total, page, limit }
ERRORS:

- 401: User not authenticated (attempt token refresh → redirect to login)
