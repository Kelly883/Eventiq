# Dashboard Endpoint Get Activity Feed

GET /api/organizer/dashboard/activity-feed

## Description

REQUEST: Query params: ?limit=20 (optional), ?offset=0 (optional), ?eventFilter=uuid (optional), ?tierFilter=uuid (optional), ?startDate=ISO8601 (optional), ?endDate=ISO8601 (optional)
PROCESS: 1. Verify auth token and extract organizerId 2. Query analytics_sales_timeline filtered by organizer's events 3. Apply optional filters (eventFilter, tierFilter, date range) 4. Sort by saleTimestamp descending (most recent first) 5. Paginate with limit/offset 6. Eager load event and tier details for each sale 7. Return paginated activity feed
SUCCESS (200): { activities: [{id, eventId, eventName, tierId, tierName, quantity, unitPrice, totalAmount, saleTimestamp, buyerEmail (if available)}], total, limit, offset }
ERRORS:
- 400: Invalid query parameters (invalid date format, non-numeric limit/offset)
- 401: User not authenticated
- 403: User does not have Organizer role
- 500: Database error
SECURITY: Auth required. Organizer role enforced. Only returns sales from organizer's own events. Rate limit 20/min per user.
