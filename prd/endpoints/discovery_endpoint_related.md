# Discovery Endpoint Related

GET /api/events/public/:eventId/related

## Description

REQUEST: URL param eventId (UUID), query params: ?limit=5
PROCESS: 1. Query events by eventId 2. Check status='published' 3. Get organizer_id from this event 4. Query other published events from same organizer, excluding current event 5. Limit to 5 results 6. Order by start_datetime ascending 7. Return related events
SUCCESS (200): { relatedEvents: [{id, title, date, bannerUrl, startingPrice}] }
ERRORS: 404 (event not found), 500 (database error)
SECURITY: Public endpoint. Rate limit 30/min per IP.
