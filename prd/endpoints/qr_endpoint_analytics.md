# Qr Endpoint Analytics

GET /api/organizer/events/:eventId/check-in-analytics

## Description

REQUEST: URL param eventId (UUID), query params: ?startDate=ISO8601 (optional), ?endDate=ISO8601 (optional)
PROCESS: 1. Verify auth token and extract userId 2. Query events by eventId 3. Check user owns event via Policy 4. Query tickets filtered by eventId, status='checked_in' 5. If date range provided, filter by checkedInAt between startDate and endDate 6. Calculate metrics: totalCheckedIn (count), checkInRate (checked-in / total tickets %), peakCheckInHour (hour with most check-ins), averageCheckInTime (avg time from event start to check-in) 7. Group check-ins by hour for timeline visualization 8. Group check-ins by ticket tier for tier breakdown 9. Return analytics summary with charts data
SUCCESS (200): { totalCheckedIn (integer), checkInRate (decimal %), peakCheckInHour (integer 0-23), averageCheckInTime (integer minutes), timeline: [{hour (integer), checkInCount (integer)}], tierBreakdown: [{tier (string), checkedIn (integer), percentage (decimal)}], lastUpdatedAt (timestamp) }
ERRORS: 400 (invalid eventId or date format), 401 (unauthenticated), 403 (user doesn't own event), 404 (event not found), 500 (database error)
SECURITY: Auth required (bearer token). Event ownership enforced via Policy. Rate limit 20/min per user. Organizers can only view analytics for their own events.
