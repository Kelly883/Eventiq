# Checkout Endpoint Webhook

POST /api/webhooks/payment-provider

## Description

Handles incoming webhooks from the payment provider (e.g., Stripe). This is the core of order fulfillment. It must verify the webhook's signature. For a successful payment event, it transactionally updates the order status to 'completed', creates the unique ticket records, decrements inventory, updates analytics tables, and queues a job to email the tickets to the user.
