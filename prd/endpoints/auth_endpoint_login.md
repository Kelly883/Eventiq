# Auth Endpoint Login

POST /api/auth/login

## Description

REQUEST: { email (string, required, valid email format), password (string, required, min 1 char) }
PROCESS: 1. Validate input format 2. Query users table by email 3. Compare password with bcrypt hash using constant-time comparison 4. If match, create session record with 7-day expiry 5. Update user.lastLoginAt 6. Return token and user info
SUCCESS (200): { token (string), user: { id, email, name, role } }
ERRORS:
- 400: Missing email or password, invalid email format
- 401: User not found or password mismatch (same message for both — don't leak which)
- 429: Rate limit exceeded (5 attempts per 15 minutes per IP)
- 500: Database error
SECURITY: Rate limit 5/15min per IP prevents brute-force. Constant-time bcrypt comparison prevents timing attacks. Never expose whether email exists. Update lastLoginAt for security audits.
