# Audit Endpoint Logs Bulk Tag

POST /api/admin/compliance/audit-logs/bulk-tag

## Description

REQUEST: { logIds: array<string> (required, max 100 items), tag: string (required, e.g., 'compliance_review', 'incident_investigation', 'data_breach'), notes: string (optional, max 500 chars) }
PROCESS: 1. Verify auth token and extract userId 2. Check user has 'Admin' role via Policy 3. Validate logIds exist and belong to auditLogs 4. Add tag to metadata.tags array for each log 5. Create auditLog entry: action='audit_log_tagged', targetType='audit_log', targetIds=logIds, metadata={tag, notes, taggedBy=userId} 6. Return success with count of tagged logs
SUCCESS (200): { tagged: integer, message: 'X logs tagged successfully' }
ERRORS: 400 (invalid logIds, empty array, too many items), 401 (unauthenticated), 403 (user not admin), 404 (one or more logs not found), 500 (database error)
SECURITY: Admin-only. Auth required. Rate limit 10 bulk operations/min per user.
