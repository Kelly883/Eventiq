# Dashboard Endpoint Get Overview

GET /api/organizer/dashboard/overview

## Description

REQUEST: Query params: ?dateRange=7days|30days|90days|all (optional, default: 30days), ?eventFilter=all|upcoming|past|draft (optional, default: all)
PROCESS: 1. Verify auth token and extract organizerId 2. Query events filtered by organizerId and eventFilter 3. For each event, query analytics_events_metrics to get revenue, tickets sold, conversion rate 4. Aggregate metrics across all events (sum revenue, sum tickets, average conversion) 5. Count events by status 6. Calculate trend indicators by comparing current period to previous period 7. Return aggregated summary with trend data
SUCCESS (200): { totalRevenue (decimal), totalTicketsSold (integer), averageConversionRate (decimal %), upcomingEventCount (integer), totalEventCount (integer), revenueTrend (string: 'up'|'down'|'flat'), ticketsTrend (string), conversionTrend (string), lastUpdatedAt (timestamp) }
ERRORS:
- 400: Invalid dateRange or eventFilter parameter
- 401: User not authenticated (attempt token refresh → if fails, redirect to login)
- 403: User does not have Organizer role
- 500: Database error
SECURITY: Auth required (bearer token). Organizer role enforced via Policy. Rate limit 20/min per user to prevent abuse. Only returns organizer's own events.
