# Checkin Endpoint Realtime Stats

GET /api/venue/check-in/stats

## Description

REQUEST: URL param eventId (UUID), query params: ?lastUpdateAt=ISO8601 (optional - for incremental updates)
PROCESS: 1. Verify auth token and extract userId 2. Check user has 'VenueStaff' or 'Organizer' role via Policy 3. Query events by eventId 4. Verify user is authorized for this event 5. Query tickets filtered by eventId to get: total capacity (from event), total checked-in (count where status='checked_in'), total remaining (capacity - checked_in), total void (count where status='void') 6. Calculate check-in rate percentage 7. If lastUpdateAt provided, only return changes since that timestamp 8. Return real-time statistics
SUCCESS (200): { totalCapacity (integer), totalCheckedIn (integer), totalRemaining (integer), totalVoid (integer), checkInRate (decimal %), lastUpdateAt (timestamp), updatedSince (ISO8601, optional) }
ERRORS: 400 (invalid eventId or lastUpdateAt format), 401 (unauthenticated), 403 (user not authorized), 404 (event not found), 500 (database error)
SECURITY: Auth required (bearer token). Venue staff role enforced via Policy. Event authorization validated. Rate limit 60 stats/min per user for real-time updates.
