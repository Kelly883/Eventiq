# Accessibility Endpoint Get Preferences

GET /api/users/me/accessibility-preferences

## Description

REQUEST: No body, auth token in Authorization header. PROCESS: 1. Verify auth token and extract userId 2. Query accessibility_preferences by userId 3. If not found, return default accessibility preferences 4. Return preferences with all current settings. SUCCESS (200): { fontSize (integer), highContrast (boolean), screenReaderOptimized (boolean), focusIndicatorEnhanced (boolean), motionReduced (boolean), lineHeight (decimal), letterSpacing (decimal), wordSpacing (decimal), colorBlindnessMode (string) }. ERRORS: 401 (unauthenticated - attempt token refresh → if fails, redirect to login), 403 (user does not have permission), 500 (database error). SECURITY: Auth required (bearer token). User can only view their own preferences (enforced by Policy). Rate limit 20/min per user to prevent abuse.
