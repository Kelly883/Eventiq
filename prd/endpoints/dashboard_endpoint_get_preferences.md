# Dashboard Endpoint Get Preferences

GET /api/organizer/dashboard/preferences

## Description

REQUEST: No body, auth token in Authorization header
PROCESS: 1. Verify auth token and extract organizerId 2. Query organizer_dashboard_preferences by organizerId 3. If not found, return default preferences 4. Return preferences
SUCCESS (200): { defaultEventFilter (string), defaultDateRange (string), expandedEventId (string or null), showActivityFeed (boolean), autoRefreshEnabled (boolean) }
ERRORS:
- 401: User not authenticated
- 403: User does not have Organizer role
- 500: Database error
SECURITY: Auth required. Organizer role enforced. Rate limit 20/min per user.
