# Dashboard Endpoint User Overview

GET /api/users/me/dashboard-overview

## Description

REQUEST: No body, auth token in Authorization header
PROCESS: 1. Verify auth token and extract userId 2. Query tickets by userId 3. Calculate summary metrics: totalTickets (count), upcomingEventsCount (count where event.startDateTime >= NOW), pastEventsCount (count where event.startDateTime < NOW), totalSpent (sum of order.total_amount) 4. Query next upcoming event (event.startDateTime >= NOW, order by startDateTime ascending, limit 1) 5. Query recent activity (last 5 ticket purchases, order by created_at descending) 6. Eager load related events, orders, delivery_events for activity items 7. Return aggregated summary
SUCCESS (200): { totalTickets (integer), upcomingEventsCount (integer), pastEventsCount (integer), totalSpent (decimal), nextUpcomingEvent: {id, title, date, venue, ticketCount}, recentActivity: [{eventTitle, tierName, purchaseDate, deliveryStatus}] }
ERRORS: 401 (user not authenticated), 403 (user does not have permission), 500 (database error)
SECURITY: Auth required (bearer token). User can only view their own data (enforced by Policy). Rate limit 20/min per user to prevent abuse.
