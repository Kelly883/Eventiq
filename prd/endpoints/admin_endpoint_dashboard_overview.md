# Admin Endpoint Dashboard Overview

GET /api/admin/dashboard/overview

## Description

REQUEST: No body, query params optional: ?period=24h|7d|30d (default: 24h)
PROCESS: 1. Verify auth token and extract userId 2. Check user has 'Admin' role via Policy 3. Query orders collection filtered by createdAt >= period start, calculate total revenue (sum of orders.total_amount) 4. Query events collection filtered by status='published', count active events 5. Query users collection filtered by role='organizer' and status='pending', count pending approvals 6. Query fraud_events collection filtered by status='flagged', count flagged transactions 7. Query payouts collection filtered by status='failed', count failed payouts 8. Calculate trend indicators by comparing current period to previous period 9. Return aggregated metrics
SUCCESS (200): { period, totalRevenue (decimal), activeEvents (integer), pendingApprovals (integer), flaggedTransactions (integer), failedPayouts (integer), revenueTrend (string: 'up'|'down'|'flat'), eventsTrend (string), transactionsTrend (string) }
ERRORS: 400 (invalid period), 401 (unauthenticated - attempt token refresh → if fails, redirect to login), 403 (user not admin), 500 (database error)
SECURITY: Admin-only (requires 'Admin' role via Policy). Auth required (bearer token). Rate limit 20/min per user to prevent abuse.
