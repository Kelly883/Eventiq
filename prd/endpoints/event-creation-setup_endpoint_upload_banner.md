# Event Creation Setup Endpoint Upload Banner

POST /api/organizer/events/:eventId/upload-banner

## Description

Handles the upload of an event's banner image. It validates the file type (image/*) and size (max 5MB). The file is stored on an S3-compatible storage disk in a path like `events/{eventId}/banner.{ext}`. The `events.banner_image_url` field is updated with the new file's URL.
