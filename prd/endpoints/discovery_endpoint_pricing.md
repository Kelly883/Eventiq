# Discovery Endpoint Pricing

GET /api/events/public/:eventId/pricing

## Description

REQUEST: URL param eventId (UUID)
PROCESS: 1. Query events by eventId 2. Check status='published' 3. Query pricing_windows filtered by eventId, only active windows (current time between startDateTime and endDateTime) 4. If no active windows, query most recent window as fallback 5. Eager load ticket_tiers for category details 6. For each tier, compute current price and next price change info 7. Return public pricing data
SUCCESS (200): { eventId, tiers: [{tierId, tierName, currentPrice, nextPrice, nextPriceChangeAt, quantityAvailable, quantitySold}] }
ERRORS: 404 (event not found or not published), 500 (database error)
SECURITY: Public endpoint. Rate limit 30/min per IP. Only published events.
