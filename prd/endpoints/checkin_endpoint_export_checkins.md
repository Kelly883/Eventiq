# Checkin Endpoint Export Checkins

GET /api/venue/check-in/export

## Description

REQUEST: URL param eventId (UUID), query params: ?format=csv|json (optional, default: csv), ?includeNoShows=true|false (optional, default: false), ?startTime=ISO8601 (optional), ?endTime=ISO8601 (optional)
PROCESS: 1. Verify auth token and extract userId 2. Check user has 'VenueStaff' or 'Organizer' role via Policy 3. Query events by eventId 4. Verify user is authorized for this event 5. Query tickets filtered by eventId, status='checked_in', optionally by time range 6. If includeNoShows=true, also include tickets with status='valid' (not checked in) 7. Eager load related order and attendee details 8. Format data as CSV or JSON based on format param 9. Set appropriate Content-Type and Content-Disposition headers 10. Return file stream
SUCCESS (200): CSV or JSON file with check-in data
ERRORS: 400 (invalid format param, invalid date range), 401 (unauthenticated), 403 (user not authorized), 404 (event not found), 500 (export generation failed)
SECURITY: Auth required (bearer token). Venue staff role enforced via Policy. Event authorization validated. Rate limit 5 exports/min per user to prevent abuse.
