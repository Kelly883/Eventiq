# Organizer Endpoint Get Organizer Events

GET /api/organizers/:organizerId/events

## Description

REQUEST: URL param organizerId (UUID), query params: ?status=upcoming|past&limit=20&offset=0
PROCESS: 1. Query organizers collection by id 2. Check profile is public (if private, return 404) 3. Query events collection filtered by organizer_id 4. Filter by status (upcoming/past) based on event date 5. Order by date descending 6. Paginate with limit/offset 7. Eager load event details (title, date, thumbnail, ticket availability) 8. Return paginated event list
SUCCESS (200): { events: [{id, title, date, description, thumbnailUrl, ticketsAvailable, ticketsSold}], total, limit, offset }
ERRORS:
- 404: Organizer not found or profile is private
- 400: Invalid query parameters (invalid status, non-numeric limit/offset)
- 500: Database error
SECURITY: Public endpoint. Rate limit 20/min per IP. Only returns events from public organizer profiles.
