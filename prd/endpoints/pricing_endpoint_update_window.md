# Pricing Endpoint Update Window

PATCH /api/organizer/events/:eventId/pricing/windows/:windowId

## Description

REQUEST: URL params eventId (UUID), windowId (UUID), body: { windowName (string, optional), startDateTime (timestamp, optional), endDateTime (timestamp, optional), price (decimal, optional, > 0), quantityLimit (integer, optional, > 0), priority (integer, optional) }
PROCESS: 1. Verify auth token 2. Query pricing_windows by windowId 3. Verify window belongs to eventId 4. Query events by eventId 5. Check user owns event via Policy 6. Validate input: if dates provided, startDateTime < endDateTime and endDateTime <= event.endDateTime 7. Check for overlapping windows (excluding current window) if dates changed 8. Update pricing_windows record with provided fields 9. Return updated window
SUCCESS (200): { id, windowName, ticketCategoryId, startDateTime, endDateTime, price, quantityLimit, quantitySold, isActive, priority, updatedAt }
ERRORS: 400 (validation failed), 401 (unauthenticated), 403 (user doesn't own event), 404 (window or event not found), 409 (overlapping window), 429 (rate limited), 500 (database error)
SECURITY: Auth required. Event ownership enforced. Input validated. Rate limit 10 updates/min per user.
