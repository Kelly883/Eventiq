# Pricing Endpoint List Windows

GET /api/organizer/events/:eventId/pricing/windows

## Description

REQUEST: URL param eventId (UUID), query params: ?categoryId=uuid (optional filter by ticket category)
PROCESS: 1. Verify auth token and extract userId 2. Query events by eventId 3. Check user owns event via Policy 4. Query pricing_windows filtered by eventId, optionally by categoryId 5. Eager load related ticket_tiers for category names 6. Sort by startDateTime ascending 7. Return paginated list with computed isActive field
SUCCESS (200): { windows: [{id, windowName, ticketCategoryId, categoryName, startDateTime, endDateTime, price, quantityLimit, quantitySold, isActive, priority}], total }
ERRORS: 400 (invalid eventId or categoryId format), 401 (user not authenticated), 403 (user does not own event), 404 (event not found), 500 (database error)
SECURITY: Auth required (bearer token). Event ownership enforced via Policy. Rate limit 20/min per user to prevent abuse.
