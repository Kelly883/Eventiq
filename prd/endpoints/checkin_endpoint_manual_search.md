# Checkin Endpoint Manual Search

GET /api/venue/check-in/search

## Description

REQUEST: Query params: ?eventId=uuid (required), ?query=string (required, min 2 chars - ticket ID, attendee email, or name), ?limit=10 (optional)
PROCESS: 1. Verify auth token and extract userId 2. Check user has 'VenueStaff' or 'Organizer' role via Policy 3. Query events by eventId 4. Verify user is authorized for this event 5. Query tickets filtered by eventId, search by ticketId (exact match), email (partial match), or attendee name (partial match) 6. Eager load related event and order details 7. Return paginated search results with ticket status
SUCCESS (200): { results: [{ticketId, attendeeName, tier, status, checkedInAt (if applicable), qrCodeData}], total, query }
ERRORS: 400 (invalid eventId, query too short), 401 (unauthenticated), 403 (user not authorized for event), 404 (event not found), 500 (database error)
SECURITY: Auth required (bearer token). Venue staff role enforced via Policy. Event authorization validated. Rate limit 60 searches/min per user to prevent abuse. Search results limited to 10 items per query.
