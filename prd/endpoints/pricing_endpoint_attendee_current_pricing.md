# Pricing Endpoint Attendee Current Pricing

GET /api/attendee/events/:eventId/pricing

## Description

REQUEST: URL param eventId (UUID), query params: ?categoryId=uuid (optional filter by ticket category)
PROCESS: 1. Query events by eventId 2. Check event is published (status='published') 3. Query pricing_windows filtered by eventId, only active windows (current time between startDateTime and endDateTime) 4. If no active windows, query most recent window as fallback 5. Eager load ticket_tiers for category details 6. For each category, return current active price and next price change info 7. Return public pricing data (no organizer-specific fields)
SUCCESS (200): { eventTitle, categories: [{categoryId, categoryName, currentPrice, nextPrice, nextPriceChangeAt, quantityAvailable}] }
ERRORS: 400 (invalid eventId), 404 (event not found or not published), 500 (database error)
SECURITY: Public endpoint (no auth required). Rate limit 30/min per IP to prevent scraping. Only returns published events.
