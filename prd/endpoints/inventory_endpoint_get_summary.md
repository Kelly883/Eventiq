# Inventory Endpoint Get Summary

GET /api/organizer/events/:eventId/inventory/summary

## Description

REQUEST: URL param eventId (UUID)
PROCESS: 1. Verify auth token and extract userId 2. Query events by eventId 3. Check user owns event via Policy 4. Query ticket_inventory filtered by eventId 5. Aggregate totalAllocated, totalSold, totalAvailable across all tiers 6. Count low-stock tiers (isLowStock=true) 7. Return summary with capacity utilization percentage
SUCCESS (200): { totalCapacity (sum of all tier allocations), totalSold, totalAvailable, utilizationPercentage, lowStockTierCount, tiers: [{tierId, tierName, allocated, sold, available, isLowStock}] }
ERRORS: 400 (invalid eventId format), 401 (user not authenticated), 403 (user does not own event), 404 (event not found), 500 (database error)
SECURITY: Auth required (bearer token). Event ownership enforced via Policy. Rate limit 20/min per user to prevent abuse.
