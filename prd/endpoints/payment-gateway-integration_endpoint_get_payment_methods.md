# Payment Gateway Integration Endpoint Get Payment Methods

GET /api/users/me/payment-methods

## Description

Retrieves a list of saved payment methods for the authenticated user. Uses Laravel Sanctum for authentication and a Policy to ensure users can only access their own data. It leverages Laravel Cashier's methods on the User model to fetch payment methods directly from the Stripe API and/or the local `payment_methods` table.
