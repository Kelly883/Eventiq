# Admin Endpoint Dashboard Alerts

GET /api/admin/dashboard/alerts

## Description

REQUEST: No body, query params optional: ?severity=critical|warning|info (optional, default: all)
PROCESS: 1. Verify auth token and extract userId 2. Check user has 'Admin' role via Policy 3. Query system alerts from multiple sources: failed payment batches (query payments where status='failed' and retryCount >= maxRetries), high fraud scores (query fraud_events where riskScore > 75 and status='flagged'), system errors (query system_logs where level='error' in last 24h), failed payouts (query payouts where status='failed'), low inventory (query ticket_inventory where isLowStock=true) 4. Aggregate and sort by severity and timestamp 5. Apply severity filter if provided 6. Return alert list with actionable information
SUCCESS (200): { alerts: [{id, type (payment_failure|fraud_spike|system_error|payout_failure|low_inventory), severity (critical|warning|info), title, description, actionUrl, timestamp}], total }
ERRORS: 400 (invalid severity), 401 (unauthenticated), 403 (user not admin), 500 (database error)
SECURITY: Admin-only. Auth required. Rate limit 20/min per user.
