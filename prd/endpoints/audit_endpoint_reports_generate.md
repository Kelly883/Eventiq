# Audit Endpoint Reports Generate

POST /api/admin/compliance/reports/generate

## Description

REQUEST: { reportType: string (required - 'data_access'|'user_activity'|'payment_audit'|'refund_audit'|'data_retention'|'incident_report'), startDate: ISO8601 (required), endDate: ISO8601 (required), classification: string (optional - 'public'|'internal'|'sensitive'|'pci_dss'|'gdpr_personal_data'|'sox_financial'), format: string (optional - 'pdf'|'csv'|'json', default: 'pdf') }
PROCESS: 1. Verify auth token and extract userId 2. Check user has 'Admin' role via Policy 3. Validate date range (endDate > startDate, not in future) 4. Queue report generation job (async) with jobId 5. Return jobId immediately for polling 6. Job process: Query auditLogs filtered by date range and classification 7. Generate report based on type: data_access (group by targetType/targetId), user_activity (group by userId), payment_audit (filter action='payment_*'), refund_audit (filter action='refund_*'), data_retention (show retention dates), incident_report (filter status='failed' or fraud events) 8. Format as PDF/CSV/JSON 9. Store report file in Storage at compliance-reports/{reportId}.{ext} 10. Create compliance_reports record with metadata 11. Log action to auditLogs: action='compliance_report_generated', classification='sox_financial'
SUCCESS (202): { jobId: string, reportType: string, status: 'queued', estimatedCompletionTime: integer (seconds), message: 'Report generation started' }
ERRORS: 400 (invalid date range, invalid reportType), 401 (unauthenticated), 403 (user not admin), 500 (job queue error)
SECURITY: Admin-only. Auth required. Rate limit 5 report generations/min per user to prevent abuse. All report generations logged.
