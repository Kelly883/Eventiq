# Organizer Endpoint Get Public Profile

GET /api/organizers/:organizerId

## Description

REQUEST: URL param organizerId (UUID)
PROCESS: 1. Query organizers collection by id 2. Check isPublic flag — if false and requester is not the organizer, return 404 3. Eager load related user data (name, email from users table) 4. Filter sensitive fields based on privacy toggles (emailPublic, phonePublic) 5. Return organizer profile with public data only
SUCCESS (200): { id, userId, displayName, bio, avatarUrl, website, socialLinks, brandingColors, totalEventsCreated, totalTicketsSold, email (if emailPublic), phone (if phonePublic), createdAt }
ERRORS:
- 404: Organizer not found or profile is private and requester is not owner
- 500: Database error
SECURITY: Public endpoint (no auth required). Rate limit 20/min per IP to prevent scraping. Sensitive fields filtered based on privacy toggles.
