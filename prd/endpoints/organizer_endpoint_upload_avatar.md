# Organizer Endpoint Upload Avatar

POST /api/organizers/me/upload-avatar

## Description

REQUEST: multipart/form-data with file (image file, required), auth token in Authorization header
PROCESS: 1. Verify auth token 2. Extract userId 3. Query organizers by userId 4. Validate file: check MIME type (image/jpeg, image/png, image/webp), check file size (max 5MB) 5. Use Storage abstraction to upload to S3/object storage at path avatars/{userId}/{timestamp}.{ext} 6. Resize image to 400x400 using image processing library (sharp) 7. Generate download URL from storage 8. Update organizers.avatarUrl with new URL 9. Delete old avatar from storage if exists 10. Create auditLog entry 11. Return new avatarUrl
SUCCESS (200): { avatarUrl (string) }
ERRORS:
- 400: File validation failed (invalid MIME type, file too large, no file provided)
- 401: User not authenticated
- 403: User does not have Organizer role
- 404: Organizer profile not found
- 413: File too large (>5MB)
- 500: Storage upload failed, image processing failed
SECURITY: Auth required. File type and size validated server-side. Stored in S3/object storage with access control. Old avatar deleted to prevent storage bloat. Rate limit 10 uploads/min per user.
