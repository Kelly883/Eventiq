# Auth Endpoint Reset Password

POST /api/auth/reset-password

## Description

REQUEST: { token (string, required), newPassword (string, required, min 8 chars) }
PROCESS: 1. Validate input 2. Query passwordResetTokens by hashed token 3. Check token not expired and not already used 4. Find associated user 5. Hash new password with bcrypt (cost 12) 6. Update user.passwordHash 7. Mark token as used (set usedAt timestamp) 8. Revoke all existing sessions for this user (set revokedAt) 9. Return success
SUCCESS (200): { message: 'Password reset successfully' }
ERRORS:
- 400: Missing token or password, password too short, token invalid/expired/already used
- 500: Database error
SECURITY: Single-use tokens (check usedAt). Tokens expire in 1 hour. Invalidate all sessions on reset. Hash new password before storing.
