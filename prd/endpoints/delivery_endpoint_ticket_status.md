# Delivery Endpoint Ticket Status

GET /api/tickets/:ticketId/delivery-status

## Description

REQUEST: URL param ticketId (UUID)
PROCESS: 1. Verify auth token and extract userId 2. Query tickets by ticketId 3. Check user owns ticket via Policy 4. Query delivery_events filtered by ticketId, order by createdAt descending 5. Eager load related order and event details 6. Compute delivery status (pending/sent/failed/viewed) 7. Return delivery status with full history
SUCCESS (200): { ticketId, status, deliveryMethod, recipientEmail, recipientPhone, deliveryTimestamp, viewedTimestamp, attemptCount, maxAttempts, errorMessage, nextRetryAt, qrCodeData, ticketPdfUrl, deliveryHistory: [{timestamp, status, method, errorMessage}] }
ERRORS: 400 (invalid ticketId format), 401 (user not authenticated), 403 (user does not own ticket), 404 (ticket not found), 500 (database error)
SECURITY: Auth required (bearer token). Ticket ownership enforced via Policy. Rate limit 20/min per user to prevent abuse.
