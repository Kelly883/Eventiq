# Event Creation Setup Endpoint Update Event

PATCH /api/organizer/events/:eventId

## Description

Updates an existing event and its ticket tiers. It can handle creating, updating, and deleting ticket tiers in the same request to sync the state.

## Ticket Tier ID Format

The `ticketTiers` array uses the `id` field to determine the action for each tier:

- **Create (new tier):** Omit the `id` field entirely from the tier object.
- **Update (existing tier):** Include the existing `id` and the fields you want to change.
- **Delete (remove tier):** Exclude the tier object from the `ticketTiers` array entirely.

Example:

    {
      "ticketTiers": [
        { "id": 42, "name": "VIP", "price": 5000 },
        { "name": "Early Bird", "price": 3000, "quantity": 100 }
      ]
    }

In this example, tier `42` is updated, and a new tier is created because it has no `id`.
