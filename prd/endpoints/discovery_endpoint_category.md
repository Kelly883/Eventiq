# Discovery Endpoint Category

GET /api/events/public/category/:categoryId

## Description

REQUEST: URL param categoryId (string), query params: ?page=1&limit=20&sortBy=date|popularity
PROCESS: 1. Validate categoryId is valid category 2. Query events filtered by status='published' and category=categoryId 3. Apply sorting 4. Paginate 5. Eager load organizer details 6. Return paginated list
SUCCESS (200): { category: {id, name, description}, events: [{id, title, organizer, date, venue, bannerUrl, startingPrice, ticketsAvailable}], total, page, limit }
ERRORS: 400 (invalid category), 500 (database error)
SECURITY: Public endpoint. Rate limit 30/min per IP.
