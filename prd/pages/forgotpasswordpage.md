## Description

FUNCTIONALITY: Single email input field for password reset request. Submit button sends reset link to email. Always shows same success message regardless of email existence (prevents email enumeration attacks). Success state replaces form entirely with confirmation message, mail icon, and instructions to check email and spam folder. 'Back to Sign In' link routes to /login. Clear instructional text explaining the reset process and timeline (reset link expires in 1 hour).
DESIGN APPROACH: Centered card, minimal — single focused action. Supportive copy explaining what will happen. Success state uses icon (mail envelope) and larger text for emphasis. No form visible after success, only confirmation message and next steps.
STATES: Loading state shows 'Sending...' in submit button, form remains interactive. Success replaces entire form with confirmation message, mail icon, 'Check your email' heading, and instructions. Rate-limited (429) shows 'Too many requests. Please try again later.' as inline message. Network error shows toast with retry. Invalid email format shows inline validation error.
SECURITY: Public page. Same response always regardless of email existence (never reveal if email is registered). Rate limit 3 requests per hour per IP to prevent abuse. Reset tokens expire in 1 hour.
