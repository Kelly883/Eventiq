## Description

FUNCTIONALITY: Multi-field registration form with name, email, password, and confirm password inputs. Real-time password strength meter (weak/medium/strong) with color indicator (red/amber/green) displayed below password field. Inline validation on field blur — email format check, password minimum 8 characters, password match verification. Terms & conditions checkbox required before submit. Form submission with loading state. On successful registration, redirect to /login with 'Account created successfully' toast. Duplicate email (409) shows specific error 'This email is already registered' with link to login page. 'Already have an account? Sign In' link routes to /login.
DESIGN APPROACH: Same centered card pattern as LoginPage for visual consistency. Password strength meter uses color progression (red for weak, amber for medium, green for strong) with text label. Fields grouped logically — name first, then email, then password fields together. Confirm password field appears after password field is valid. Terms checkbox positioned above submit button. Error messages appear inline below relevant field.
STATES: Loading state disables all form fields and shows 'Creating account...' in submit button. Validation errors highlight field in red with message below on blur. 409 conflict shows 'This email is already registered' below email field with 'Sign In' link. Network error shows toast with retry. Success redirects to /login with confirmation toast.
SECURITY: Public page (unauthenticated users only). Password hashed server-side before storage. Email uniqueness enforced at database level. Rate limit on registration attempts to prevent abuse.
