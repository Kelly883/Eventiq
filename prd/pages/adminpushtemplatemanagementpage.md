## Description

FUNCTIONALITY: An admin-only interface for managing all push notification templates, mirroring the email template page. The page displays a list of existing templates (e.g., 'Event Reminder', 'Ticket Confirmation'). Admins can create, edit, or delete templates. The editor includes fields for template name, type, a title (max 65 chars), and a body (max 178 chars). A sidebar shows available placeholder variables (e.g., {{user.name}}, {{event.title}}). A 'Send Test Notification' button opens a modal where an admin can enter a user ID to send a real test push notification to that user's registered devices.
DESIGN APPROACH: A two-column layout consistent with the AdminEmailTemplateManagementPage. The left column lists all push templates. The main content area on the right contains the template editor form. The form provides real-time character counts for the title and body fields. The 'Send Test' action opens a small modal to input a User ID.
STATES: Loading: Skeleton list items and a disabled editor form. Empty: An illustration with 'No push templates created yet' and a 'Create Template' CTA. Saving: Spinner on the 'Save' button, form disabled. Error 401: Redirect to login. Error 403: 'Access Denied' page. Error 500: Error banner with retry button.
SECURITY: Protected route for users with the 'Admin' role, enforced by a Laravel Policy. All template content is sanitized on the backend.
