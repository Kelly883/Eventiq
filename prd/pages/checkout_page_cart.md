## Description

FUNCTIONALITY: Displays items added to the cart from event pages. Users can adjust the quantity of each ticket tier or remove items completely. The page dynamically recalculates subtotals and an estimated total. It uses a React Context (`CartContext`) for state management. A prominent 'Proceed to Checkout' button navigates the user to the /checkout page, passing the cart state. If the cart is empty, this button is disabled.
DESIGN APPROACH: A clean, table-like layout showing ticket tier name, event, quantity, price per ticket, and line total. A summary card is displayed on the side (desktop) or bottom (mobile) showing subtotal, fees, and total. Each line item has '+' and '-' buttons for quantity and a 'remove' icon.
STATES: Loading: Not applicable as cart state is client-side. Empty: Shows an illustration, 'Your cart is empty', and a button to 'Browse Events' which links to /events. Success: Displays the list of cart items. Item update: A brief loading spinner on the specific line item being updated.
SECURITY: This page is accessible to both authenticated and unauthenticated users. Cart contents are stored in local storage and managed by a React Context. No sensitive operations occur here.
