## Description

FUNCTIONALITY: Displays real-time delivery status for a single purchased ticket. Shows current delivery method (email, SMS, dashboard), delivery timestamp, and status badge (pending/sent/failed/viewed). If delivery failed, displays the reason and a 'Resend Ticket' button. For email delivery, shows recipient email address with option to change it. For SMS, shows phone number. Includes a 'Download PDF' button to manually download the ticket. Shows QR code preview and ticket details (event name, date, tier, seat info if applicable). Delivery history timeline shows all delivery attempts with timestamps and outcomes. For failed deliveries, provides troubleshooting suggestions (check spam folder, verify phone number, etc.).
DESIGN APPROACH: Vertical scrollable layout with status badge prominently at top (color-coded: green=sent, amber=pending, red=failed). Delivery method cards show current status with icon and timestamp. QR code displayed large and centered for easy scanning. Timeline of delivery attempts below with expandable details. Resend button positioned prominently if delivery failed. Mobile-friendly with full-width cards and stacked sections.
STATES: Loading shows skeleton status card and placeholder timeline. Success displays full delivery status with QR code and timeline. Error 401 redirects to login with 'Session expired' toast. Error 403 shows 'Access Denied — you don't own this ticket' with back button. Error 404 shows 'Ticket not found' with link to my-tickets. Error 500 shows error banner with retry button. Resending shows spinner on button, disabled state.
SECURITY: Authenticated users only. Users can only view their own tickets (enforced by Policy). Rate limit 10 resend attempts/min per user to prevent abuse.
