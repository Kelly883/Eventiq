## Description

FUNCTIONALITY: Organizer-only dashboard displaying real-time ticket inventory across all tiers and pricing windows for a single event. Shows a summary card with total capacity, tickets sold, tickets remaining, and low-stock alerts. Below, a detailed table or card grid showing each ticket tier (Regular, VIP, VVIP, Early Bird) with current stock levels, sold count, and percentage utilization. For each tier, displays all active and upcoming pricing windows with their individual quantity limits and quantities sold. Includes bulk actions to adjust inventory allocations — select multiple windows, set new quantity limits, apply changes. A timeline visualization shows inventory depletion over time (if historical data available). Inline low-stock alerts (e.g., 'Only 15 tickets left in VIP tier') with color-coded urgency (green=healthy, amber=low, red=critical). 'Adjust Inventory' button opens a modal to manually increase/decrease stock for specific tiers. Real-time updates via polling or WebSocket (if infrastructure supports). Export inventory report as CSV.
DESIGN APPROACH: Dense scannable layout for power users — summary cards at top (total capacity, sold, remaining), then a data table with sortable columns (tier name, base price, quantity limit, sold, available, utilization %). Pricing windows nested as expandable rows or tabs within each tier. Color-coded utilization bars (green/amber/red) for quick visual scanning. Sticky header with filter bar (filter by tier, status, price window). Mobile: stacked cards instead of table, collapsible tier sections.
STATES: Loading shows skeleton summary cards and placeholder table rows with shimmer effect. Empty state (no tiers) shows 'No ticket tiers configured' with link to pricing page. Error 401 redirects to login with 'Session expired' toast. Error 403 shows 'Access Denied — only event organizers can manage inventory' with back button. Error 404 shows 'Event not found' with link to events list. Error 500 shows error banner with retry button. Success displays full inventory dashboard with real-time data.
SECURITY: Organizer-only (requires event ownership via Policy). Auth required (bearer token). Rate limit 20/min per user for read operations, 5/min for write operations (inventory adjustments) to prevent abuse. All inventory changes logged to auditLogs with timestamp and admin ID.
