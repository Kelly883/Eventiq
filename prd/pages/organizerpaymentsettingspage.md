## Description

FUNCTIONALITY: Allows organizers to connect their Stripe account to receive payouts. The page checks the organizer's Stripe Connect status. If not connected, it displays information about the partnership with Stripe and a single 'Connect with Stripe' button. Clicking this button navigates the user to the '/api/organizer/settings/stripe-connect' endpoint, which redirects them to the Stripe Connect Onboarding flow. If the account is already connected, the page displays the connected Stripe account ID (masked), the status ('Enabled', 'Pending'), and a link to their Stripe Express Dashboard. It also provides an option to 'Disconnect' their account.
DESIGN APPROACH: A simple, clear settings page section. The primary state is a call-to-action to connect with Stripe, using Stripe's branding assets for trust. Once connected, it becomes a status display page, providing information and links rather than editable forms.
STATES: Loading: A spinner while checking the organizer's connection status. Not Connected: A view with explanatory text and the 'Connect with Stripe' button. Connected: A view showing the account status and dashboard link. Error_401: Redirects to login modal. Error_403: Shows 'Access Denied - Only organizers can configure payments.'
SECURITY: Requires authenticated user with 'organizer' role. The connection flow is handled via a secure redirect to Stripe.
