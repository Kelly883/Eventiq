## Description

FUNCTIONALITY: Token extracted from URL query parameter (?token=...). Initial token validation before showing form — displays loading state 'Validating reset link...' during validation. If token is invalid or expired, shows clear error message with 'Request new link' action that routes to /forgot-password. If token is valid, reveals two password fields: new password (with strength meter) and confirm password. Password requirements listed visibly near input field (minimum 8 characters, etc.). On successful password reset, redirects to /login with 'Password reset successfully' toast. Form submission shows loading state 'Resetting...' in button.
DESIGN APPROACH: Centered card, same pattern as other auth pages. Progressive flow — first validates token (loading state), then reveals form if valid, or shows error if invalid. Password strength meter (weak/medium/strong) with color indicator. Password requirements listed as bullet points for clarity. Error state includes prominent 'Request new link' button.
STATES: Initial loading: 'Validating reset link...' with spinner. Invalid/expired token: error message 'This link has expired or is invalid' with 'Request new link' button. Form ready: shows new password and confirm password fields with strength meter. Submitting: 'Resetting...' in button, fields disabled. Success: redirect to /login with toast 'Password reset successfully'.
SECURITY: Token single-use — cannot be reused after password reset. Tokens expire in 1 hour. All existing sessions for this user invalidated on successful password reset. Public page but token-gated (invalid token shows error, not 404).
