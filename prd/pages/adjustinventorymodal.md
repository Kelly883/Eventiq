## Description

FUNCTIONALITY: Modal dialog triggered from the TicketInventoryDashboardPage via 'Adjust Inventory' button. Allows organizers to manually increase or decrease ticket quantities for specific tiers or pricing windows. Displays a dropdown to select which tier/window to adjust, a numeric input field for the new quantity (with validation to prevent negative numbers or exceeding event capacity), and optional reason field for audit trail. Shows current quantity and proposed new quantity side-by-side for clarity. 'Apply' button submits the change, 'Cancel' closes the modal without changes. On success, shows 'Inventory updated' toast and refreshes the dashboard table. Prevents overselling — if new quantity would exceed event capacity, shows validation error 'Quantity exceeds event capacity by X tickets'.
DESIGN APPROACH: Modal overlay with semi-transparent background. Centered card (max-w-md) with clear title 'Adjust Inventory'. Dropdown for tier/window selection, numeric input with increment/decrement buttons, optional reason textarea. Current vs. proposed quantities displayed as side-by-side cards for easy comparison. Submit button disabled until quantity is changed. Mobile-friendly with full-width inputs.
STATES: Loading shows spinner in submit button. Validation error highlights input field in red with message below (e.g., 'Quantity exceeds capacity'). Success shows 'Inventory updated' toast and closes modal. Error 400 shows validation error inline. Error 401 redirects to login. Error 403 shows 'Access Denied'. Error 500 shows error message in modal with retry button.
SECURITY: Organizer-only. Auth required. Rate limit 5 adjustments/min per user to prevent spam. All changes logged to auditLogs with reason field.
