## Description

FUNCTIONALITY: Admin-only real-time dashboard monitoring ticket delivery across all events. Summary cards show total tickets delivered (24h), delivery success rate (%), failed deliveries count, and average delivery time. Interactive table lists all delivery events with ticket ID, event name, buyer email, delivery method, status (sent/failed/pending), timestamp, and retry count. Color-coded status badges (green=sent, amber=pending, red=failed). Bulk actions to retry failed deliveries or manually trigger delivery for specific tickets. Expandable row details show full delivery attempt history, error messages, and recipient contact info. Filters by event, delivery method, status, or date range. Real-time updates every 30 seconds. Export delivery report as CSV. Search by ticket ID or email. Delivery method breakdown chart showing percentage of tickets delivered via email vs SMS vs dashboard.
DESIGN APPROACH: Dense scannable layout for power users. Summary metric cards at top (delivered count, success rate, failed count, avg time) with color-coded trend indicators. Data table below with sortable columns (ticket ID, event, method, status, timestamp). Expandable rows show delivery history without leaving page. Sticky filter bar with status, method, date range filters. Mobile: stacked cards instead of table, collapsible details.
STATES: Loading shows skeleton metric cards and placeholder table rows with shimmer. Empty state (no deliveries) shows 'No delivery events yet' with illustration. Error 401 redirects to login with 'Session expired' toast. Error 403 shows 'Access Denied — only admins can view delivery dashboard' with back button. Error 500 shows error banner with retry button. Success displays full dashboard with live-updating delivery metrics.
SECURITY: Admin-only (requires 'Admin' role via Policy). Auth required (bearer token). Rate limit 20/min per user for read operations to prevent abuse. All delivery actions logged to auditLogs with admin ID and timestamp.
