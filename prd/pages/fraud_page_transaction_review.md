## Description

FUNCTIONALITY: Modal dialog triggered from FraudDetectionDashboardPage when admin clicks on a flagged transaction. Displays comprehensive fraud analysis for a single order: order details (ID, amount, currency, timestamp), buyer information (email, name, IP address, device fingerprint), payment method details (card last 4 digits, issuer, country), velocity metrics (orders from this user in last 24h, total spend, average order value), duplicate ticket detection results (if any matching QR codes found), and fraud risk factors (reasons why flagged). Shows risk score breakdown by category (payment velocity, duplicate detection, device fingerprinting, geolocation mismatch). Admin can approve the transaction (mark as legitimate) or reject it (void order and refund). Optional notes field for documenting the decision. On approve/reject, shows confirmation dialog before applying action.
DESIGN APPROACH: Modal overlay with semi-transparent background. Centered card (max-w-2xl) with scrollable content. Sections organized vertically: order summary at top, buyer/payment info in middle, fraud analysis at bottom. Risk score displayed prominently with color-coded badge (green/amber/red). Action buttons (Approve/Reject) sticky at bottom of modal. Mobile-friendly with full-width layout.
STATES: Loading shows skeleton sections with shimmer effect. Success shows full transaction details with all fraud analysis. Error shows 'Unable to load transaction details' with close button. Submitting shows spinner on action button, form disabled. Confirmation dialog appears before approve/reject action.
SECURITY: Admin-only. Auth required. Rate limit 10 reviews/min per admin to prevent abuse. All decisions logged to auditLogs.
