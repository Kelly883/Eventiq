## Description

FUNCTIONALITY: Organizer-only page to configure dynamic pricing rules for an event's ticket categories. Displays a list of existing ticket categories (Regular, VIP, VVIP, Early Bird) with their base prices. For each category, organizers can add multiple pricing windows (time-based tiers) with specific start/end dates, prices, and quantity limits. A 'Add Pricing Window' button opens a form to create new windows. Each window shows: window name, start date/time, end date/time, price override, quantity limit, and delete action. A timeline visualization shows when each pricing window is active relative to the event date. Form validation ensures windows don't overlap, prices are positive, and dates are logical (start before end, windows before event end). 'Save Changes' button persists all pricing rules. 'Preview' button shows a summary of pricing schedule for attendee view.
DESIGN APPROACH: Two-column layout on desktop (ticket categories left, pricing windows right). Each category as a collapsible card showing base price and active windows. Pricing windows displayed as timeline cards with drag-to-resize capability for date adjustment. Color-coded by window type (early bird=green, regular=blue, last-minute=orange). Mobile: stacked single-column with collapsible sections. Sticky footer with Save and Preview buttons.
STATES: Loading shows skeleton category cards and placeholder windows. Empty state (no pricing windows) shows 'No pricing rules yet' with 'Add Pricing Window' CTA. Saving shows spinner on button, form disabled. Validation error highlights invalid field with red border and message below. Success shows 'Pricing updated' toast and refreshes timeline. Error 401 redirects to login. Error 403 shows 'Access Denied'. Error 404 shows 'Event not found'. Error 500 shows error banner with retry.
SECURITY: Organizer-only (requires ownership of event via Policy). Auth required (bearer token). Rate limit 10 updates/min per user to prevent abuse. All changes logged to auditLogs.
