## Description

FUNCTIONALITY: Admin-only real-time fraud monitoring dashboard displaying suspicious transactions flagged by the fraud detection system. Summary cards show total flagged transactions (24h), fraud risk score distribution (low/medium/high), and blocked orders count. Interactive table lists flagged orders with transaction details (order ID, amount, buyer email, timestamp, risk score, reason flagged). Color-coded risk badges (green=low, amber=medium, red=high). Bulk actions to review and approve/reject flagged orders. Expandable row details show full transaction history, payment method fingerprint, velocity metrics (orders per hour, total spend), and device/IP geolocation. Filters by risk level, date range, payment method, or reason. Real-time updates every 30 seconds. Export flagged transactions as CSV for external analysis.
DESIGN APPROACH: Dense scannable layout for power users. Summary metric cards at top (flagged count, risk distribution, blocked orders) with color-coded trend indicators. Data table below with sortable columns (order ID, amount, risk score, timestamp, status). Expandable rows show detailed fraud analysis without leaving the page. Sticky filter bar with risk level, date range, payment method filters. Mobile: stacked cards instead of table, collapsible details.
STATES: Loading shows skeleton metric cards and placeholder table rows with shimmer effect. Empty state (no flagged transactions) shows 'No suspicious transactions detected' with illustration. Error 401 redirects to login with 'Session expired' toast. Error 403 shows 'Access Denied — only admins can view fraud dashboard' with back button. Error 500 shows error banner with retry button. Success displays full dashboard with live-updating flagged transactions.
SECURITY: Admin-only (requires 'Admin' role via Policy). Auth required (bearer token). Rate limit 20/min per user for read operations to prevent abuse. All fraud decisions logged to auditLogs with admin ID and timestamp.
