## Description

FUNCTIONALITY: Language and locale selection interface for users to choose their preferred language and regional settings. Language selector dropdown showing all supported languages (English, Spanish, French, German, Portuguese, Chinese, Japanese, Arabic, etc.) with native language names and flag icons. Current language highlighted. On selection, entire UI immediately switches to selected language including all labels, buttons, error messages, and date/time formats. Locale-specific formatting options: date format selector (MM/DD/YYYY, DD/MM/YYYY, YYYY-MM-DD), time format (12-hour, 24-hour), currency display (USD, EUR, GBP, etc.), number formatting (comma vs period for decimals). RTL (right-to-left) language support automatically applied for Arabic, Hebrew, Urdu. Preview section shows how dates, times, and numbers will be formatted with current locale settings. Language preference persists across sessions and syncs across all user devices. Keyboard navigation fully supported with arrow keys to navigate language list.
DESIGN APPROACH: Vertical scrollable layout with language selector prominently at top. Language grid showing flag icons and language names as selectable cards (current language highlighted with checkmark). Locale formatting options below as grouped cards. Preview section shows real-world examples of formatted dates/times/numbers. Mobile: full-width cards with stacked layout, language grid becomes vertical list.
STATES: Loading shows skeleton language selector and placeholder preview. Success displays language grid with current selection highlighted, preview showing formatted examples. Error 401 redirects to login with 'Sign in to change language' toast. Error 403 shows 'Access Denied'. Error 500 shows error banner with retry. Language switching shows brief loading state then immediate UI update.
SECURITY: Authenticated users only. Users can only modify their own language preferences (enforced by Policy). Rate limit 5 language changes/min per user to prevent spam. All language preference changes logged to auditLogs with user ID and timestamp.
