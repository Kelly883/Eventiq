## Description

FUNCTIONALITY: Displays a list of all tickets purchased by the authenticated user. It fetches data from the `/api/my-tickets` endpoint. Tickets are grouped by event. Each ticket is displayed as a card with event details (title, date, venue), ticket tier, and a unique QR code for scanning at the venue. Options to download the ticket as a PDF or add it to a mobile wallet (if supported) are provided.
DESIGN APPROACH: A user-dashboard style page. Events are listed chronologically. Each event is a collapsible card that reveals the individual tickets purchased for it. The QR code is rendered using a library like `qrcode.react`. The layout is responsive, stacking vertically on mobile.
STATES: Loading: Shows several skeleton ticket cards. Empty: An illustration with the message 'You have no tickets yet.' and a 'Browse Events' button. Error 401: Redirects to login. Error 500: Shows an error banner with a retry button.
SECURITY: Requires authentication. The API endpoint is scoped to only return tickets owned by the authenticated user.
