## Description

FUNCTIONALITY: Detailed view of a single purchased ticket. Displays large QR code (scannable at venue) with ticket ID below. Event details section shows: event title, date/time, venue address with map embed, organizer name and avatar. Ticket information section shows: tier name, seat/section info (if applicable), ticket status (valid/checked-in/void), purchase date, order ID. Delivery status section shows: delivery method (email/SMS/dashboard), recipient address (masked for privacy), delivery timestamp, and delivery history timeline showing all delivery attempts with timestamps and outcomes. For failed deliveries, shows error reason and 'Resend Ticket' button. Action buttons: 'Download PDF', 'Add to Wallet', 'Share Ticket', 'Report Issue'. Check-in info (if event has passed) shows: checked-in timestamp, venue staff name who scanned. Related section shows other tickets from same order.
DESIGN APPROACH: Vertical scrollable layout with QR code prominently at top (large, centered, scannable). Event details in card below QR. Ticket info as horizontal key-value pairs. Delivery timeline as vertical timeline with expandable details. Action buttons sticky at bottom on mobile. Mobile: full-width cards with stacked sections, QR code optimized for mobile scanning.
STATES: Loading shows skeleton QR placeholder, placeholder event card, skeleton delivery timeline. Error 401 redirects to login with 'Session expired' toast. Error 403 shows 'Access Denied — you don't own this ticket' with back button. Error 404 shows 'Ticket not found' with link to /my-tickets. Error 500 shows error banner with retry button. Success displays full ticket details with QR code and delivery history.
SECURITY: Authenticated users only. Users can only view their own tickets (enforced by Policy). Rate limit 20/min per user to prevent abuse.
