## Description

FUNCTIONALITY: Cross-event analytics comparison page allowing organizers to compare sales performance across multiple events. Displays a table of all organizer's events with key metrics (total revenue, tickets sold, conversion rate, avg ticket price, attendee count). Allows selecting 2-3 events to compare side-by-side with detailed metrics and charts. Comparison charts show revenue trends, sales velocity, and tier performance across selected events. Identifies best-performing events and pricing strategies. Export comparison report as PDF or CSV.
DESIGN APPROACH: Two-section layout. Top section: event selection with checkboxes (max 3 events). Bottom section: comparison charts and metrics table. Charts use different colors for each event for easy visual distinction. Mobile: stacked sections with event selector as collapsible panel.
STATES: Loading shows skeleton event list and placeholder comparison charts. Empty state (only 1 event) shows 'Create more events to compare performance' message. Error 401 redirects to login. Error 403 shows 'Access Denied'. Error 500 shows error banner. Success displays event list with comparison charts.
SECURITY: Organizer-only. Auth required. Rate limit 10/min per user. Only shows organizer's own events.
