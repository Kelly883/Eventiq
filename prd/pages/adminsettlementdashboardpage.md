## Description

FUNCTIONALITY: Admin-only real-time dashboard for managing revenue settlements across all organizers. Summary cards show total platform revenue (24h), total pending payouts, settlement success rate (%), and average payout processing time (hours). Interactive table lists all pending settlements with columns: organizer name, event count, gross revenue, platform commission collected, refunds applied, net payout amount, status (pending/calculated/approved/processing/completed/failed), and action buttons. Color-coded status badges (amber=pending, blue=calculated, green=approved, purple=processing, gray=completed, red=failed). Bulk actions to approve/reject multiple settlements at once. Expandable row details show full settlement breakdown: individual event revenues, commission calculation by tier, tax withholding details, and payment method. Filters by organizer, status, date range, or revenue range. Real-time updates every 30 seconds. Search by organizer name or event ID. Export settlement report as CSV. Settlement method breakdown chart showing percentage of payouts by method (ACH, wire, etc.). Manual payout trigger for urgent settlements with admin approval.
DESIGN APPROACH: Dense scannable layout for power users. Summary metric cards at top (platform revenue, pending payouts, success rate, avg processing time) with color-coded trend indicators (green=up, red=down). Data table below with sortable columns (organizer, events, gross, commission, net, status, date). Expandable rows show full settlement details without leaving page. Sticky filter bar with status, organizer, date range, revenue range filters. Mobile: stacked cards instead of table, collapsible details. Bulk action checkboxes on left of each row.
STATES: Loading shows skeleton metric cards and placeholder table rows with shimmer. Empty state (no pending settlements) shows 'All settlements processed' with illustration. Error 401 redirects to login with 'Session expired' toast. Error 403 shows 'Access Denied — only admins can view settlements' with back button. Error 500 shows error banner with retry button. Success displays full dashboard with live-updating settlement metrics and status badges.
SECURITY: Admin-only (requires 'Admin' role via Policy). Auth required (bearer token). Rate limit 20/min per user for read operations, 5/min for write operations (approvals) to prevent abuse. All settlement decisions logged to auditLogs with admin ID and timestamp. Sensitive organizer banking info masked (last 4 digits only).
